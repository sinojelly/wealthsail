# 全球大宗商品晴雨表与多尺度经济周期研判 SOP（L4，非 MVP）

> 本 Skill 默认关闭，只输出研究情景，不输出通用资产配比或订单。周期划分存在模型风险、修订滞后与区间不确定性，不能仅凭单一比价决定投资。

## 1. 核心宏观指标与经济传导机制

### 1.1 大宗晴雨表
1. **原油 (WTI / Brent)**：工业血液与输入型通胀预期核心。
2. **铜博士 (LME / 沪铜)**：全球制造业开工与实体需求最敏感领先指标。
3. **上海金基准价 (Au99.99)**：抗通胀、央行购金与地缘避险定价中枢。

### 1.2 比价衍生指标
- **金铜比 (Gold/Copper Ratio)**：避险 vs 经济景气。持续走高提示经济降速与避险升温。
- **油铜比 (Oil/Copper Ratio)**：滞胀压力指标。高油价低铜价提示输入型滞胀风险。

## 2. 基钦库存周期 4 阶段与情景假设

| 周期阶段 | 宏观特征 | 需要核对的相反证据 | 仅供研究的资产敏感性假设 |
| :--- | :--- | :--- | :--- |
| **① 被动去库存** | 需求回升，库存继续下降 | 需求是否只是低基数；价格/信用是否背离 | 权益和顺周期可能更敏感，但需验证盈利与估值 |
| **② 主动补库存** | 预期乐观，企业扩产备货 | 库存是否由被动积压造成；通胀/利率是否压制 | 商品与顺周期可能受益，也可能面临过热回撤 |
| **③ 被动补库存** | 需求转弱，产品积压 | 供给冲击、季节性和口径修订 | 防御资产可能相对占优，但不自动生成现金/黄金比例 |
| **④ 主动去库存** | 需求疲软，企业主动降库存 | 政策刺激和信用拐点是否已出现 | 久期/高股息敏感性需结合利率、信用与估值验证 |

## 3. 确定性再平衡候选

本 Skill 只输出 `scenario_id`、证据、反证、置信区间、`as_of` 和来源。只有确定性配置引擎才能在用户风险承受能力、允许资产、现金需求、费税和目标策略均完整时计算候选：
$$\text{调仓金额} = \text{总净值} \times (\text{目标比例} - \text{当前实际比例})$$

输出必须展示目标策略版本、偏离门槛、金额取整、费用、数据时点和“不执行”选项；不得由 LLM 生成具体金额/克数，也不得声称某种配置必然平滑回撤。
