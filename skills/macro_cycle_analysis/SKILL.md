# 全球大宗商品晴雨表与多尺度经济周期研判 SOP (L2–L4 演进)

## 1. 核心宏观指标与经济传导机制

### 1.1 大宗晴雨表
1. **原油 (WTI / Brent)**：工业血液与输入型通胀预期核心。
2. **铜博士 (LME / 沪铜)**：全球制造业开工与实体需求最敏感领先指标。
3. **上海金基准价 (Au99.99)**：抗通胀、央行购金与地缘避险定价中枢。

### 1.2 比价衍生指标
- **金铜比 (Gold/Copper Ratio)**：避险 vs 经济景气。持续走高提示经济降速与避险升温。
- **油铜比 (Oil/Copper Ratio)**：滞胀压力指标。高油价低铜价提示输入型滞胀风险。

## 2. 基钦库存周期 4 阶段与美林时钟资产轮动

| 周期阶段 | 宏观特征 | 美林时钟象限 | WealthSail 大类资产推荐配置权重 |
| :--- | :--- | :--- | :--- |
| **① 被动去库存** | 需求回升，企业库存继续下降 | 复苏早段 (Recovery) | **权益 55%~60%** + **黄金 15%** + 纯债 15% + 现金 10% |
| **② 主动补库存** | 预期乐观，企业主动扩产备货 | 繁荣过热 (Overheat) | **大宗商品/顺周期 35%** + 权益 35% + 黄金 15% + 现金 15% |
| **③ 被动补库存** | 需求开始转弱，产品积压滞销 | 滞胀晚期 (Stagflation) | **现金 40%** + **黄金 30%** + 短债 20% + 权益 10% (防守) |
| **④ 主动去库存** | 需求疲软，企业降价抛售去库 | 衰退低谷 (Recession) | **中长端国债 45%** + 黄金 20% + 高股息 20% + 现金 15% |

## 3. 动态再平衡调仓指令生成
当组合中实际权益比例偏离基准（如偏离超过 $\pm5\%$）时，SOP 自动计算调仓算式：
$$\text{调仓金额} = \text{总净值} \times (\text{目标比例} - \text{当前实际比例})$$
向用户输出结构化调仓建议（如：“建议赎回 2.5 万元高涨股票基金，转买 40 克上海金现货或中短债基金，平滑组合回撤”）。
