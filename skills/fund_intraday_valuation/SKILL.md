# 场外公募基金 14:30 盘中估值与申赎决策 SOP

## 1. 金融严谨性原则
1. **禁止将估值称为“实时净值”**：基金确认净值由基金管理人/销售机构按合同与公告发布。盘中 14:30 仅为基于披露持仓、成分行情与基准假设的**区间估算 (ESTIMATED)**。
2. **披露滞后性降级**：若基金最新持仓披露已超过 90 天，数据质量自动降级为 `ESTIMATED_STALE_HOLDINGS`，必须在报告中高亮风险，且不给出激进的确定性单边申赎指令。
3. **截止时效窗口**：目标在 `14:30 ~ 14:40` 完成推送；报告显示销售机构/基金合同适用的实际截止时间。`15:00` 只能作为常见示例，不能硬编码为所有基金规则。
4. **确定性计算优先**：LLM 不计算净值区间、覆盖率或申购金额。领域服务传入已经校验的确认净值、持仓权重、成分收益、剩余资产基准、方法版本和风险政策，LLM 只解释结果。
5. **覆盖率不足必须弃权**：缺少持仓明细、行情、基准或来源时返回 `UNAVAILABLE/ABSTAIN`，禁止用固定 `±x%` 常量生成看似实时的估值。

---

## 2. 估算算法与决策逻辑

```
估算日涨跌幅 = ∑ (前十大重仓股权重 × 重仓股盘中实时涨跌幅) + (剩余其他资产权重 × 对应行业基准指数涨跌幅)
```

- 若估算收益率 $\le -1.5\%$、估值处于历史低分位，且确定性风险政策允许 $\rightarrow$ 提示**“复核既有日度/周度定投计划”**；具体金额由用户预设计划或领域风控服务给出；
- 若估算涨幅与估值条件触发用户已确认的止盈规则 $\rightarrow$ 提示**“复核既有分批止盈计划”**；比例由版本化风险政策给出；
- 若波动在 $\pm0.5\%$ 以内 $\rightarrow$ 提示**“维持定投计划，保持观望”**。

> 上述阈值是可版本化的策略参数，不是普适投资规律。没有回测/评估证据时只作为提醒条件，不能宣称能提升收益。
