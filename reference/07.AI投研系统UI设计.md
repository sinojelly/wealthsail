随着功能的全面扩充，这个系统已经从一个单点工具演变成了一个专业的**个人量化投研中台**。要让如此多维度的功能既美观又易用，UI 设计的核心思路必须是：**“复杂配置后台化，日常决策对话化”**。

在设计这套界面时，我们可以采用现代跨端应用的组件化思维（如响应式布局，侧边栏在移动端折叠为底部导航栏或抽屉），确保 Web 端的高效信息展示与手机端的轻量化操作体验保持一致。

以下是为您设计的全局 UI 架构与核心页面交互方案：

### 一、 全局布局风格 (UI/UX 调性)

* **视觉风格**：极简专业风 (Minimalist Pro)。推荐采用深色模式 (Dark Mode)，以深灰 (Slate/Zinc) 为底色，降低长时间盯盘的视觉疲劳。涨跌信号严格使用高亮色（如 A股习惯的红涨绿跌，或美股习惯的绿涨红跌，支持全局切换）。
* **交互框架**：经典的 **左-中-右 三栏/双栏布局**。
* **左侧 (侧边栏)**：全局导航模块（支持图标折叠）。
* **中部 (主工作区)**：承载核心流（如聊天流、数据表格、卡片面板）。
* **右侧 (抽屉面板)**：全局上下文（如随时滑出的 K 线图、快捷参数微调），点击空白处即可收起。



---

### 二、 核心模块与页面设计

我们将所有需求拆解为 5 个核心主菜单模块：

#### 1. 登录与全局工作台 (Workspace / Command Center)

这是用户每天打开系统停留最久的页面，采用 **ChatOps (对话+卡片)** 形式。

* **UI 呈现**：类似飞书或 Slack 的主聊天界面。
* **核心功能**：
* **时间轴流 (Timeline)**：定时任务（盘前推演、盘后总结）生成的卡片会像消息一样推送到这里。
* **快捷指令区**：底部输入框支持 `@` 唤醒特定 Skill（如 `@财报分析大师 帮我看看茅台`），或输入 `/` 呼出快捷指令（如 `/buy 00700`）。
* **置顶看板**：工作区顶部悬浮几个关键的极简数据模块（大盘情绪温度计、今日预估总盈亏）。



#### 2. 资产与仓位中心 (Portfolio & Assets)

将仓位管理和关注列表数据化、可视化。

| 页面子 Tab | UI 元素与交互设计 | 承载功能 |
| --- | --- | --- |
| **资金概览** | 环形图 (资产占比)、折线图 (历史收益走势) | 配置总投入资金，自动计算可用资金、已用仓位、整体收益率。 |
| **持仓明细** | 响应式数据表格 (Data Grid) | 展示：代码、买入均价、现价、盈亏比例、**AI 建议止损位**。支持行内直接点击“平仓”。 |
| **自选/关注** | 瀑布流卡片或紧凑列表 | 配置关注股票，右侧直接显示 AI 对该股的实时情绪评级（🟢 偏多 / 🔴 偏空）。 |

#### 3. 引擎与策略舱 (Engine Room)

这是系统的“武器库”，将插件、Skill 和策略的管理做成类似“应用商店 (App Store)”的卡片化界面。

* **Skill (认知 SOP) 面板**：卡片形式展示已安装的思维模型（如“威科夫分析法”、“财报造假扫雷”）。点击卡片可编辑底层的 System Prompt。
* **Plugin (工具插件) 面板**：开关列表（Toggle Switch）。例如“AkShare 数据源”、“宏观经济指标 API”。显示其连接状态（绿灯/红灯）。
* **操作策略 (Strategy) 面板**：
* **策略卡片**：展示策略名称（如“双均线顺势策略”）、近期回测胜率。
* **扩展交互**：提供一个“上传/新建”按钮，允许用户粘贴 Python 策略代码，或配置 JSON 参数，完成策略扩展。



#### 4. 历史与复盘档案 (History & Post-mortem)

将冰冷的历史数据变成可供学习的“投资日记”。

* **UI 呈现**：采用**双向对比的时间轴 (Dual-Timeline)** 或 **看板 (Kanban)**。
* **核心功能**：
* **历史报告库**：像邮件客户端一样，左侧是日期列表，右侧是当日的盘前/盘后长文报告，支持全文检索。
* **复盘沉淀区**：分屏展示。左边是“AI 当初的建议”，右边是“用户的实际操作”。
* **认知记忆 (Memory)**：用高亮便签的形式展示从复盘中提取的“经验教训”（例如：*“警告：在下跌趋势中过早抄底”*），并在标签上标明是否已写入向量数据库。



#### 5. 系统配置中心 (Settings)

将琐碎的参数配置表单化。

* **模型参数设置**：滑动条 (Sliders) 控制 `Temperature`，下拉菜单切换底层大模型（如 DeepSeek、GPT-4o），提供 API Key 的安全输入框。
* **定时任务调度 (Cron Jobs)**：
* 提供可视化的时间选择器。例如：勾选“工作日 08:30 执行盘前推演”、“工作日 15:30 执行盘后总结”、“周六 10:00 执行深度复盘”。


* **用户档案 (Profile)**：管理登录凭证，配置个人的“风险偏好级别”（激进/稳健/保守），该级别将直接影响 AI 计算买入数量时的仓位系数。

### 三、 交互动效与细节加分项

1. **抽屉式 K 线图**：在任何聊天界面或持仓表格中，点击股票代码，不需要跳转页面，从右侧滑出一个抽屉 (Drawer) 显示 TradingView 风格的轻量级 K 线，看完即关，不打断主流程。
2. **状态流转加载 (Skeleton & Stepper)**：AI 运行复杂分析或回测时，界面不要只给一个转圈的 loading，而是采用步骤条（如：*1. 正在拉取 20 天数据... -> 2. 正在调用双均线策略... -> 3. 模型生成结论中...*），缓解用户的等待焦虑。
3. **快捷执行卡片 (Actionable Cards)**：历史建议不能只是文字。如果 AI 建议买入，卡片底部必须带一个明显的 `[确认生成记录]` 或 `[修改买入数量]` 的交互按钮，点击后数据直接落入 Supabase。

这套 UI 架构将复杂的量化配置隐藏在后台菜单中，而将最核心的“决策与复盘”放在了极其直观的聊天与卡片流中。
