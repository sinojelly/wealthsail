# Codex 统一模型与 NAS 认证实施计划及任务清单

## 已确认范围

用户要求即时聊天、常规报告、每日研究全部统一走 Codex，不保留 `MODEL_API_KEY` 调用通道。部署使用现有独立 PostgreSQL、空库管理员/租户和 Cloudflare Access 方案；本机没有 Docker，实际登录和模型请求由用户在 NAS 验收。

设计与完整操作：[32.Codex统一模型与NAS认证操作指南](../docs/32.Codex统一模型与NAS认证操作指南.md)。按顺序执行的部署入口：[external-access/DEPLOYMENT.md](../external-access/DEPLOYMENT.md)。此前 50/51 的数据库和外网接入方案继续适用，模型运行时以本次补充为准。

## 实施顺序与完成条件

- [x] 盘点模型入口：ChatService、报告 Model Gateway、每日公共研究；区分模型分析与既有确定性财务计算/模板报告。
- [x] 保持前端 SSE `delta`/`done`、聊天权限和历史、报告校验接口；删除运行时旧 provider HTTP 调用与重试，旧 `MODEL_*` 设置仅作过期配置兼容。
- [x] 新增 Codex Client，API/Worker 统一通过内部 Runner 调用；本机路径必须显式配置，避免测试或旧 API key 意外触发真实模型。
- [x] 新增 Codex Runner：独立内部令牌、模型白名单、并发/队列和请求/响应大小限制、无认证内容的错误响应；无公网端口、无数据库/会话密钥。
- [x] 私人聊天使用 app-server 的真实文本增量；私人报告使用独立临时目录、无工具和搜索的 Codex 执行。输入走 stdin，结果按业务 JSON 校验，不输出工具/推理事件或子进程 stderr。
- [x] 贯通浏览器断连、ASGI 发送失败、HTTP 流取消和本机 Codex 子进程清理；释放 Runner 并发槽。
- [x] 每日研究保留公共输入、联网搜索、数据库唯一名额和持久化状态；请求超时或已发送后连接中断标为 `UNCERTAIN`，不自动重试。
- [x] 后端镜像安装固定版 Linux 原生 CLI，支持 x86_64/arm64、检查 ELF 和版本；Node/npm 仅存在于构建阶段，运行用户 UID/GID 10001。
- [x] Compose 新增常驻 `codex-runner` 与一次性 `codex-auth`；可写认证卷仅给这两个服务，API/Worker 使用专门网络和内部令牌，与 StudyOS 认证卷分离。
- [x] 新装生成四份私密配置；旧三文件安装使用增量配置工具，保留数据库口令、Web 身份密钥，拒绝不一致的已有 Runner 参数。
- [x] 增加不发模型请求的 CLI/登录/功能预检，以及仅向空认证卷导入 ChatGPT `auth.json` 的备用工具；拒绝覆盖和 API key 文件。
- [x] 更新 NAS/外网部署顺序、设备登录、模型参数、每日开关、更新/备份/排错文档，并保留用户自行填写的 NAS 路径。
- [x] 扩大 Git/镜像忽略规则，排除 Codex 认证目录和 `auth.json`；不创建、读取或提交真实凭据。
- [ ] NAS 构建固定版本镜像，验证真实 CLI 功能、设备登录及无模型预检。
- [ ] NAS 验收聊天逐段输出、断连释放、常规报告、租户权限和容器重启后的认证保留。
- [ ] 验收后按需同时开启 API/Worker 每日研究，再以一次实际执行验证名额和产物；不重复消耗名额进行诊断。

## 验证记录

本次自动测试使用 Mock CLI/HTTP/App Server，不调用真实模型、不读取个人认证；临时配置只写入测试临时目录。已覆盖：

- 仅旧模型 key 不能启用模型，聊天和报告统一路由到 Codex。
- Runner Bearer 认证、模型限制、大小/并发/队列限制与环境变量过滤。
- 真实 ASGI `http.disconnect`、发送失败与异步关闭取消点；HTTP 流和 CLI 子进程清理。
- App Server 事件匹配、真实 delta、完成/失败、JSON 解析和输出上限。
- 每日研究的远程调用、唯一名额、未知结果处理与无重试。
- 新装/增量配置的密钥分离、拒绝覆盖、幂等；认证导入权限/重复字段/非法输入与预检脱敏。

本机最终验证：后端全量 **3360 passed / 142 skipped**（6 项既有 jose 弃用警告）；前端 **355 passed**。变更相关 Python Ruff 检查和 `git diff --check` 通过；7 份 Compose YAML 静态解析及认证卷/网络隔离断言通过；4 份 NAS/Codex/外网操作文档中的 **61 个 Bash 代码块**通过 `bash -n`，备用 Windows 导入 PowerShell 片段通过解析。文档门禁及本地链接检查通过。

其中跳过的数据库/外部能力测试仍需在对应环境执行。本机无 Docker，因此 YAML 静态解析和 Mock 测试不能代表固定版本镜像已经构建，也不能代表 NAS/Cloudflare/账号配额或实际流式性能已验收。
