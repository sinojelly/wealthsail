\## 二、发现的问题



\### P1：文章标题仍可能掩盖不相关行业的风险



位置： `backend/macro/industry\_cycle.py`，`\_industry\_scope\_verified()`



目前逻辑是：



1\. 引文包含目标行业关键词，返回 `True`。

2\. 引文包含其他已知行业关键词，返回 `False`。

3\. 引文未命中任何已知行业关键词，允许用文章标题证明归属。



第三步有一个漏洞。



示例：



| 字段   | 内容               |

| ---- | ---------------- |

| 核查行业 | `ROBOT`          |

| 文章标题 | 机器人产业投资观察        |

| 原文引句 | 近期造船行业融资规模下降30%  |

| 来源核验 | `SOURCE\_CHECKED` |

| 事件时间 | `RECENT`         |



由于当前行业词表没有“造船”，引文可能被视为“没有明确行业”，然后文章标题中的“机器人”使 `industryScopeVerified=True`。



这样，造船行业的融资下降就可能升级为机器人行业的 `CONFIRMED`，影响基金评分和买入区间。



建议： 原文出现明确的“某某行业/产业”主体，却无法匹配目标行业时，不允许用标题覆盖。只有“该行业”“本行业”等确实需要上下文才能消歧的引句，才考虑标题辅助匹配。



新增一个针对上述场景的回归测试即可，不需要重写整个词表。



\### P2：产业阶段及盈利证据还没有完整应用行业归属校验



位置： `industry\_cycle.py` 中的 `stage\_kinds`、`earnings\_pair` 和阶段判定。



这轮 `expected\_industries` 已用于五类行业风险的确认，但阶段证据仍然主要检查原文语义和时间。



例如核查机器人行业时，如果引用的是：



> 近期半导体行业仍处于试制验证阶段，尚未实现规模量产。



即使风险归属严格限制了半导体新闻，也可能因为该句满足商业化早期的语义规则，让机器人方向被标成 `EARLY\_COMMERCIALIZATION`。



同样，已经绑定企业及报告期的利润与回款，也没有再验证这些企业是否属于被研究的产业方向。



建议： 阶段及盈利证据也要有明确的适用对象。无法确认产业关联时，保持 `UNKNOWN`，但不要自动否定已经核实的公司级财务事实。
