## 3. 全局约束

1. 模块化单体扩展；复用账户、权限、自选、调度和审计，不建设第二套 Web/Streamlit 产品。
2. 指标和评分采用确定性计算；大模型不能生成数值、补行情或决定仓位。
3. 评分是技术状态，不是上涨概率、胜率或收益承诺；首版不生成买卖执行指令，不自动下单。
4. API 不同步访问行情供应商；共享研究数据与租户自选、任务状态分开控制权限。
5. 未采集、缺失、过期、冲突、来源不可用明确区分；未知数值为 `null`，不能补零或随机数。
6. 场内 ETF 价格、指数价格、场外净值分别保存口径；累计净值不是严格的分红再投资总回报序列。
7. 排名明确候选池范围、批次和覆盖率，未验证全市场覆盖前禁止称为“全市场机会排行榜”。
8. 数据和参数带来源、日期、版本；不同市场使用自己的交易日历。界面时间按 `Asia/Shanghai` 展示。
9. 新迁移顺序追加，不改已执行迁移的内容；以下 069—072 是计划编号，实施时按实际最大编号顺延。

## 4. 页面与交互设计

### 4.1 页面结构

沿用“基金筛选”菜单和路由，页面自上而下：

1. **研究覆盖条：** 候选总数、已采集数、可完整评分数、最新批次和数据截止日期。主数据覆盖与分析覆盖分别显示。
2. **筛选区：** 关键词、基金类型、ETF/场外基金、资产方向、跟踪指数；展开后显示历史长度、净值位置区间、技术状态、数据质量。快捷入口只填入对应筛选条件。
3. **结果区：** 分页表格、排序、已选条件与清空按钮；提供“全部候选”和“可评分 ETF”两种视图。
4. **单基金诊断：** 点击一行打开侧栏，窄屏使用全屏面板；展示结论、图表、指标、分项评分、数据依据及自选/更新操作。

首屏默认“全部候选”，按名称升序；每页 20 条，可选 50 条，上限 100 条。切换“可评分 ETF”后默认技术评分降序。搜索与过滤同时生效，不再互相清空。

### 4.2 字段与状态

基础列表显示：代码/名称、交易形态、类型/方向、跟踪指数、最新价格或净值及日期、历史净值区间位置、技术状态、技术评分、数据质量、操作。收益和波动率作为可展开指标，避免表格过宽。

- `undervalued` 快捷入口改为“净值区间偏低”，保持原有 `<30` 规则；`near_high` 为“净值区间偏高”，保持 `>70` 规则。它们不是估值结论。
- `currentPercentile` 的新名称是 `navRangePosition`；展示示例“区间位置 72.50% · 区间偏高”，附公式说明。
- `drawdownFromHigh` 展示“距区间高点跌幅”；不能当作历史最大回撤。后续滚动最大回撤必须另算。
- 历史不足展示“历史不足”，无 OHLC 展示“不支持完整评分”，过期展示“数据待更新”；仍可查看有效历史指标。
- 空结果、请求失败、加载中、任务失败分别提供可理解的提示；任务失败时保留上次有效数据并标记过期。
- URL 仅保存筛选和排序，不保存租户任务 ID；点击自选后同步已有自选缓存，不能把共享评分绑定到某个用户。

诊断首版回答“技术趋势如何、哪些条件满足、有哪些数据限制”。长期配置价值和个性化可用资金在尚无模型时显示“尚未评估”，不得从技术分数推导。

## 5. 数据、指标与 API 契约

### 5.1 标的关系与分析池

新增 `reference.research_indices`（指数 ID、市场、供应商代码、名称、币种、日历、来源）和 `reference.fund_research_profiles`（`instrument_id`、基金代码、交易形态、资产方向、份额组、成立日期及来源）。新增 `reference.fund_index_links` 保存基金与指数的基准/跟踪关系、ETF 联接目标、生效区间和来源。

基金主数据以 `(市场, 代码)` 映射 `instrument_id`，六位代码不能单独作为跨市场身份。A/C 份额保留独立基金，可归同一 `share_class_group`；联接基金不能合并为 ETF。无来源的方向和指数关系保持未知，不按名字猜出已确认标签。

新增 `reference.fund_research_universe`（基金标的、纳入状态、采集优先级、池版本、生效区间），独立于用户持仓和搜索缓存。首批配置中国宽基、成长、红利、美国权益、港股、债券、黄金七个方向的研究对象；每个方向是否可展示排名取决于实际采集覆盖。M1 可先从现有 fund_master 返回基本信息，分析字段允许为空。

### 5.2 历史数据与快照

| 新表 | 核心字段/约束 |
| --- | --- |
| `market.research_daily_bars` | subject_type=INSTRUMENT/INDEX、subject_id、trade_date、series_kind、adjustment、open/high/low/close、volume/amount、source_id、source_snapshot_id、available_at、retrieved_at、revision、quality_status；唯一键含标的、日期、序列口径、来源、修订；按标的/口径/日期索引 |
| `market.fund_analysis_batches` | batch_id、universe_version、as_of、expected_count、success_count、failed_count、status=RUNNING/COMPLETED/FAILED、发布时间；发布批次以事务切换，不让列表混用未完成批次 |
| `market.fund_analysis_snapshots` | batch_id、instrument_id、input_hash、algorithm_version、parameter_version、参数 JSON、历史起止/样本数、数据状态、指标 JSON、score、score_state、reason_items、source_snapshot_ids；唯一键 batch_id+instrument_id |

日线保留修订和输入 hash；快照引用的具体输入版本可重新加载，不能只存 hash 后覆盖历史事实。供应商未提供真实披露时间时，以首次获取时间作为保守 `available_at` 并记录该限制。后续回测另行验证历史可得性，本期不能宣称具备无前视偏差回测能力。

ETF/指数采集复权 OHLCV，保留原始价格供成交/折溢价扩展使用；成交量不按价格复权因子缩放。场外基金采用经核验的收益/复权净值序列计算动量；只有累计净值时只显示相应净值走势和区间事实，不冒充总回报指标。

历史初次目标至少 260 个本市场交易日，此后增量更新并重取最近 7 个日历日校验修订；新基金保留实际长度。停牌和缺失不前向填充成虚假日线。缺失交易日、无法核实口径或坏 OHLC 标记质量问题并阻止完整评分。

分析新鲜度单独判定：ETF/指数取本市场已收盘且已到数据发布窗口的最近交易日，场外基金取该来源已到披露窗口的最近净值日；晚于最新有效数据日则为 STALE。发布窗口配置必须来自任务 0 的来源核验；未知窗口为 UNVERIFIED，不进入评分榜。不能把“历史记录日期早于今天”一律认定为坏数据，也不能在周末因无新行情把周五有效快照判过期。历史每条质量与整份分析的新鲜度分别输出。

### 5.3 指标与技术评分 v1

以下是为使实现可复现而提出的首版参数，属于研究假设，并非已经回测验证：

- MA20/60/200：收盘价简单平均；样本不足输出 `null`。
- MACD(12,26,9)：EMA 初值为首个有效收盘价，`alpha=2/(n+1)`；DIF=EMA12−EMA26，DEA=EMA9(DIF)，柱值=2×(DIF−DEA)。
- KDJ(9,3,3)：RSV 基于 9 日真实 high/low，K/D 初值 50，平滑系数 1/3，J=3K−2D；最高=最低时 RSV=50。
- RSI14：Wilder 平滑，初值取前 14 个涨跌幅的均值；仅上涨为 100、仅下跌为 0、完全不变为 50。
- ATR14：真实 OHLC 的 TR 使用前收盘价，Wilder 平滑；只有净值时为“不适用”。
- 63 日动量：`close[t]/close[t-63]−1`；20 日波动率：最近 20 个日收益样本标准差（ddof=1）×√252。跨境不同日历和汇率影响在诊断注明，不直接合成跨资产总榜。
- 满足至少 200 条完整、有效本市场交易日 OHLC，且评分所需当日/前日指标齐备，才给完整 ETF 分数；MACD 柱改善必须有前一日值。

| 得分项 | 确定条件 | 分值 |
| --- | --- | --- |
| 长期价格趋势 | close > MA200 | 25 |
| 中期趋势 | MA60 > MA200 | 15 |
| 短中期趋势 | MA20 > MA60 | 10 |
| 中期动量 | 63 日收益 > 0 | 15 |
| MACD 趋势 | DIF > DEA | 10 |
| MACD 动量改善 | 本日柱值 > 前日柱值 | 5 |
| KDJ 支持 | K>D 且 20≤K≤80 | 10 |
| RSI 区间 | 40≤RSI14≤70 | 10 |

75—100 为“趋势较强”，55—74 为“信号不一致”，0—54 为“趋势偏弱”。每项输出 `key/value/threshold/passed/points/reason`。缺失、过期、冲突时 `score=null`、`score_state` 为 `INSUFFICIENT/STALE/CONFLICT/UNSUPPORTED`，不将剩余项重新归一化为 100 分。场外基金可展示可用指标，但不能用指数 KDJ 冒充本基金指标。

评分榜按投资方向/同类研究池比较；综合经济、估值和基金质量的 100 分模型留到后续，其权重不与技术分数混用。缺失值最后排序，同分按市场和基金代码稳定排序。

### 5.4 新接口

继续使用项目 `/api/v1` 前缀、认证与 `ok(...)` 响应封装。下表列出封装中的 data：

| 接口 | 输入 | data 输出 |
| --- | --- | --- |
| GET `/funds/screener/options` | 无 | 类型、方向、指数、支持排序字段、candidateCount、collectedCount、scorableCount、覆盖截止日期 |
| GET `/funds/screener` | keyword、fundType、tradeForm、direction、indexId、minHistoryDays、navPositionMin/Max、technicalState、dataState、scorableOnly、sortBy、sortOrder、page、pageSize、batchId | items、total、page、pageSize、batchId、universeVersion、coverage、asOf |
| GET `/funds/instruments/{instrument_id}/analysis` | 可选 batchId | identity、range、indicators、score、scoreState、reasonItems、quality、provenance、latestRefresh；无快照为 NOT_COLLECTED |
| GET `/funds/instruments/{instrument_id}/history` | window=1y/3y、seriesKind | 有序 points、unit、adjustment、quality、来源；不支持的序列返回明确状态 |
| POST `/funds/instruments/{instrument_id}/analysis-refresh` | 无 | HTTP 202；runId、created、status=QUEUED |
| GET `/funds/analysis-refresh/{run_id}` | 无 | status=QUEUED/RUNNING/COMPLETED/FAILED、errorCode、completedAt；仅当前租户可读 |

`FundScreenItem` 明确定义：instrumentId 为 string|null；market、fundCode、fundName、fundType 为 string；tradeForm、direction、indexId 为 string|null；navRangePosition、latestValue、technicalScore 为 number|null；latestDate、unit、technicalState 为 string|null；historyDays 为 number；dataState 为 NOT_COLLECTED/READY/INSUFFICIENT/STALE/CONFLICT/UNAVAILABLE/UNVERIFIED。scoreState 另含 UNSUPPORTED，避免把“不适用指标”和“数据获取失败”混成同一状态。主数据尚未映射标的时禁止诊断更新和加入自选，给出“研究资料待登记”。

筛选条件 AND 组合；区间条件为包含上下界，空值不命中数值条件；`navPositionMin>Max`、page<1、pageSize>100、非法枚举返回 422；排序字段白名单，禁止拼接用户 SQL。高级筛选新接口不自动入队。排序分页全在数据库执行，不能先取 20 条再在浏览器筛选。

翻页固定首个响应的 batchId，条件改变重置页码和批次；删除或过期批次返回明确的批次失效状态，前端重新从第一页查询。筛选统计与列表采用同一池、同一批次定义。

自选复用 `/watchlist` 及已有前端 API，携带已核验的 name、assetType=ETF/FUND、market、currency；失败回滚按钮状态。任务入队复用 `workflow.job_runs`，新增 FUND_ANALYSIS_REFRESH 类型及受控入队函数；同一租户/标的在运行中请求去重，共享计算按标的/输入版本复用。禁止读到其他租户的 runId 状态。
