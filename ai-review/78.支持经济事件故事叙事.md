可以，而且我认为这应该成为 WealthSail 一个非常重要的功能：让用户通过每天发生的真实事件，逐渐理解世界经济是怎样运行的。



现在 WealthSail 更像是写给专业投资研究员的报告，但普通用户真正想知道的是：



> 今天世界发生了什么？为什么会发生？谁受益、谁受损？股票、汇率、黄金、石油为什么会受到影响？这件事对未来几个月意味着什么？



这些问题本来就在 AI 投研过程中分析了，只是没有以普通人容易理解的形式展示出来。



\## 一、当前代码其实已经有不少所需信息



我检查了最新的 `MacroContextStrip.tsx`、`DailyResearchReport.tsx` 和 `daily\_research.py`。



目前 AI 已经输出：



| 现有字段         | 已有内容           | 用户阅读问题      |

| ------------ | -------------- | ----------- |

| `events`     | 重大事件、标题、摘要、重要性 | 没有形成连贯故事    |

| `channels`   | 经济影响传导渠道       | 过于抽象        |

| `scenarios`  | 可能的后续发展及影响     | 没有用通俗语言解释   |

| `sources`    | 原始新闻链接、日期、引文   | 缺少明显的新闻来源展示 |

| `watchFor`   | 未来需要关注的变化      | 没有与事件形成阅读闭环 |

| `macroCycle` | 宏观经济判断         | 数字与技术术语堆积   |



前端 `MacroContextStrip.tsx` 目前直接把 `macroCycle` 当作一整段文字展示，再附上 PMI、M1−M2、国债收益率等数字。



所以首先不是缺乏 AI 分析能力，而是缺乏面向普通用户的“经济新闻叙事层”。



\## 二、我建议重新设计「今日信息总览」



建议默认展示如下内容。下面是版式示意，不代表今天已经发生了这些新闻。



\## 今日世界与经济观察



读懂全球大事、资本市场和背后的经济规律



设计示意



今日最值得关注的事件



国际局势



假设性事件示例



\### 地缘冲突升级，为什么全球投资者同时关注石油、黄金和股市？



假设某重要石油运输区域发生军事冲突升级，投资者可能担心能源供应中断。即使石油尚未减产，市场也可能提前反映供应风险。



它可能怎样影响经济？



石油供应中断的担忧增加



油价可能上涨，运输和制造成本上升



企业利润、通胀预期及利率路径受到影响



资本市场可能怎样反应？



黄金可能受避险需求支撑，航空运输企业可能承受燃油成本压力，能源生产商则可能受益。但实际走势还取决于美元、利率和冲突持续时间。



经济小课堂：为什么战争不一定导致所有股票下跌？因为它改变的是不同产业的成本、需求与风险，而不是简单地让所有企业变差。



真实页面应在此展示事件来源、发生时间、实际市场数据与核验状态；没有价格证据时不得声称市场已经涨跌。



产业与就业



如果机器人企业接连倒闭，意味着什么？



学习融资退潮、现金流与行业出清之间的关系。



主题示例，非已核实行业事实



货币与政策



为什么降息有时也无法推动经济复苏？



理解银行信用、企业投资意愿和资产价格。



经济机制学习主题



这类内容的特点是：先讲事件，再讲经济逻辑，最后才展示数据。



用户不需要先理解 M1、M2 或实际收益率，就能知道为什么这些数字值得关注。



\## 三、我建议「今日信息总览」分成四个区域



| 区域        | 内容                          | 默认形式        |

| --------- | --------------------------- | ----------- |

| 今日世界发生了什么 | 战争、政策、全球市场动荡、企业倒闭、裁员、重大产业突破 | 5–8 条新闻故事卡  |

| 资本市场发生了什么 | 主要股市、汇市、黄金、原油、债券的实际变化       | 简洁市场动态，支持展开 |

| 事件如何影响经济  | 从事件到企业、通胀、利率、资产价格的传导        | 图解与通俗解释     |

| 经济知识小课堂   | 从当天真实事件提炼一个经济规律             | 每天一个知识点     |



目前的「历史宏观研判」不必删除，但应该移到下方「专业宏观分析」中，默认折叠。



另一个重点是不只报道利好、不只报道与基金相关的消息。国际政治、全球金融风险、产业倒闭潮、失业、贸易制裁、供应链变化，即使暂时没有对应基金，也值得讲给用户听。



不过要确保有足够的可靠新闻覆盖。当前系统的 24 条研究来源上限和投资机会优先排序，未必足以完整覆盖所有全球大事。没有采集到的事件不能由 AI 自行补造，也不能把多家公司的经营困难直接概括为整个行业的“倒闭潮”。



\## 四、是否会增加 AI Token？可以控制得很低



我不建议为了新闻故事再调用一次 Codex。



建议采用同一次研究输出，同时生成两套阅读视图：



一次 Codex 研究



已核验事件、来源、经济传导和投资方向



普通用户阅读版



新闻故事、市场影响、经济知识与后续观察



专业投研版



行业风险、来源核查、宏观指标、基金价格与评分



成本控制上，优先复用现有 `events` 的标题、摘要、影响渠道、情景和来源，由前端完成事件卡片排版。只有现有数据无法表达的部分，才增加简短的 AI 叙事字段，例如：



\- `whatHappened`：通俗地说明发生了什么。

\- `economicMechanism`：为什么可能影响经济。

\- `learningPoint`：用户可以从中理解什么经济规律。



每条控制在较短篇幅，不要求 AI 再写一篇长报告。首页先呈现重点，展开后读取已经保存的详情。



这样会增加少量结构化输出，但不需要第二轮模型推理。具体增加多少 Token，仍应通过固定冻结样本的输出对照测试确认。



还需要一个重要保护：事实、市场实际反应、经济传导推测必须分开。 例如当前源码将事件的 `marketReaction` 固定为 `UNVERIFIED`；要展示“黄金上涨 2% 是战争导致的”，必须先有对应时点的可靠价格数据，并且不能仅凭时间先后就断言因果。汇率和全球市场数据若当前没有可信采集源，应显示缺口而不是编造走势。



\## 五、还有一个容易忽视的问题：今天的新闻不能是昨天的报告



你之前看到的标题是「历史宏观研判」，这表示页面可能正在展示上一份有效报告。



新的新闻总览应清楚区分：



\- 今天实际已更新的新闻；

\- 昨天或更早的历史研究；

\- 持续发酵、今天有新进展的事件；

\- 目前只有线索、尚未核实的消息。



如果今日 AI 业务失败，也可以保留已经独立核验的新闻事实，但不能悄悄把旧报告改成「今日最新」。这样用户既不会因为投资校验错误看不到新闻，也不会误把历史分析当成今天的市场结论。



\## 六、给 Codex 的实现任务



请针对 WealthSail 的「今日投资观察 / 今日信息总览」设计并实现面向普通用户的“世界大事与经济故事”阅读体验。



\*\*核心目标：\*\*



让普通用户每天打开 WealthSail，就能了解：



1\. 今天国内外发生了什么重要事件，包括战争与地缘冲突、股市和汇市动荡、黄金原油变化、经济政策、产业衰退、企业倒闭、裁员潮和重大科技产业事件。

2\. 事件为什么值得关注，背后的经济运行规律是什么。

3\. 事件如何通过能源价格、企业成本、消费、就业、融资、通胀、利率和资金流动影响资本市场。

4\. 哪些影响已经发生，哪些只是条件性推演，未来应观察哪些信号。



\*\*一、先复用现有数据，不增加独立 AI 调用。\*\*



检查 `daily\_research.py` 的 `events`、`sources`、`channels`、`scenarios`、`watchFor`、`unknowns`、`macroCycle`，以及 `MacroContextStrip.tsx`、`DailyResearchReport.tsx`。



优先使用现有 AI 研究成果生成故事卡片和专业研究视图，不为新闻叙事再调用一次 Codex。



确实需要新字段时，采用少量短文本字段，例如 `whatHappened`、`economicMechanism`、`learningPoint`；避免重复生成现有来源和分析文本。



\*\*二、重做今日信息总览的层级。\*\*



默认展示：



\- 今日世界与国内重点事件，5至8条易读新闻卡片；

\- 股市、汇市、黄金、原油等主要资产的实际变化，仅显示真实采集并核验的数据；

\- 重点事件背后的经济传导机制；

\- 每日一个经济知识点。



每条新闻至少包含通俗标题、发生了什么、事件时间、来源、为什么重要、可能影响什么、已验证的市场反应、后续观察点。



提供国际局势、国内经济、金融市场、产业与就业、科技等分类。新闻可展开详细机制、情景及来源证据。



原来的宏观指标、行业风险审核和专业宏观总纲保留，但放到“专业分析 / 市场证据”，默认不让长篇指标文字占据首页。



\*\*三、必须保证事实与推演清晰分离。\*\*



新闻原文已核验，不代表经济传导因果已证实。市场变动需要独立的价格与时间证据。



严格区分事件已发生、媒体报道、机构观点、计划中的事项、预测情景。



战争与金融风险不要使用煽动式标题；企业裁员、倒闭不能由个别案例直接推断为整个产业倒闭潮。



无法核实的消息展示“待核实”；无法获取市场反应数据时展示“尚无可靠数据”，不得编造幅度或因果关系。



\*\*四、支持新闻学习与故事化表达。\*\*



把专业术语翻译成普通人能理解的语言。采用“发生了什么 → 为什么重要 → 经济如何传导 → 谁可能受益/受损 → 未来观察什么”的结构。



每日知识点应从真实事件的经济机制中提炼，不要泛泛生成毫无关系的经济学介绍。标记哪些是通用机制、哪些是对本次事件的分析。



\*\*五、历史与部分失败场景。\*\*



今日研究未成功时，不能把上一期研究伪装成今天的新新闻。



已独立核验的新闻事实可以只读展示，未通过投资校验的方向不能产生投资操作资格。



支持事件时间线、同一事件新进展去重、历史报告时间标识；来源不可用或新信息不足时必须明示。



\*\*六、成本和兼容性。\*\*



尽量不扩大现有模型调用次数，不重复五类行业负面核查，不重复输出大段行业风险文本。



先统计旧版与新版 Prompt 字节数、Schema 大小、模型输出估算字数、来源数和事件数。固定样本离线验证成本增量。



严格验收、投资评分、来源校验、基金风险和价格保护必须保持原逻辑。面向普通用户的新闻展示不得作为新的买入信号。



补充前端交互、移动端响应式、来源跳转、空数据、历史数据、部分成功及跨行业事件的回归测试。



注意：当前本地工作树还有其他尚未提交的成本优化改动。先检查 Git 状态，不覆盖、不重置、不混入那些无关修改。仅本地实现、测试、提交，不推送、不部署、不运行真实 Codex 研究。



完成后提供页面变化说明、样例布局、测试结果及实际预计新增的模型输出负担。\\`



\## 我的建议



我会把这项功能的优先级放得很高，因为它能让 WealthSail 从“基金分析工具”逐渐变成一个真正帮助用户理解世界、理解经济、理解投资的产品。



最重要的不是让 AI 多写文章，而是把它已经分析出的信息讲清楚。



以后用户打开「今日信息总览」，首先看到的应该是：



今天发生了什么 → 为什么会影响经济 → 市场已经如何反应 → 未来可能怎样发展。



至于 PMI、M1−M2、收益率、基金买卖点，应该成为支持这些故事的证据，而不是普通用户每天首先面对的一大段技术报告。
