\### 一、 深度诊断：为什么算出的买区这么高？为什么没有卖出提示？



我们直接把截图中 `华夏中证银行ETF联接A (008298)` 的数据代入 `actionable\_zones.py` 的源码（第 125–183 行）进行反推，真相一目了然：



\#### 1. 买区设计缺陷：「短期均线追高效应」把买入区间拽到了山顶



\* \*\*反推当前计算过程\*\*：

截图中建议买入区间为 `1.7151–1.7320`，源码公式为 $\\text{下沿} = \\text{MA20} - 0.55 \\times \\text{scale}$，$\\text{上沿} = \\text{MA20} + 0.25 \\times \\text{scale}$。

由此反推出：当前波动尺度 $\\text{scale} = (1.7320 - 1.7151) / 0.80 \\approx 0.0211$ 元，而 \*\*$\\text{MA20} \\approx 1.7267$ 元\*\*。





\* \*\*为什么这个设计是错的？\*\*

`MA20`（20日均线）是一个\*\*强跟随性的短期指标\*\*。当 `008298` 一路连涨到近 1 年 \*\*100% 分位\*\*、近 2 年 \*\*98.5% 分位\*\*（`1.7675` 元，逼近 2 年最高点 `1.7988` 元）时，`MA20` 也被硬生生拽到了 `1.7267` 元的山顶位置！





\* \*\*实战后果\*\*：在近两年的绝对山顶（98.5%分位），给用户推荐一个仅比现价低 2% 的“浅回踩买区（`1.7151–1.7320`）”毫无实战意义。看看右图 07-31 那次见顶（`1.7988` 元）：一旦高位见顶回落，净值会一路跌穿 `MA20`，直接杀到 `1.53 \~ 1.58` 元！如果在 `1.72` 买入，几天内就会被打穿 `1.6843` 的止损线。\*\*在极高位区，真正的合理买区绝不可能是 `MA20` 浅回踩，而应该是中期波段支撑位（如 `MA60` 或历史中枢平台 `1.56–1.61`）。\*\*







\#### 2. 卖区设计缺陷：止盈目标绑定了 `close + 2.5 \* scale`，“胡萝卜永远在驴前面跑”



你问了一个最核心的问题：\*\*“为什么当前处于 100% 分位的高价，却没有卖出区间提示？”\*\*

请看 `actionable\_zones.py` 第 151–158 行的止盈计算源码：



```python

first = max(

&#x20;   ma60 or maximum + 2 \* scale,

&#x20;   close + Decimal("2.5") \* scale,  # <--- 致命缺陷在这里！

&#x20;   maximum + 2 \* scale,

)

second = max(

&#x20;   \_number(values.get("bollUpper")) or first + scale,

&#x20;   close + Decimal("4.5") \* scale,  # <--- 致命缺陷在这里！

&#x20;   first + scale,

)



```



\* \*\*看出问题了吗？\*\* 代码在计算 `first`（止盈目标一）和 `second`（止盈目标二）时，直接用 \*\*当天最新净值 `close` 加上 `2.5 倍 / 4.5 倍波动率\*\*`：





\* 今天 `close = 1.7675`，算出的止盈目标一就是 $1.7675 + 2.5 \\times 0.0211 = 1.8205$；





\* 假如明天大涨到 `1.8205`，代码又会用明天的 `close (1.8205) + 2.5 \* scale`，把止盈目标一推高到 `1.8733`！





\* \*\*荒谬的结论\*\*：由于止盈目标永远等于 $\\text{今日净值} + 2.5 \\times \\text{scale}$，\*\*无论基金涨到多高（哪怕 100% 分位），止盈目标永远比当天净值高出一截，当天净值在数学上永远不可能进入止盈卖区！\*\* 这不仅让止盈目标失去了客观阻力位的意义，也导致右侧走势图上那条橙色虚线（`1.8205`）永远悬在历史最高点（`1.7988`）上方。

\### 二、 优化方案：围绕「什么价格该买、什么价格该卖」重构双区间算法



用户看这张卡片和走势图，核心诉求只有两个：\*\*① 跌到什么合理价格该买？② 涨到什么合理价格该卖（现在是不是已经到卖点了）？\*\*



为此，我们需要把原来的“追着 `MA20` 算买点、追着 `close` 算卖点”的漂移逻辑，重构为 \*\*「基于周期分位与中长期支撑/阻力的客观买卖双区间模型」\*\*：



\#### 1. 总是给出合理的「建议买入区间」（拒绝山顶浅回踩）



根据当前净值所处的历史分位（`navPercentile1y` / `navPercentile2y`），自动切换买区锚点：



\* \*\*场景 A：中低位或趋势初/中期（分位 `< 70%`）\*\*

趋势尚未透支，买区可围绕 `MA20` 与 `MA60` 构建，但\*\*强制增加安全上限\*\*：买区上沿不得超过近 1 年 \*\*60% 分位价\*\*。

\* 场景 B：中高位/山顶区（分位 $\\ge 70\\%$，如当前 `008298` 处于 98.5%\~100% 分位）

\*\*严禁再用 `MA20`（`1.7151–1.7320`）作为建议买入区间！\*\* 此时自动将买区锚点下移至 \*\*「中期均线 `MA60` 与近 1 年 35%\~50% 中枢分位支撑带」\*\*：







$$\\text{BuyZone}\_{\\text{合理低吸}} = \\left\[\\min(\\text{MA60} - 0.5\\times\\text{scale},\\; P\_{40\\%}),\\;\\; \\min(\\text{MA60} + 0.3\\times\\text{scale},\\; P\_{55\\%})\\right]$$





\* \*\*对 `008298` 的实际效果\*\*：在右侧走势图上，建议买入区间会从山顶的 `1.7151–1.7320` 下移到 \*\*`1.5650–1.6150`\*\*（正好对应图中 12月\~5月 多次验证的波段底部支撑平台）。











\#### 2. 总是给出客观的「建议卖出区间」并在到价时强提示



彻底删除 `close + 2.5 \* scale` 这种随现价逃跑的公式，改为基于 \*\*周期前高阻力位、分位极值与布林上轨\*\* 构建客观的 \*\*「建议卖出区间 (`sellZoneMin` – `sellZoneMax`)」\*\*：



\* \*\*卖出区间下沿（`sellZoneMin` / 止盈起售线）\*\*：

取 \*\*近 1\~2 年 85% 分位价格 ($P\_{85\\%}$)\*\* 与 \*\*合理买区上沿 + $2.5\\times\\text{scale}$\*\* 的较大值。对 `008298` 而言，大约在 \*\*`1.7350` 元\*\*。

\* \*\*卖出区间上沿（`sellZoneMax` / 阶段极值阻力）\*\*：

取 \*\*近 1\~2 年 98% 分位 / 周期前高 ($P\_{\\text{peak}} = 1.7988$)\*\* 与 \*\*布林带上轨 (`bollUpper`)\*\* 的客观阻力位。对 `008298` 而言，即 \*\*`1.7988` 元\*\*。





\* \*\*触发「已入卖出区间」强提示\*\*：

当最新净值 `1.7675` 落入建议卖出区间 \*\*`1.7350–1.7988`\*\* 内（或分位 $\\ge 85\\%$ 且 `RSI14 >= 65`）时，系统立刻判定 `inSellZone = True`！
