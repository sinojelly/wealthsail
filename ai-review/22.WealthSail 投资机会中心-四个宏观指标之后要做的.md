# WealthSail 投资机会中心：下一步应该补什么？

你的判断是对的：现在宏观数据模块已经比较完善，但离真正的基金投资决策系统还有一段关键距离。

我看了最新三张截图，也核对了 WealthSail 当前 `codex/investment-opportunities` 分支中的宏观研究代码。

首先纠正一个概念：截图里的 CPI、M2、PMI、PPI 是四个宏观经济指标，不是四个可以直接交易的指数。

现在系统已经能够做到：自动采集、官方事实核验、历史走势、参考线、历史分位、最近变化、关键事件，以及研究方向的关联入口。这些基础都值得保留。

但真正决定基金买卖时，还必须回答下面五个问题：

1\. 宏观环境

经济、通胀、利率和信用环境，正在怎样变化？

2\. 投资标的

哪些市场、行业或指数可能受益或承压？

3\. 估值与预期

这些利好或风险，是不是已经反映在价格里？

4\. 买卖时机

指数趋势、动量和预设策略条件是否支持行动？

5\. 个人组合风险

已经持有哪些资产、集中度有多高、还能承担多少风险？

最重要的结论是：不要期待再增加十几个宏观指标，就能自动知道该买什么基金。宏观决定研究方向，估值和盈利决定投资吸引力，趋势和策略负责时机，组合风控决定仓位。

## 一、现有界面还有哪些问题？

最新版的信息可靠性已经有明显提升，但我觉得有三处产品设计值得调整。

### 1. 宏观数据越来越详细，投资结论却没有同步进步

现在每张卡片有最新值、月变化、参考线、历史中位数、分位、发布时间、下一次发布、走势图和取值范围。

这些都是有用的证据，但它们不应该成为日常投资页面的主角。

用户真正关心的是：

> 这些数据相比之前，改变了我对 A股、债券、黄金或美股的研究判断吗？

因此建议继续保留完整的“宏观深度研究”，但默认收起详细统计，将变化解读、影响方向、未验证因素放在醒目的摘要区。

### 2. 「关键变化」现在是逐条罗列，不是重要性排序

截图中 CPI、M2、PMI、PPI 的变化几乎都以同等权重展示。

但 PMI 跨越 50、长期国债收益率明显变化、信用风险突然扩大、突发战争等事件，在不同环境下的重要程度可能完全不同。

建议引入事件与指标变化的优先级：区分普通更新、值得关注的变化和需要及时复核的风险，而不是让所有数据都争夺注意力。

### 3. 「沿影响渠道继续研究」不应该展示十几个同等重要的按钮

目前从 A股宽基、红利、成长，一直到港股、美股、债券、黄金，所有方向几乎平铺在一起。

建议默认只展示当前用户所选市场相关的方向，以及有可靠证据支持需要复核的方向；其他方向进入“全部研究方向”。

没有足够证据时，应该显示“待验证”，而不是为了凑出排行榜给每个方向打分。

## 二、最应该补充的宏观与市场指标

我最赞成你提出的“长期国债收益率”。它应当是下一阶段的重点。

目前 WealthSail 有 PMI、CPI、PPI 和 M2，但缺少两个直接影响资产定价的维度：市场实际利率和信用融资环境。

除此之外，还需要能反映市场预期、风险偏好和外部冲击的高频数据。

### 为什么国债收益率如此重要？

国债收益率可以同时帮助理解三类资产。

债券基金

当市场利率上升时，固定利率债券价格通常下降；久期越长，价格对利率变化通常越敏感。反之亦然。

股票指数基金

利率影响未来盈利的折现价值，也影响投资者在债券和股票之间的收益要求。但利率下降不一定意味着股市上涨：如果下降源于经济恶化，企业盈利也可能下降。

黄金与全球资产

美国实际利率、美元和避险需求是值得持续观察的因素。实际利率上升可能增加持有无息黄金的机会成本，但避险需求有时会产生相反力量。

因此我建议在宏观模块里新增一个“利率与信用”专题，包含中国国债收益率、美国国债收益率、实际利率、社融和资金价格。

尤其需要同时显示利率的当前水平、最近变化、变化速度和历史位置，而不是只看绝对数字。

## 四、战争、石油价格、A50 和全球新闻应该怎样使用？

这些信息很重要，但它们的主要作用是识别突发风险和判断传导渠道，不是直接产生确定的买卖信号。

| 事件或指标         | 应研究的传导路径              | 系统要避免的错误         |
| ------------- | --------------------- | ---------------- |
| 地缘冲突或战争       | 供应链、能源供给、避险、贸易、通胀、利率  | 看到战争就机械地买黄金、卖股票  |
| 国际油价暴涨        | 通胀压力、企业成本、能源企业盈利、利率预期 | 认定所有周期股都受益       |
| 美国长债收益率快速上行   | 美股估值、成长股折现率、全球资金成本    | 认定股市一定下跌         |
| 富时中国A50期货大幅波动 | 境外交易时段对中国大型股的价格反应     | 把A50期货当作整个A股的预测器 |
| 美股隔夜大跌        | 全球风险偏好、美元和跨市场关联       | 忽略A股独有的基本面和政策    |
| 重大政策发布        | 资金成本、产业利润、市场预期改变      | 只读标题，不检查政策细节和落实  |

一个突发事件通常会同时影响多种资产，而且方向可能相互抵消。

例如，能源供给受扰动时，油价可能上升，能源生产企业的盈利预期可能改善，但其他企业的能源成本也可能增加，通胀和利率预期可能变化。系统必须按资产类别和行业区分受益与承压渠道。

至于 A50，我查到 WealthSail 现有 `backend/integrations/market_data.py` 已有富时中国A50期货的行情获取与盘前快照逻辑。

因此这不是需要完全从零建设的新能力。可以把已有盘前行情经过统一数据质量检查后，复用到投资机会中心。

全球新闻、政策公告和经济专家分析则建议单独增加“关键事件与观点”数据层：官方事实优先核验，媒体事件做交叉确认，专家观点保留署名和时间。未经验证的预测不能进入确定性交易条件。

## 五、观察基金买卖机会，真正最需要什么信息？

我建议按照买卖决策的重要性来排列，而不是按照宏观数据数量来排列。

| 决策层       | 需要的信息                    | 主要回答            |
| --------- | ------------------------ | --------------- |
| 1. 资产价值   | 指数估值、盈利趋势、资产收益率、风险溢价     | 值得长期研究和配置吗？     |
| 2. 价格趋势   | MA60/MA200、动量、MACD、回撤、波动 | 当前趋势是否支持进入或持有？  |
| 3. 宏观环境   | 增长、通胀、信用、利率、政策           | 有哪些支持因素或逆风？     |
| 4. 市场风险   | 波动、流动性、风险事件、市场宽度         | 是否正在进入高风险状态？    |
| 5. 基金产品质量 | 费用、跟踪误差、规模、折溢价、交易规则      | 哪只基金是更合适的工具？    |
| 6. 持仓与仓位  | 已有敞口、相关性、现金、风险预算         | 是否应该增加、减少或保持仓位？ |

注意：这个表是决策检查顺序，不代表经过实证验证的固定指标权重。不同基金和投资期限应有不同模型。

其中，技术指标不一定只用 MACD/KDJ。我反而建议先把长期趋势、波动、最大回撤和重要趋势变化做好，再把 MACD、KDJ 作为辅助观察。

### 例如，如何真正形成买入候选信号？

示例：研究沪深300 ETF，以下全部为规则设计，不代表当前真实信号

第一关：长期价值

指数的估值与盈利风险是否有足够可靠的数据支持？

第二关：趋势确认

例如观察价格与MA200的关系、中期均线、动量及回撤变化。

第三关：宏观和事件风险

信用或利率是否发生不利变化？是否存在重大未消化事件？

第四关：基金和个人风险

费用、跟踪、折溢价是否合理？现有持仓是否已经集中在相同风险上？

输出：研究状态与下一步

条件满足 → 进入可考虑建仓的候选清单；条件不足 → 等待；已持仓且风险规则触发 → 提醒复核减仓或再平衡。

所有阈值须先进行历史和样本外验证，扣除交易成本，并按基金交易机制设定。不能把规则满足当作获利保证。

这套设计还需要区别“已经持有”和“尚未持有”两种状态。

同一个市场环境，对未持仓用户可能意味着等待；对已持仓用户可能意味着继续持有或减少集中风险。单靠市场数据，无法对两者输出相同的买卖结论。

### 一个重要设计：日常研究应按时间尺度分层

| 时间尺度    | 看什么                    | 用来做什么            |
| ------- | ---------------------- | ---------------- |
| 盘前、盘中   | A50期货、海外市场、油价、汇率、重大事件  | 发现突发风险，不单独作为交易依据 |
| 每日盘后    | 指数价格趋势、波动、基金折溢价与信号变化   | 筛选机会、复核风控        |
| 每月经济公布后 | PMI、信用、CPI、PPI、政策与利率趋势 | 调整中期经济情景         |
| 每季度     | 企业盈利、估值、行业盈利趋势         | 判断长期投资价值         |
| 按持仓变化   | 组合集中度、风险预算和再平衡偏离       | 决定个人账户是否需要调整     |

这样就不会用一个月才更新一次的 PMI，去指导每天甚至盘中的买卖操作。

## 七、结合 WealthSail 现有代码，我会怎样实施？

我特别检查了 `backend/macro/research.py`。

目前它已经有一个不错的确定性分析框架：把宏观观察组织为增长、通胀、流动性、市场风险，并在 `direction_research()` 中关联 A股宽基、周期、成长、债券和黄金。

但现在的关联主要是解释性的：告诉用户某类数据可能影响什么，还不是能够验证某个投资方向是否具有优势的研究模型。

例如，代码虽然把国债收益率、政策利率、信用利差等列为“待检查”，但这不等于已经实现这些行情的完整采集、历史计算和方向分析。

我建议分三期推进：

| 阶段          | 核心开发内容                                  | 用户实际获得什么              |
| ----------- | --------------------------------------- | --------------------- |
| 第一期：补关键变量   | 中国/美国国债收益率、社融与利率、主要指数行情、估值及波动风险         | 能看清经济与市场风险，而不只是四项经济数据 |
| 第二期：研究方向联动  | 按A股、美股、债券、黄金调用不同的指标模型；形成有证据的支持、反方和待验证条件 | 知道哪些方向值得进一步研究，以及为什么   |
| 第三期：策略与持仓闭环 | 趋势验证、基金质量、历史回测、组合风险、条件变化提醒              | 能区分等待、考虑建仓、继续持有和风险复核  |

数据层可优先利用央行、国家统计局、中债、中国外汇交易中心、美国财政部、EIA和交易所的可用官方数据，再以可靠市场数据源补充价格和交易指标。正式自动采集前需要核查获取方式、时间戳、历史修订及使用许可。

对于美国市场风险，VIX 可以作为补充指标，但它衡量的是标普500期权价格隐含的未来约30天预期波动，并不是股市涨跌方向预测。

## 八、最终建议：下一步优先级应该改变

现阶段已经没有必要继续在 CPI、M2、PMI、PPI 四张图上增加更多文字。

我认为 WealthSail 下一阶段最有价值的开发重点，依次是：国债收益率与信用、主要指数的估值和趋势、市场风险、基金产品质量与个人持仓风险。

尤其是长期国债收益率、实际利率和指数估值/趋势，值得尽早接入，因为它们能把“经济发生了变化”和“资产是否具有吸引力”真正连接起来。

新闻、战争、油价、政策和A50也应该引入，但作为事件与风险研究层，并结合市场实际反应进行验证，而不是把新闻热度直接转成买卖评分。

最终，我希望你每天打开 WealthSail 时看到的不是几十条曲线，而是四句话：

市场发生了什么重要变化？

哪些投资方向因此值得研究，哪些风险上升了？

哪些指数和基金满足已经验证过的投资条件？
