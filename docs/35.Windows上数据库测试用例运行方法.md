你现有的 PostgreSQL 是 Windows 便携版 16，安装在 WealthSail 项目的 `.local` 目录中。不需要安装，也不需要重新初始化数据库。



可以直接使用 `pg\_ctl.exe` 启动原来的数据库。



\## 1. 启动 PostgreSQL



打开 PowerShell，执行：



```

cd D:\\develop\\gitee\\WealthSail



$pgctl = ".\\.local\\postgres\\pgsql\\bin\\pg\_ctl.exe"

$pgdata = ".\\.local\\pgdata"

$pglog = ".\\.local\\logs\\postgres.log"



\# 先检查是否已经运行

\& $pgctl -D $pgdata status

```



如果显示：



```

pg\_ctl: no server running

```



再执行启动命令：



```

\& $pgctl -D $pgdata `

&#x20;   -l $pglog `

&#x20;   -w -t 90 `

&#x20;   -o "-p 55432 -h 127.0.0.1 -c timezone=Asia/Shanghai" `

&#x20;   start

```



正常会显示：



```

waiting for server to start.... done

server started

```



这与原来 `start-local.ps1` 使用的启动参数一致。



\## 2. 验证 PostgreSQL 已运行



```

\& $pgctl -D $pgdata status

```



再检查端口：



```

\& .\\.local\\postgres\\pgsql\\bin\\pg\_isready.exe `

&#x20;   -h 127.0.0.1 -p 55432 -U postgres

```



预期：



```

127.0.0.1:55432 - accepting connections

```



\## 3. 然后重建 094 测试数据库



确认你已修改 SQL 094 和对应测试文件后，可以删除旧的专用测试库：



```

$env:PGPASSWORD = (

&#x20;   Get-Content .\\.local\\secrets.json -Raw |

&#x20;   ConvertFrom-Json

).postgres\_password



\& .\\.local\\postgres\\pgsql\\bin\\psql.exe `

&#x20;   -h 127.0.0.1 `

&#x20;   -p 55432 `

&#x20;   -U postgres `

&#x20;   -d postgres `

&#x20;   -v ON\_ERROR\_STOP=1 `

&#x20;   -c "DROP DATABASE IF EXISTS ai\_usage\_isolated\_test WITH (FORCE);"



Remove-Item Env:\\PGPASSWORD

```



只会删除 `ai\_usage\_isolated\_test`，不会删除你的 `wealthsail\_local`。



然后运行一键测试：



```

powershell -NoProfile -ExecutionPolicy Bypass `

&#x20;   -File .\\run-wealthsail-db-tests.ps1

```



脚本会自动重新创建测试数据库、执行 Migration 001–094，并运行静态测试和 PostgreSQL 集成测试。



\## 4. 测试结束后关闭 PostgreSQL



```

\& .\\.local\\postgres\\pgsql\\bin\\pg\_ctl.exe `

&#x20;   -D .\\.local\\pgdata `

&#x20;   -m fast -w stop

```



注意：如果 `start-local.ps1` 正在运行本地网站和 API，就不要手动关闭数据库，以免影响正在运行的服务。



其实最简单的方式： 你的 `run-wealthsail-db-tests.ps1` 已经具备自动启动 PostgreSQL 的功能。只有在需要手动删除旧测试库时，才需要提前执行上面的 `pg\_ctl.exe start` 命令。
