## 当前发布规则

- Schema 不再把输出行业限制为当轮冻结子集。全部全局行业和自由标签均可表达；确定别名映射到全局代码，其他自定义标签归入 `BROAD` 并保留原标签和映射说明。
- 冻结子集只说明实际完成了哪些反方搜索。未完成搜索的方向标为 `UNAUDITED_SCOPE`，页面显示“基于已有资讯研判”；关联基金、模型观点和参考区间保留。
- 正常执行通过 `sanitize_report`、`validate_report_outcome`、`evaluate_research_batch` 逐项修复。错误来源引用移除、日期待确认、可选字段补默认值；损坏单项写入 `validationWarnings`，健康兄弟项继续展示。
- 基金价位以服务端真实净值和 `actionable_zones` 计算为准，覆盖模型价格。不能确定的基金身份保留待匹配信息；不会套用另一只基金的价位，也不会伪造净值。
- 可解析JSON的业务结果为 `executionStatus=COMPLETED`，已有数据库/接口发布状态仍为 `READY`。未返回JSON、模型进程退出未确认、基础设施写入失败仍如实记录；本次没有提高模型调用次数或扩大超时。
- 旧严格验收保留为显式 `diagnose_*` 历史诊断入口，不在正常研究发布路径中一票否决。历史修复预览可继续比对原有诊断。

## 基金与页面

《今日重点》展示全部价值方向、全部研究主题和正文提及的基金。缺少基金计划的方向/主题从完整基金目录匹配；定量扫描再补充已入买区、距买区不超过3%或右侧触发的真实机会。10~15是补充机会的目标，不会截断模型已经产出的方向和主题。

关联基金使用同一净值坐标展示参考买区、止盈T1/T2、止损、当前净值、分位和带区间的走势图。观察或待审状态作为说明，不会清空计划。《我的基金》采用单栏价位面板；历史样本不足或净值落后时，按现有授权拉取真实历史净值并缓存入库后计算。外部来源临时不可用时仍会显示数据状态，不以假数据填空。

## 零模型调用恢复

先按既有部署流程备份并应用迁移 `108_sanitized_research_recovery.sql`，再部署包含本次修改的后端和前端。迁移工具会核对恢复函数及审计表权限。恢复命令在可读取原研究审计卷、具有既有 Worker 数据库配置的容器中执行：

```sh
# 默认只预览，只输出数量、hash及原完成时刻，不输出研究正文。
docker exec wealthsail-worker-1 python -m backend.jobs.research_report_recovery \
  --run-id ae71f283-b0db-46dc-a072-229714627476

# 发布同一份保存的模型输出，不创建新模型调用。
docker exec wealthsail-worker-1 python -m backend.jobs.research_report_recovery \
  --run-id ae71f283-b0db-46dc-a072-229714627476 --publish
```

命令读取指定执行的原始审计、冻结公共包与来源检查，在禁止网络和模型调用的子进程内重验收。预览的基金补齐只读取本地真实目录和历史净值；显式发布时，会在子进程之外补取缺失基金的公开历史净值并缓存入库，再计算参考价位。单只取数失败会保留报告并返回缺口计数，正常页面读取也会按授权重试。

发布通过受限 Worker 函数，在一个事务中保存原失败结果、原流水线和原请求快照，再更新可展示报告。原模型执行记录、用量和成本锁不变。冻结包摘要必须一致；同一执行及原始输出hash重复发布为幂等成功。浏览器API角色无发布权限。研究原完成时间与恢复发布时间分别保留，恢复不会把11月10日的证据改成11月11日的新研究。

审计文件仅在NAS内部读取和处理，不需要导出完整研究正文到开发电脑。真实预览已确认原始输出包含9个价值方向、12个主题，并保留AI硬件方向；预览不等于生产发布，也不等于全部引用均已有足够本地净值，需查看命令返回的独立基金、完整价位和走势图覆盖计数。
