## 1. 测试战略与质量评估体系 (Testing Strategy & Quality Metrics)

为了确保 WealthSail MVP 能够稳定提供高质量的量化投研服务，杜绝大模型金融幻觉与数据滞后，系统建立 **“四维质量指标体系”** 与 **“三层金字塔测试架构”**。

### 1.1 四维质量考核指标
| 质量维度 | 考核标准与验收阈值 | 验证手段 |
| :--- | :--- | :--- |
| **1. 数据时效性 (Freshness)** | • 盘前隔夜外盘/期指数据抓取时间戳为当日 `08:00 - 08:30`。<br>• 股票日 K 线包含最近一个交易日最新收盘价。<br>• 上海金基准价与原油/铜大宗商品为当日最新发布行情。<br>• 宏观 PMI 与库存数据为国家统计局最新公布月度数据。 | 校验 API 返回的最新记录 `date` / `timestamp` 字段与当前交易日对比。 |
| **2. 计算准确性 (Accuracy)** | • 股票量价支撑位/阻力位计算严谨无数学错误。<br>• 基金分红再投资折算份额公式精确到 `0.0001` 位，成本摊薄无偏差。<br>• 黄金资产按“克 (g)”与“每克单价”计算总市值，与金价波动完全一致。<br>• 金铜比与油铜比计算公式严格符合宏观定义。 | 自动化单元测试断言，对比官方交易所/权威财经网站公布数据。 |
| **3. 内容完整性 (Completeness)** | • 盘前简报必须包含：宏观风向、持仓标的支撑/阻力、If-Then 预案、操作方向评级与止损线。<br>• 真实成交记录必须包含：标的代码、多度量衡数量、成交均价与出局规则绑定。 | 自动化正则/JSON Schema 校验字段缺失率（缺失率必须为 0%）。 |
| **4. 系统可靠性 (Reliability)** | • 外部金融 API 偶发超时具备至少 3 次重试与兜底降级策略。<br>• 企业微信推送消息到达率 100%，网络抖动自动补偿。<br>• 定时 Cron 任务在 7x24 小时无人值守下准时触发率 $\ge 99.9\%$。 | 模拟网络断开与重试注入测试、长周期稳定性监控。 |

### 1.2 分层测试架构 (Testing Hierarchy)
```
          / \
         /   \       【系统与端到端场景验收测试 (E2E System Acceptance)】
        / ST  \      用户旅程、盘前推演、HITL交互、分红结算、微信卡片推送 (自动化+手动)
       /-------\
      /   IT    \    【集成测试 (Integration Testing)】
     /-----------\   Hermes 工具链调用、Supabase RLS 鉴权隔离、Cron 定时器集成
    /     UT      \  【单元测试 (Unit Testing)】
   /---------------\ 金融数据工具、分红数学算法、多度量衡转换、微信消息格式化 (100% 自动化)
```

```python
"""
Database & Dividend Algorithm Unit Tests for WealthSail MVP.
"""
import pytest

def test_dividend_cash_calculation():
    """测试现金分红：资金增加，持仓份额不变。"""
    # 模拟持仓 1000 份，每份分红 0.20 元
    current_qty = 1000.0
    dividend_per_share = 0.20
    total_dividend = round(current_qty * dividend_per_share, 2)
    assert total_dividend == 200.00

def test_dividend_reinvest_dilution():
    """测试红利再投资：份额增加，单位成本严格摊薄。"""
    current_qty = 1000.0
    old_cost = 6.00  # 原总本金 6000 元
    dividend_per_share = 0.20
    reinvest_nav = 5.00  # 除息日折算净值
    
    total_dividend = round(current_qty * dividend_per_share, 2)  # 200 元
    added_shares = round(total_dividend / reinvest_nav, 4)       # 40.0000 份
    new_qty = current_qty + added_shares                         # 1040.0000 份
    new_cost = round((current_qty * old_cost) / new_qty, 4)      # 5.7692 元
    
    assert added_shares == 40.0000
    assert new_qty == 1040.0000
    assert new_cost == 5.7692
```
