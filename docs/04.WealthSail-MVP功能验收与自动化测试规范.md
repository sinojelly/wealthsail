## 1. 测试战略与质量评估体系 (Testing Strategy & Quality Metrics)

为了确保 WealthSail MVP 能够稳定提供高质量的量化投研服务，杜绝大模型金融幻觉与数据滞后，系统建立 **“四维质量指标体系”** 与 **“三层金字塔测试架构”**。

### 1.1 四维质量考核指标
| 质量维度 | 考核标准与验收阈值 | 验证手段与断言 |
| :--- | :--- | :--- |
| **1. 数据时效性 (Freshness)** | • 盘前隔夜外盘/期指数据抓取时间戳为当日 `08:00 - 08:30`。<br>• 股票/ETF 日 K 线包含最近交易日最新收盘价。<br>• 上海金基准价与大宗商品原油/铜为当日最新发布行情。<br>• 宏观 PMI 与库存数据为国家统计局最新公布月度数据。 | 校验 API 返回的最新记录 `as_of` / `retrieved_at` 字段，打标 `FRESH/STALE`。 |
| **2. 计算准确性 (Accuracy)** | • 股票量价支撑位/阻力位计算严谨无数学错误。<br>• 基金分红再投资折算份额公式精确到 `0.0001` 位，成本摊薄严格守恒。<br>• 黄金资产按“克 (g)”与“每克单价”计算总市值，与金价波动完全一致。<br>• 金铜比与油铜比计算公式严格符合宏观定义。 | 自动化单元测试断言，对比官方交易所/权威财经网站公布数据。 |
| **3. 内容完整性 (Completeness)** | • 盘前简报必须包含：宏观风向、持仓标的支撑/阻力、If-Then 预案、操作方向评级与止损线。<br>• 真实成交记录必须包含：标的代码、多度量衡数量、成交均价与出局规则绑定。 | 自动化 JSON Schema 校验字段缺失率（必填字段缺失率为 0%）。 |
| **4. 系统可靠性 (Reliability)** | • 外部金融 API 偶发超时具备至少 3 次重试与兜底降级策略。<br>• 企业微信推送消息到达率保障，幂等键去重拦截率完全有效。<br>• 定时 Cron 任务在 7x24 小时无人值守下准时触发率 $\ge 99.9\%$。 | 模拟网络断开与重试注入测试、长周期稳定性监控。 |

### 1.2 分层测试架构 (Testing Hierarchy)
```
          / \
         /   \       【系统与端到端场景验收测试 (E2E System Acceptance)】
        / ST  \      用户旅程、盘前推演、HITL交互、分红结算、微信卡片推送 (自动化+手动)
       /-------\
      /   IT    \    【集成与安全隔离测试 (Integration & Security Testing)】
     /-----------\   Hermes 工具链调用、PostgreSQL RLS 鉴权隔离、Cron 定时器集成
    /     UT      \  【单元测试 (Unit Testing)】
   /---------------\ 双式记账借贷守恒、分红摊薄算法、大宗比价计算、数据质量清洗 (完全自动化)
```
