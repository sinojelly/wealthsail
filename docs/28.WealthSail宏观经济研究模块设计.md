## 2. 机会发现与证据边界

`LEFT_VALUE`（左侧价值/超跌观察）与`RIGHT_TREND`（右侧趋势）独立计算，每轨返回`CANDIDATE`、`WATCH`或`INSUFFICIENT`、实际输入日期、规则依据和缺失项。满足任一轨可形成该轨研究候选；另一轨缺数据或未满足条件不否决它。PB、企业盈利、完整产品评分和505期REAL_PIT不足是独立警告，不再是双轨的一票否决条件。MA200仅作为有真实200期时的观察和可选锚点。

研究候选表示当前版本条件成立，不表示收益保证、策略已验证或个人预算合格。实际PIT验证与价值证据保留各自真实状态；不下调旧统计的样本数后继续沿用“已验证”标签。坏值、冲突、陈旧、未知来源、无可信当前交易日等仍影响它们实际依赖的输入。缺数只关闭依赖它的条件、指标或价格字段，并披露原因；不得把缺数补0、补合成行情、改写为已满足。

保留来源、方法、观察期、公布/可得/抓取时刻与修订的区分。指数点位不是基金净值或收益；后复权价格、收益指数、净值只能给出相同口径的研究坐标，不能冒充ETF实时可挂单价格。按既有instrumentId、市场、真实映射和货币/单位识别标的，未知映射不移用其他标的行情。个人风险、交易权限和账本约束不因机会候选而放宽。

## 3. 确定性指标与双轨规则

### 3.1 输入和指标

使用已落库的真实、有序、当前有效历史。价格须有限且为正，OHLC须同日对齐并满足`0 < low <= close <= high`。无效值与断点不通过删除样本伪造连续历史；指标使用各自真实连续尾窗。

- MA20/60/200分别需要真实20/60/200期收盘，不用短均线替代长均线。
- RSI14采用Wilder平滑；20期动量为`C / C[-21] - 1`。平盘无涨跌时RSI为50。
- Bollinger(20,2)为`MA20 ± 2 × 最近20期收盘总体标准差`，不把人为价格下限当原始布林下轨。
- ATR14采用真实高低价和前收的True Range及Wilder平滑。只要求用于当前ATR的连续尾部真实OHLC；更早缺高低价不污染有效尾窗。缺OHLC不能用收盘变化倍数、固定波动率或价格下限伪造ATR。
- PE分位只使用现有已核验、同方法的实际分位和声明窗口；未知分位不按低PE倍数或净值区间位置推导。

### 3.2 轨道触发

设`C`为当前有效收盘，`BollLower`为真实20期布林下轨：

| 轨道 | 候选条件 |
| --- | --- |
| LEFT_VALUE | `cheap OR oversold`；`cheap = PE分位 <= 40 或 真实MA200偏离 <= -8%`；`oversold = Wilder RSI14 <= 38 或 C <= BollLower × 1.02` |
| RIGHT_TREND | `C >= MA20 且 20期动量 > 0 且 Wilder RSI14 < 75` |

LEFT的任一可核验分支成立即为`CANDIDATE`，无需同时低估且超跌；只有全部分支均可核验且均不成立时才为`WATCH`，否则为`INSUFFICIENT`。RIGHT的三个条件须同时成立；任一已知条件不成立即为`WATCH`，无已知反例且必要输入不足时为`INSUFFICIENT`。事件催化可补充解释，不增加新的全局一票否决条件。两轨可同时成立，不强制压成单一方向或总分。

### 3.3 区间、止损与目标

在对应输入可用时，按同一价格口径计算：

| 字段 | LEFT_VALUE | RIGHT_TREND |
| --- | --- | --- |
| entryMin | `min(BollLower, C - 0.8 × ATR14)` | `MA20 - 0.2 × ATR14` |
| entryMax | `min(MA20, C + 0.3 × ATR14)` | `max(C, MA20 + 0.6 × ATR14)` |
| stopLoss | `entryMin - 2 × ATR14` | `entryMin - 2 × ATR14` |
| takeProfitT1 | `max(可用MA60, entryMax + 2 × ATR14)` | 同左 |
| takeProfitT2 | `max(可用MA200, takeProfitT1 + 2 × ATR14)` | 同左 |

可选MA60/MA200缺失时只用上述ATR锚点，不制造均线。没有真实ATR但收盘、MA20和布林带可用时，可显示明确标注的均线/布林参考区间：LEFT为`[BollLower, min(C, MA20)]`，RIGHT为`[MA20, max(C, MA20)]`；止损及目标为`null`，价格完整度为`PARTIAL`，不全局清空已经成立的候选。

每个价格必须有限且为正，区间满足`entryMin <= entryMax`，止损低于入场区，目标依次高于入场区；不合理时关闭相应字段并返回原因，不凭空挪动锚点或连带隐藏其他有效事实。输出记录算法版本、参数、输入日期、单位、价格口径、完整度和缺失原因，价格沿用金融十进制字符串边界。

## 10. 结构化复盘记忆

保存REVIEW笔记后，在同一事务内按themeCode聚合最新复盘到`research.strategy_memory_rules`；每actor每track只计最新REVIEW，重复笔记不作为独立试验。最新无经验总结时不回退旧结论；零样本规则撤销公开输出。只接受固定五主题及UNCLASSIFIED、已有错误类别枚举。

本轮用户已授权把复盘校准规则用于研究，但输出只包含固定类别模板、真实聚合计数和统计口径；不把原始reason/lessons、账户、成本、仓位或actor标识写进公共包。公共读取只取环境配置指定机会用户的规则，不扫描全租户自由文本，不新运行一次模型提炼。表仍为actor RLS。

SUPPORTED/(SUPPORTED+REFUTED)是“判断支持率”，MIXED/INCONCLUSIVE单列，样本分母明确。盈利胜率独立使用已关联CONFIRMED真实成交：当前本人MINE可见、成员与账户有效，同一账户/标的/币种，完整数量闭合、手续费与逐条账本分录一致且未冲销，全部买入交易日严格早于全部卖出交易日。按闭合现金流分盈利/亏损/持平，`winRate=profitWinCount/profitSampleCount`；同日先后未知、交错买卖、部分仓位、多账户/异币、非标准税费或跨track复用同一成交均不构成独立盈利样本。读取时重新核验权限与冲销，不能沿用过期盈利统计；成交关联在同事务内刷新受影响主题。没有合格样本时`winRate=null`，不能把SUPPORTED改称盈利；闭合现金流也不证明策略因果。Worker仅新增所需账本成交/账户成员列的SELECT权限，无账本写权限。模型通过规则key引用，ActionablePlan展示calibrationNote及调价说明。

## 11. 估值核对、MFE/MAE与Webhook

入场判断为闭区间；止损为当前值<=stopLoss；目标为>=T1；同一项优先STOP_LOSS、TAKE_PROFIT、ENTRY。提醒同时显示估算区间和可能误差，未知项独立列出。未进入条件也可以汇总“暂无命中”，避免用沉默冒充成功检查。已保存计划不会被当日模型调价覆盖。

## 15. 场外净值波动风险价与精度

当且仅当价格口径为UNIT_NAV、缺少真实OHLC且至少有20个实际连续净值时，使用独立的`navVolatility14`，方法`NAV_ABS_CHANGE_STD_V1`：`s=max(mean(最近14个净值绝对日变化)×1.4, 最近20个净值总体标准差×0.65, 当前净值×0.012)`，四位小数量化。最后一项是明确的策略最小风险幅度，不是供应商观察，也不是概率置信区间。真实ATR14保持null；close-only指数、复权价和收益指数不自动套用该净值方法。

净值入场区间沿用同口径均线/布林与波动锚点。左侧止损为entryMin−2s，右侧为MA20−2s；T1至少为`max(可用MA60,currentPrice+2.5s,entryMax+2s)`；T2至少为`max(BollUpper,currentPrice+4.5s,T1+s)`。价位输出四位小数，舍入后再次保证`0<stop<entryMin≤entryMax<T1<T2`。不合理的价位仍关闭并解释，不能为消灭横杠制造负价、假历史或假ATR。真实OHLC的ATR路径保持原算法。

20期之前的短历史、当前日期未核实、交易日缺口、陈旧、冲突或QDII海外日历不足仍保留实际事实与缺失原因，不认证有效当前买卖点。算法版本升级，方法和尺度进入公共包、模型选择结果与冻结快照，旧冻结价位不回算。前端和Webhook净值显示3—4位、指数2位、百分比1—2位；原始长浮点不直接进入正文、算法详情或群提醒。

## 23. 主动综合催化，扩大有价值方向

根据Gemini评审08，研究过程先聚合同一产业链的回购/增持、经营业绩、政策、重大会议和技术位置，再解释传导路径、可观察的验证点及最重要风险。回购提议可以提供管理层意向和潜在资金需求信号，海外龙头业绩可以支持产业景气假设；准确注明阶段与受益路径，不能因为尚未执行或传导尚待验证，就自动否定其研究价值。单条新闻不拆成一个方向，同一逻辑聚合，优先寻找不同产业或驱动因素的有效机会。
