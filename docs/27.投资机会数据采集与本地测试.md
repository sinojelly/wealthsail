# 投资机会：宏观历史采集、自动更新与本地测试

> 2026-10-14。对应[数据设计](24.支持基金筛选的方案.md)、[Windows一键运行](26.Windows-local-development.md)与[实施计划](../ai-review/18.WealthSail-基金筛选页面功能扩展实施计划.md)。

## 页面刷新为什么可能没有数据

浏览器刷新和12/36/60月切换只查询数据库，不向供应商抓取。API负责读数据；采集由独立后台进程完成。`NOT_COLLECTED / 0个样本`表示所连数据库尚无可用宏观事实，不代表宏观数值为零。

旧版一键启动只启动数据库、API和前端，旧版完整Worker也只在06:30定时研究中采集宏观，窗口外启动不会立即回填。本轮补上冷启动检查和宏观独立进程；已经运行的旧服务需要重启才能载入新代码，单纯刷新网页不能更新后端进程。

## 从哪里取历史

采集使用项目锁定的AKShare 1.18.94适配东方财富经济数据接口，原始统计数据是月度观察值。不是大模型生成，也不是从网页卡片反推数据。

| 页面字段 | AKShare函数 | 保留字段 | 来源页面 |
| --- | --- | --- | --- |
| CPI同比 | macro_china_cpi | 全国-同比增长 | [东方财富CPI](https://data.eastmoney.com/cjsj/cpi.html) |
| 制造业PMI | macro_china_pmi | 制造业-指数 | [东方财富PMI](https://data.eastmoney.com/cjsj/pmi.html) |
| PPI同比 | macro_china_ppi | 当月同比增长 | [东方财富PPI](https://data.eastmoney.com/cjsj/ppi.html) |
| M2同比 | macro_china_money_supply | 货币和准货币(M2)-同比增长 | [东方财富货币供应量](https://data.eastmoney.com/cjsj/hbgyl.html) |

每次读取供应商完整可得历史，按最近五年的月初至今天裁剪；解析中文/数字月份，校验单位、数值、重复冲突与未来期。每源有20秒超时，单源失败不清空其他源或旧事实。API显示的是数据库内实际覆盖，不保证每源都有60期或已经公布本月数据。

## 启动、检查与更新

| 场景 | 实际行为 |
| --- | --- |
| API启动/页面刷新 | 只建只读连接并查询数据库，不采集 |
| 完整Worker启动 | 后台检查宏观历史，不阻塞既有调度/任务启动 |
| Windows一键启动 | 默认另起仅采集宏观的macro_worker，使用独立Worker登录和macro.env |
| 宏观后台进程启动 | 检查四指标的五年窗口、已返回月份连续性与最近采集时间；缺失/缺月或超过24小时未采集则回填 |
| 正常更新 | 每天Asia/Shanghai 06:30，周末/节假日也更新，重取五年历史以记录修订 |
| 采集不完整/失败 | 保留原记录和具体缺口；独立宏观进程一小时后重试，不持续空转 |
| 手动更新 | --once强制读取，输出各指标覆盖和本次采集状态，不等次日 |

06:30后启动且最近采集尚未覆盖当天06:30时，独立宏观进程立即补取当天任务；不会因昨天数据尚在24小时内而漏掉今天更新。失败重试的一小时从本次尝试结束后计时。

“完整”按该来源最近实际返回的观察月核对连续性，不假设本月已公布。最近采集时间和数据观察期分别保留；24小时是采集检查期限，不能当作公布时间或保证统计数据最新。

生产完整Worker已有06:30研究任务，不需要同时再运行macro_worker。宏观独立进程适用于不启用报告/投递的本地体验或单独采集部署；多进程部署仍须避免重复配置定时采集。

## 如何测试当前页面

在仓库根目录的PowerShell执行。已有旧服务运行时，先停止，再启动更新后的代码；停止保留数据库、账户和页面编辑。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -Action Stop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -SkipInstall
```

新启动会执行全部迁移，并自动检查/回填宏观。打开投资机会→市场环境概览，等待首次采集后刷新页面。应看到四指标的数值、来源、实际样本数和历史曲线；12/36/60月切换应改变查询窗口和样本覆盖。

需要明确立即重取数据时，保持本地服务运行，在另一个窗口执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -Action RefreshMacro
```

该命令使用正在运行的本地数据库端口，补齐生产迁移并调用宏观采集一次；不重置登录密码、账户或投资记录，也不启动报告/投递。若网络失败或仅部分指标成功，查看输出及日志，不能把命令结束理解为所有数据已完整。

不需要联网采集时可用 `-SkipMacro` 启动本地服务；已有数据库事实仍可查看，空库不会自动有数据。手动回填需要本地数据库已启动。

```powershell
Get-Content .local\logs\macro.stderr.log -Tail 80
```

完整Worker日志使用macro_bootstrap、research_macro_sync等记录；独立采集进程输出启动检查、覆盖、每日更新和重试状态。先确认数据库迁移和正确连接库，再检查外网是否可访问上述来源。

## 保存在哪里、如何看待质量

原始来源URI、获取时刻、内容哈希和观察期保存在market.source_snapshots；每个字段/月度观察值在market.market_observations，修订追加保留，避免覆盖历史审计。CPI/PPI/M2单位为%，PMI为指数值。

供应商适配器未提供经过核验的公布时刻，因此published_at保持空，页面显示“公布时间未核实/UNVERIFIED”。即便曲线已经有数据，也只能称观察期事实，不能据此直接输出可信经济周期判断。

基金/指数历史采集另依赖真实来源、发布窗口与跟踪映射登记；本地宏观采集不代表基金池已经全部配置。完整价值候选仍需足够的收益、估值和成本证据，缺口见[验收](../ai-review/investment-data-evidence-acceptance.md)及[ADR-002](adr/002-index-valuation-history-sources.md)。
