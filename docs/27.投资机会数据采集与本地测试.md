## 本轮基线

本轮清理与双轨计划复用既有数据库、采集、日报和私有跟踪，不新增083或任何迁移，不接新数据源、经验库、自进化和Webhook。078—082保持原字节。文档和单元通过不表示本地旧服务已经载入新代码；历史测试数量、截图和数据覆盖只代表当时记录。

页面保持三个入口和下方工作台。检查两轨独立状态及真实价格口径；缺PB/PIT/MA200不使全部候选WAIT。没有真实ATR时允许PARTIAL参考区间，止损和目标为空，不能用收盘差推造ATR。指数点位、净值、复权价均应明确标注。

## 页面刷新与数据来源

浏览器刷新、筛选、分页和宏观窗口切换只查询数据库；API不向供应商采集。`NOT_COLLECTED`或0个样本代表没有可用事实，不代表经济数值为零。采集由现有独立后台进程执行，只有API/前端而无消费者时刷新任务可停留排队。

| 字段 | 现有AKShare函数 | 字段/来源 |
| --- | --- | --- |
| CPI同比 | macro_china_cpi | 全国-同比增长；东方财富CPI |
| 制造业PMI | macro_china_pmi | 制造业-指数；东方财富PMI |
| PPI同比 | macro_china_ppi | 当月同比增长；东方财富PPI |
| M2同比 | macro_china_money_supply | 货币和准货币(M2)-同比增长；东方财富货币供应量 |

适配器按锁定AKShare实际接口读取最近五年可得历史，解析月份、检查单位、数值、冲突和未来期；独立超时或单源失败不清空其他源和旧事实。五年是目标，API显示实际样本和截止期，不保证每源60个月。指数沿用中证公开收盘与PE，既有美国利率/能源和官方公告来源继续按原配置；中债/CFETS未授权不通过修改来源状态冒充获批。

## 启动、检查和现有更新

| 场景 | 既有行为 |
| --- | --- |
| Windows一键启动 | 默认启动独立macro_worker，使用受限Worker登录和macro.env |
| 宏观后台启动 | 检查四指标窗口、连续性及最近采集，缺失/缺月或超过期限时回填 |
| 常规宏观更新 | 每天上海时间06:30，周末/节假日照常，保留修订 |
| 宏观不完整/失败 | 保留记录和缺口，独立进程一小时后重试 |
| 官方证据 | 现有启动检查、每15分钟唤醒与租约/重试规则 |
| 指数研究 | 沪深300/A500/中证500启动检查、15分钟唤醒，正常24小时重采，失败/部分一小时重试 |
| 页面对象刷新 | 使用现有耐久后台队列，GET不代替消费者 |

采集时间、观察期、计划发布与实际公布时刻分别保留；计划已过不证明后台在线。生产已有完整Worker时避免重复配置macro_worker定时采集。网络等待不占数据库长事务；停止使用既有cancel/await清理，不按进程名称批量结束服务。

需要载入新代码时由操作者按[运行手册26](26.Windows-local-development.md)确认自己实例后停止/启动；本轮实现与验证不会擅自重启用户服务：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -Action Status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -Action Stop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -SkipInstall
```

一键启动按现有逻辑执行迁移并检查数据；本轮没有新增迁移。生产静态前端需重新构建，Vite开发服务按其热更新规则载入。只刷新浏览器不会更新旧API/Worker代码。

需要显式重新采集现有宏观时，操作者可在自己的运行实例执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-local.ps1 -Action RefreshMacro
```

命令不重置账户/持仓或执行模型。分别核对顶层status/coverage、officialEvidence与marketEvidence的status/sourceResults；顶层COMPLETED/退出0不代表全部子源成功。`-SkipMacro`可读取已有事实但不自动填空库。

只更新指数可在已有受限Worker环境执行`./.venv/Scripts/python.exe -m backend.jobs.index_research --once`，不是API身份；PARTIAL/FAILED退出1需看具体缺口。不得为本轮验收向用户库写合成新闻、行情或成交。

日志与状态核对：

```powershell
Get-Content .local\logs\macro.stderr.log -Tail 80
```

先核对连接的是预期实例和迁移状态，再看来源异常；凭据不写日志、Git或响应。公开历史补抓不认证当时PIT，未知公布日期不填成抓取日期。

## 每日Codex及跟踪边界

本地启动器现有默认`DAILY_RESEARCH_ENABLED=true`，上海时间08:30每日一次、晚启动当天补一次；生产显式启用。`-SkipMacro`或无研究消费者时计划时间不表示可执行。同日消费标记已登记后，即使失败/超时/UNCERTAIN也不删除重派发。旧READY报告保留原日期，任务时间与有效报告时间分开。

Codex由同一Windows用户登录，优先使用原生codex.exe，可用`DAILY_RESEARCH_CODEX_PATH`和`DAILY_RESEARCH_MODEL`配置现有能力；公共单stdin、独立临时目录和剔除私有凭据的子环境保留。普通概率/买卖措辞不再是拒绝条件，结构、引用和时点检查保留。程序双轨价位和冻结计划使用服务器的真实输入；日报自由文本中的预测数字没有逐项价格锚点认证，不进入结构化价格或自动执行链，详见设计28第4节。私人持仓、交易、风险预算和复盘不进入公共输入。

刷新、切标签、开图、核对已存证据、保存主题或复盘均不新派发模型；本轮验证零新模型执行。原study actor权限、不可变版本、15分钟条件检查、generation、ACK及真实成交DAY约束保留。actionablePlan只冻结进现有版本JSON，本轮不新增到价推送或实时盯盘数据。

## 本轮验证方法

核心回归覆盖左轨低估/超跌分别触发、右轨三条件、MA200/PB/PIT缺失、真实尾部OHLC及旧缺高低价、无ATR部分计划、价位正值/顺序、陈旧/冲突输入、口径标识、公共隐私与私有冻结。

运行项目现有后端回归和前端test/typecheck/lint/build，校验文档链接、迁移原字节和diff；实际命令、数量、跳过与限制只填写计划38。需要隔离SQL测试时由主任务提供专用`INVESTMENT_TEST_DATABASE_URL`与`OPPORTUNITY_JOB_TEST_DSN`，缺环境跳过不算实库验证。本轮不访问用户数据库、运行新模型或把旧截图当新界面验收。

历史真实源/实库/浏览器证据保留在归档评审，供应商许可、策略有效性和目标部署验收仍分别声明；数据覆盖不足不全局阻断双轨，但不得声称缺失事实已验证。
