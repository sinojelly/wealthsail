### 基金投资系统：从宏观判断、选基金、择时交易，到自动化决策

我的建议是：不要只做一个利用 KDJ、MACD 判断买卖点的系统，而是建立一套完整的、可以回测、可以量化、可以自动监控的基金投资决策系统。

它应该解决六个问题：

第一层：宏观经济 — 现在应该投资股票、债券、黄金，还是更多持有现金？

第二层：投资方向 — 哪些国家、行业、风格有更好的风险收益前景？

第三层：基金筛选 — 同一方向，选哪只指数基金或主动基金更合适？

第四层：技术择时 — 什么时候适合分批买入、减仓或者退出？

第五层：资金与风险管理 — 买多少、能承受多少亏损、何时再平衡？

第六层：自动化系统 — 自动采集数据、计算评分、产生信号、显示原因并提醒人工决策。

### 一、首先理解：提高收益和提高胜率不是一回事

投资最重要的并不是每一笔都赚钱，而是长期、扣除费用后，获得更好的风险调整收益。

例如：

| 策略  | 盈利交易占比 | 平均盈利 | 平均亏损 | 单笔期望收益 |
| --- | ------ | ---- | ---- | ------ |
| A   | 70%    | +3%  | -10% | -0.9%  |
| B   | 45%    | +12% | -5%  | +2.65% |

这些是纯粹的数学示例，不是实测策略业绩。可以发现，A 虽然胜率高达 70%，长期却可能亏损；B 的胜率不到一半，期望收益反而更好。

所以我们的优化目标应该是：

净收益、最大回撤、长期复合收益、风险调整收益、交易成本和策略稳定性。

为什么不应该频繁预测市场？

晨星在 2026 年发布的 Mind the Gap 研究发现：截至 2025 年底的十年间，美国基金投资者实际资金加权年收益率为 8.7%，而相应基金的总体年化收益率为 9.9%。这种每年约 1.2 个百分点的差距，与投资者买卖资金的时点和规模有关。

这也意味着，一个优秀的自动化系统，其价值有时不是让你交易更多，而是减少错误交易。

### 二、第一层：从经济周期判断投资方向

你的第一个思路很重要，但需要从简单的「经济好就买股票，经济差就卖股票」升级为更可靠的多变量模型。

### 1\. 观察增长、通胀、流动性、估值

| 维度    | 需要监控的数据          | 作用               |
| ----- | ---------------- | ---------------- |
| 经济增长  | PMI、工业生产、消费、企业盈利 | 判断基本面是在改善还是恶化    |
| 通货膨胀  | CPI、PPI、核心通胀     | 判断货币政策空间和企业利润压力  |
| 货币流动性 | 政策利率、信用利差、社融、信贷  | 判断资金环境是宽松还是收紧    |
| 市场估值  | PE、PB、股息率、ERP    | 判断当前价格是否已经透支未来增长 |
| 市场风险  | 波动率、信用压力、市场宽度    | 识别风险偏好是否明显恶化     |

其中，最有价值的通常是变化方向，而不只是绝对水平。

例如，PMI 仍低于 50，但已连续几个月上升，说明经济活动仍偏弱，不过可能正在改善。而股市往往会提前交易这种预期。

### 2\. 建立经济周期与资产配置矩阵

| 宏观环境       | 值得重点研究的资产     | 主要风险       |
| ---------- | ------------- | ---------- |
| 增长改善、通胀温和  | 宽基股票、部分周期行业   | 估值上涨过快     |
| 增长改善、通胀较高  | 部分价值、资源、周期资产  | 成本压力和政策收紧  |
| 增长走弱、通胀下降  | 高质量债券、防御性资产   | 利率下降预期已经计价 |
| 增长走弱、通胀上升  | 高流动性资产、部分黄金配置 | 股债可能同时承压   |
| 流动性宽松、信用改善 | 可重点观察股票风险资产   | 政策传导失败     |
| 估值昂贵、市场过热  | 降低集中度、逐步再平衡   | 过早退出导致踏空   |

这不是必然的资产涨跌规律，而是研究优先级。

特别注意：经济指标有发布时间滞后，经济周期往往在事后才容易识别。因此系统不能把「准确预测经济拐点」作为成功前提。

### 3\. 我建议采用的宏观综合评分

假设给宏观环境建立一个 0—100 分的评分：

M=0.30G+0.25L+0.20I+0.15V+0.10R

其中：

* ：经济增长趋势评分

* ：流动性评分

* ：通胀环境评分

* ：估值吸引力评分

* ：市场风险环境评分

所有指标先转化为可比较的 0—100 分，分数越高表示越有利。

这些权重属于待回测的初始假设，并不是已证明最优的参数。特别是增长、流动性和估值会相互影响，不能把相关指标简单堆积成大量重复信号。

宏观评分用于调整风险预算，而不是机械地决定必须满仓或空仓。

### 三、第二层：如何筛选最值得投资的方向和基金？

这里要区分两个决策：

先选指数或资产，再选具体基金。

例如，看好中国大盘股，不等于随便选一只沪深300 ETF；看好科技创新，也不等于选最近一个月涨幅最大的科技基金。

### 1\. 建立投资候选池

我建议最初覆盖以下方向，避免把所有资金押在同一种市场环境上。

| 资产方向 | 可观察的指数或基金类别        | 主要研究逻辑         |
| ---- | ------------------ | -------------- |
| 中国宽基 | 沪深300、中证A500、中证500 | 中国整体企业盈利、估值、政策 |
| 中国成长 | 创业板、科创50           | 成长预期、利率、科技产业发展 |
| 中国红利 | 中证红利、红利低波          | 股息可持续性、估值、利率   |
| 美国权益 | 标普500、纳斯达克100      | 全球企业盈利、科技创新、美元 |
| 港股   | 恒生指数、恒生科技          | 估值、盈利修复、流动性    |
| 债券   | 国债、政策性金融债、短债       | 利率、久期、信用风险     |
| 黄金   | 黄金ETF等             | 实际利率、美元、风险对冲需求 |

这里列举的是研究范围，不是对这些方向在 2026 年 10 月的即时买入建议。

### 2\. 为不同投资方向建立排名

可先设计一套 100 分模型：

| 因素         | 权重  | 怎么评价             |
| ---------- | --- | ---------------- |
| 长期基本面和增长前景 | 25% | 盈利增长、产业需求、经济驱动   |
| 当前估值与历史分位  | 25% | PE、PB、ERP、历史估值区间 |
| 中期价格趋势     | 20% | 3—12个月动量、均线趋势    |
| 资金和市场确认    | 15% | 成交活跃度、市场宽度、相对强弱  |
| 风险和组合分散价值  | 15% | 波动率、相关性、集中度      |

这是研究评分模板。不同资产之间的估值和风险指标必须采用适合该资产的定义，不应直接比较股票 PE 与债券收益率。

最终找出的不是「涨得最多的方向」，而是：

前景、估值、趋势与风险四方面相对匹配的方向。

例如，某行业长期前景很好，但估值已处于极高水平，且价格持续跌破中长期均线，就可能值得长期观察，却未必是近期的好买点。

### 3\. 同一指数，如何选择基金？

我会重点考察以下条件：

| 指标        | 理想特征         | 为什么重要        |
| --------- | ------------ | ------------ |
| 跟踪差异和跟踪误差 | 同类中较低、长期稳定   | 判断是否有效复制指数   |
| 综合持有成本    | 管理费、托管费等相对较低 | 费用长期侵蚀收益     |
| 规模        | 适度且稳定        | 降低小规模基金的运营风险 |
| 成交流动性     | 成交额充足、买卖价差小  | 降低实际交易成本     |
| 折溢价       | 市价接近可比净值     | 避免明显溢价买入     |
| 基金运行质量    | 运作稳定、指数复制透明  | 降低非市场风险      |

特别关注ETF 折溢价、买卖价差和交易价格偏离净值。这些风险不会自动反映在 MACD 或 KDJ 里。上交所投资者教育也特别强调 ETF 的流动性、跟踪效果与系统性风险。

对于主动管理基金，我会额外研究基金经理任职期间、相同风格和相同风险条件下的超额收益、最大回撤、持仓漂移和业绩持续性，而不是只看收益率排行榜。

作为参考，标普道琼斯指数的 2025 年度 SPIVA 报告显示，美国大型股主动基金在该年度约有 79% 未跑赢标普500。这是美国市场的统计，不能机械推广到中国所有类别，但足以说明：主动基金要持续跑赢其合适的基准，并不容易。

因此，我建议以低成本、分散化指数基金作为主要研究对象；只有在证据充分时，才引入主动基金。

### 四、第三层：建立 MACD、KDJ、均线相结合的择时系统

这是你提出的第二个重点。

我的建议是：用长期趋势决定能不能买，用中期动量决定优先买什么，用短期指标寻找更合适的执行时机。

### 1\. 不同技术指标的角色

| 指标           | 主要作用        | 优点        | 主要缺点        |
| ------------ | ----------- | --------- | ----------- |
| MA60 / MA200 | 确认中长期趋势     | 易解释、便于程序化 | 趋势反转时滞后     |
| MACD         | 判断趋势变化、动量   | 适合趋势确认    | 震荡市频繁假交叉    |
| KDJ          | 观察短线超买超卖与转折 | 较敏感       | 强趋势中容易过早卖出  |
| RSI          | 辅助判断涨跌动量    | 便于量化      | 超买不代表马上下跌   |
| ATR          | 衡量价格波动      | 有助于设定风险幅度 | 不预测方向       |
| 相对强弱         | 对比候选基金      | 识别中期强势方向  | 容易追逐已经拥挤的行情 |

学术研究确实发现过多个资产市场中的时间序列动量现象，例如 Moskowitz、Ooi 和 Pedersen 2012 年的研究。但它不能直接证明某组 MACD/KDJ 参数在中国 ETF 上扣费后必然盈利。

### 2\. 设计可量化的技术评分

下面是一套可以用程序直接计算的初始技术模型。

| 信号条件            | 得分  |
| --------------- | --- |
| 收盘价高于 MA200     | 25  |
| MA60 高于 MA200   | 15  |
| MA20 高于 MA60    | 10  |
| 最近63交易日收益率为正    | 15  |
| MACD DIF 高于 DEA | 10  |
| MACD 柱状动量改善     | 5   |
| KDJ 有效转强或处于支持区间 | 10  |
| RSI 在预设合理区间     | 10  |
| 总分              | 100 |

初步可以定义：

75—100：趋势较强

优先研究

55—74：信号不完全一致

继续观察

0—54：趋势偏弱

风险复核

这只是技术状态分数，不是上涨概率。例如 85 分不意味着有 85% 的概率赚钱。评分边界、权重、参数都必须通过样本外测试来验证。

### 3\. 买入策略：趋势确认 + 分批执行

一套值得回测的规则可以是：

* 建仓前提：长期趋势向上，宏观和估值没有明显风险警告，基金质量合格。

* 第一次买入：技术评分达到预设阈值，买入计划仓位的一部分。

* 第二次买入：回踩重要均线后重新走强，或者经过一定时间后上涨趋势得到再次确认。

* 第三次买入：基本面和趋势继续支持，且组合仍处于风险预算之内。

不建议用「跌了 10% 就必须补仓」作为通用规则，因为价格下跌既可能带来机会，也可能意味着投资逻辑已经失效。

### 4\. 卖出策略：区分三种情况

第一种：正常获利后的再平衡。 某个方向上涨过多，超过了原定组合权重，就减仓回到目标配置，而不是等待 MACD 死叉。

第二种：技术趋势发生实质性恶化。 例如持续跌破中长期均线、中期动量转负、MACD 同时恶化，可以触发减仓复核。

第三种：投资逻辑失效。 例如指数规则发生重要改变、行业盈利前景明显恶化、基金跟踪质量出现问题。这类风险应优先于短线技术信号。

不建议仅因为 KDJ 超过 80 就卖掉全部持仓。在强牛市中，超买状态可能维持很长时间。

### 5\. 核心仓与择时仓分开

为了避免频繁买卖破坏长期收益，我更倾向于「核心—卫星」模式。

一个示例：投资组合内部的两类权益策略

70% 核心长期配置

30% 卫星策略

仅是权益策略内部的示例比例，不代表总资产应全部投入股票，也不是普适的最优配置。

核心部分以持有、定期投入、低频再平衡为主。卫星部分才运用动量、均线、MACD、KDJ 和行业轮动，争取改善风险收益特征。

这样能避免一个很常见的问题：为了躲避一次小幅调整，把长期表现优秀的资产全部卖掉，之后却没能及时买回来。

### 五、第四层：真正决定风险的，是仓位管理

即使基金方向判断正确、技术信号也不错，如果仓位过大，依然可能遭遇无法承受的亏损。

### 1\. 先规定最大可承受回撤

用一个简单的情景计算：

假设股票资产下跌 30%，其他资产价格不变。

| 股票占总投资组合 | 组合大约下跌 |
| -------- | ------ |
| 20%      | -6%    |
| 40%      | -12%   |
| 60%      | -18%   |
| 80%      | -24%   |
| 100%     | -30%   |

这是单因素压力测试，实际股票可能跌得更多，债券、黄金也可能同时下跌。因此不能把这个表当成最大亏损保证。

更可靠的做法是，先决定愿意承受多大的组合风险，再反推股票、债券、黄金和现金的配置，而不是看到上涨信号就直接增加仓位。

### 2\. 设置硬性风险限制

我建议在自动化系统中至少加入以下检查：

* 组合最大权益仓位限制。

* 单一行业、主题和国家的集中度限制。

* 高相关性基金的合并风险敞口。

* 单只基金成交额、折溢价和流动性异常。

* 组合回撤达到警戒水平时强制人工复核。

* 行情中断、数据错误、指标缺失时禁止生成交易建议。

例如，买了三只科技主题 ETF，并不意味着完成了分散投资。它们可能主要暴露于相同的科技成长风险。

### 3\. 不要把止损当成无风险保险

止损、均线退出、移动止盈都有一定的风险控制用途，但会遇到跳空、假突破、反复震荡和无法及时成交等问题。

因此，风险管理顺序应当是：

合理配置 > 控制仓位 > 分散相关性风险 > 再考虑交易止损。

### 六、第五层：怎样证明策略真正有效？

建立技术指标评分以后，最重要的是进行科学回测，而不是直接拿高评分买入。

我建议至少比较四套策略：

| 策略                        | 比较目的           |
| ------------------------- | -------------- |
| A：长期买入持有                  | 判断择时是否真的创造价值   |
| B：定期定额投入                  | 判断复杂择时是否优于简单执行 |
| C：MA200 趋势过滤              | 验证简单趋势规则       |
| D：宏观 + 估值 + MA + MACD/KDJ | 验证复杂规则的增量价值    |

要回答的不是「策略 D 赚钱吗」，而是「它在相同风险、相同现金投入、扣除费用后，是否稳定优于 A、B 和 C」。

回测必须满足以下条件：

* 避免未来信息：当天收盘计算出来的指标，不能假设当天早些时候就已经知道。

* 样本外测试：一段历史用于研究规则，另一段完全独立的历史用于检验。

* 包含真实成本：手续费、价差、滑点、申赎规则与折溢价。

* 跨行情检验：上涨、下跌、震荡及突发流动性冲击时期都要评估。

* 防止过度拟合：不能尝试几千组参数后，只展示其中收益最高的一组。

* 跟踪风险表现：重点观察年化收益、最大回撤、夏普比率、换手率、收益稳定性和参数敏感性。

一个复杂策略若只能在少数年份、少数基金、某一组精确参数下成功，暂时不能认为它具有可靠预测能力。

在完整系统中，我建议一只基金的决策界面显示三个互相独立的结论：是否值得长期配置、现在技术趋势是否适合建仓、如果买入允许配置多少资金。

这样可以避免把一个简单的 MACD 金叉直接解读成「值得大额投资」。

### 3\. 长期应该升级成什么系统？

数据采集中心

ETF行情 · 宏观经济 · 估值 · 基金费率 · 历史净值

策略与评分引擎

经济周期 · 资产排名 · MACD/KDJ · 趋势识别

风险与组合管理

最大仓位 · 集中度 · 波动率 · 回撤 · 现金需求

自动观察台 + 条件提醒

机会变化 · 风险警告 · 评分原因 · 人工审批

我建议采用以下工作节奏：

| 频率       | 自动执行的工作           |
| -------- | ----------------- |
| 每个交易日收盘后 | 更新技术指标、分数、风险状态    |
| 每周       | 排名候选基金、监控资金与趋势变化  |
| 每月       | 更新宏观变量、估值、基金费率和质量 |
| 每季度      | 组合再平衡、风险归因、策略表现评估 |
| 每半年或每年   | 样本外验证、规则审计、数据质量检查 |

真正实现宏观和估值自动化，还需要加入严格的数据发布时间管理。比如某个经济指标在 10 月 15 日公布，回测时不能假设 10 月 1 日就已经知道它。

### 八、最终怎么选择投资策略？

我建议先把这套系统当成一个研究项目，而不是直接投入全部资金。

阶段一：建立被动投资基准

明确个人投资周期、最大可承受回撤、权益与低风险资产比例，选取分散且低成本的基础基金。

阶段二：测试简单择时

只测试长期趋势、少量动量指标和低频再平衡，确认它们是否改善组合回撤与风险调整收益。

阶段三：增加宏观和估值

判断额外数据是否真的提供了预测增量。如果复杂度增加而样本外表现没有改善，就保留简单策略。

阶段四：模拟运行，再小规模实盘

对比实际信号与回测假设，监控交易偏差和风险。只有经过足够检验，才逐步提高使用比例。

### 我的最终建议

你提出的「经济周期 + 基金方向 + KDJ/MACD 择时」是一个可以深入研究的基础。但我认为最值得投入精力的，不是寻找一组神奇指标，而是把以下三个问题做扎实：

第一，哪些资产长期值得持有？ 依靠基本面、估值、分散化和基金质量。

第二，现在适合承担多少风险？ 依靠趋势、波动、宏观环境和组合风险预算。

第三，如何证明买卖规则增加了价值？ 依靠严格回测、样本外检验、交易成本和真实业绩跟踪。

能够提高胜率的系统，不一定能提高最终收益；能够降低历史最大回撤的系统，也不保证未来不会发生更严重的亏损。

如果继续把这个项目完善，我最优先开发的将是\*\*「ETF 全市场筛选 + 多维评分排行榜 + 买卖信号解释 + 组合仓位建议 + 自动提醒」\*\*，保留人工确认交易，不急于做全自动下单。
