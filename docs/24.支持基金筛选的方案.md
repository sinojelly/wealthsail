## 目标与现状

用户能从宏观历史了解环境，选择A股方向/指数，再比较基金收益风险、成本和技术趋势。所有结果可追溯来源、区间和限制。技术趋势、净值区间位置不代替投资价值。缺必要证据时返回具体缺口，不用总分掩盖。

近期 `6059700`建立方向/指数/基金查询，`f7a5c6e`建立技术快照和刷新，`d2f3973`接入v3.3，`2fdffed`修复发布窗口和页面回归。继续复用；本轮补自动历史、来源登记、收益风险与证据链。回测、经理评价、个人化交易和仓位建议独立推进。

## 架构

Worker定时/耐久刷新 → 供应商适配器 → 规范化/质量检查 → 来源事实与不可变快照 → 确定性分析 → 数据库查询API → 投资机会页面。

- integrations：字段/单位转换、超时和单来源失败隔离。
- market：历史、日历、口径/质量；不生成投资结论。
- indicators：纯函数技术和收益风险；版本/参数明确。
- investment：独立证据、资格闸门、组合查询；API不访问供应商。
- jobs：独立研究池每日采集与计算；页面按对象刷新复用Worker耐久任务租约。每日全池任务通过不可变输入哈希幂等，并在06:30–08:30内支持重启补跑。
- reference：经核验身份、真实跟踪关系、供应商映射/发布窗口。

全池研究刷新由调度器持有独立后台任务，慢供应商不会阻塞后续报告tick；同进程不重叠，停止时取消并等待清理。它不使用跨进程租约，窗口内重启可重跑并由快照哈希去重；跨日忙时保留当天补跑机会，窗口外等待次日。同步HTTP线程不能强制终止，供应商调用仍有独立超时。页面对象刷新继续使用已有耐久队列。

## 自动采集

| 数据 | 来源 | 历史/更新 | 口径 |
| --- | --- | --- | --- |
| PMI、CPI同比、PPI同比、M2同比 | AKShare宏观历史，保留上游URI | 最近5年月度；每日重取修订 | 月份是观察期；未知公布时间不形成可信周期结论 |
| A股指数行情 | 已核验provider_symbol的指数日线 | 最近5年真实交易日 | 指数价格趋势不是基金总回报 |
| 场内ETF | 后复权真实OHLCV | 最近5年可得覆盖 | 技术和复权价格口径收益风险，成交量不作价格复权 |
| 场外基金 | 单位净值/供应商日增长率 | 最近5年可得日线 | 净值只画走势；独立核验后由日增长率复合收益指数 |
| 指数估值 | 登记供应商/指数/方法 | 实际可得区间 | 同口径PE/PB分位；负PE或历史不足不给低估结论 |
| 基金成本 | 真实费用来源 | 定期刷新保留日期/URI | 管理、托管、销售服务费；未知为null |

实现依据是锁定 AKShare `1.18.94` 本地源码及[官方宏观接口](https://github.com/akfamily/akshare/blob/main/docs/data/macro/macro.md)、[基金接口](https://github.com/akfamily/akshare/blob/main/docs/data/fund/fund_public.md)、[指数接口](https://github.com/akfamily/akshare/blob/main/docs/data/index/index.md)。联机可用性独立验收，不能直接依赖已从锁定版本移除的接口。

## 身份、候选池和质量

基金用instrument_id；市场与代码共同识别。A/C、ETF、联接基金独立。真实跟踪关系含有效期和URI，不按名称猜测。来源登记后后台自动更新；不要求用户逐对象点击。候选池包括经核验研究来源的基金和有效映射基金，独立于持仓。主数据可以搜索，不代表全部有研究覆盖。

登记命令：`python -m scripts.register_investment_reference --input reviewed.json`。JSON的indices登记指数来源，links登记真实跟踪关系，funds登记instrumentId/sourceUri/publishHour/sourceVerified/returnSeriesVerified。后者默认false；必须核验供应商日增长率口径后才能设为true。登记仅合并metadata.research，保留其他元数据；迁移074只向Worker授予metadata列更新权限，不扩大API或标的身份写权限。

宏观复用market_observations/source_snapshots及修订；行情复用investment_analysis_snapshots不可变输入。估值和成本独立存储。观察期、首次获取、可得时刻、公布时刻不混用；历史修订不能伪装为当时可得。

A股SSE/SZSE/FUND_CN研究明确复用落库SSE日历；缺日历输出UNVERIFIED，不按工作日猜节假日。跨境披露/交易日历独立。坏值、重复冲突、缺日、过期、未知来源阻止完整评分和资格。旧指标可以查看，但不作为当前机会证据。

日历必须逐日完整覆盖至已公布截止日，不能用旧日历尾部推导当前READY；已知关闭日可以保留上次交易日。每日06:30（含周末/假日）先检查并更新真实日历，再更新研究数据；启动补跑窗口到08:30。077仅允许Worker插入日历事实/修订is_trading_day，不扩大API和market身份写权限。合法非交易日净值披露保存为navObservations，列表最新净值及日期取最新披露，收益窗口按真实交易日采样；指数/ETF不接受额外非交易日行情。旧快照日期晚于修订后最新交易日时，列表与详情均标UNVERIFIED并撤销资格。

## 分层评价

| 层 | 输出 | 阻止结论的条件 |
| --- | --- | --- |
| 宏观观察 | 多年月度历史、连续月份变化、覆盖 | 未核验发布时刻/不足/间断/过期不给可信方向推荐 |
| 指数价值 | 同方法估值、实际窗口分位、股息事实 | 缺失、负PE、方法未核验、历史不足或过期 |
| 基金收益风险 | 63/252日收益、最大回撤、20日波动、区间 | 累计/原始净值、未核验收益口径、缺日/过期不得入选 |
| 产品质量 | 成本、交易状态、关联来源及未评估项 | 未知成本、映射或交易限制；跟踪/流动性缺失不能称完整排名 |
| 技术趋势 | technical-v1及适用分项 | 无真实OHLC不得完整评分 |
| 组合适配 | 个人风险预算、相关性与期限 | 未接入时始终尚未评估 |

收益为P[t]/P[t-n]-1；最大回撤来自运行高点至后续低点；波动为最近20个日收益样本标准差乘sqrt(252)。指标是明确区间的历史事实，不是预测。

资格采用版本化透明条件和缺口清单，不用不可解释综合100分。同指数先比较口径、覆盖和成本，再看收益风险/趋势。必要证据缺失时只能称“证据不足”；完整投资判断仍需跟踪质量与组合风险。

当前 `value-evidence-v1` 是可解释的研究过滤规则，参数是未经样本外验证的研究假设：PE_TTM与PB的5年目标窗口均至少756个真实观察值且跨度至少3年，时间分位均不超过30%；明确披露的管理/托管/销售服务费合计不超过0.8%/年；可比收益历史至少253个观察值，区间最大回撤不超过35%；唯一有效且已核验的跟踪指数映射。分位公式 `(小于最新值的数量+0.5×等于最新值的数量)/样本数×100`，不是净值极值位置。费用以获取时刻作为45天更新期限，不伪造披露日期；各来源披露窗口独立。精确回撤使用Decimal，`performance-v2`防止浮点误拒绝门槛边界。

指数来源登记可附 `valuation={provider:LEGULEGU,symbol,sourceUri,verified,publishHour}`。symbol只接受锁定库实际支持的精确指数名；未覆盖的A股指数显示不支持，不能把另一指数估值移用。076新增只追加的基本面快照，API只读、Worker仅查询与插入；供应商请求期间释放DB连接。

真实联机已发现当前沪深300估值接口只有61期PE/PB，而行情/NAV可取得五年历史。适配器没有历史截断，这是本次上游实际覆盖，未确认其原因。因此估值必须保持历史不足，不能宣称实际基金已完成多年价值判断。中证历史源缺PB；理杏仁双指标长历史需要账户Token且须独立方法核验，选择见ADR-002。接入可核验长历史源、正式参考映射和策略有效性仍是部署前置，详见 [本轮验收](../ai-review/investment-data-evidence-acceptance.md)。

查询重新核对当前来源/收益口径、唯一映射、估值配置、交易日和费用期限；撤销后旧快照立刻退出候选。列表和诊断同时撤销资格，历史事实仍可查看。宏观CONFLICT/UNAVAILABLE保留状态且不计连续变化，最新坏修订不回退旧值。

## 接口和验收

`GET /investment/market-context?months=36`范围1–120个月，返回每指标历史、单位、变化、实际覆盖、来源与质量。研究analysis接口分别返回技术、收益风险、估值和成本证据，各层截止期独立。screener组合筛选/服务端分页/空值排后；刷新入耐久后台任务。读取重新检查新鲜度，过期撤销评分和资格。

每项先RED再GREEN。核心测试包括中文月份/修订、负PE、未知费用、净值分红跳变、缺日/晚发布、周末、失效映射、无instrumentId和过期快照。单元、隔离数据库、真实供应商、浏览器桌面/手机分别记录，状态与提交仅维护实施计划。
