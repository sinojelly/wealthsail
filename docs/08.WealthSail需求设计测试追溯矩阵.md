## 1. 使用规则

1. 新需求先在 PRD 分配唯一 ID，再进入本矩阵；
2. L0/L1 Must 至少有一个正常测试和一个异常/安全测试；
3. `PASS` 必须填写 run ID/报告链接、commit、环境、migration 和 fixture/model/provider 版本；
4. UI 原型测试通过只证明原型交互，不得把后端/系统用例改为通过；
5. 需求变更时同步更新设计章节、API/表、测试和兼容影响；
6. 需求退休保留行并标为 RETIRED，不复用 ID。

## 10. 当前实现边界

截至本文基线：

- `figma/v1-mobile` 是模拟数据 React 原型，其测试只证明原型 UI 行为；
- 仓库已有 001–008 Migration、内存账本/基金估值原型、企微 Adapter 原型、Skill 与部分 Python 测试，但尚无完整生产 Domain API、Worker、Repository、真实 Auth/企微联调、Web 工作台和数据库执行证据；
- 因此本矩阵的正式系统、数据库、Provider、Agent 和真实 WeCom 用例保持 `NOT_RUN`；本地 Python 通过不等于这些用例通过；
- 后续每次实施只更新真实执行过的具体行，禁止批量把计划用例改为通过。
