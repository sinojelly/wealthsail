# 动态研究目录、分批审核与零 AI 恢复

本次只在本地实现、测试和提交，没有推送、部署、连接 NAS/生产数据库或调用真实模型。

## 发现与正式投资计划分开

`topicCatalog` 是研究发现目录，`valueDirections` 是本批严格验收的正式投影。主题、服务器产品行业、相关行业、已完成风险核查分别记录。严格别名必须同范围；多行业组合必须逐范围审核。`RARE_EARTH_METALS` 新闻分类不能代替 `NONFERROUS` 基金行业核查，“工业金属”也不被强制视为“有色金属”同义词。

主题状态为 `FORMAL`、`OBSERVATION_ONLY`、`PENDING_REVIEW`、`QUARANTINED`。每项展示原因、影响、采取措施、待补证任务和匹配依据。基金计划仍使用服务器核实的产品身份及规范行业；缺少完整审核的计划不能投资。目录 API 整体 `actionable=false`，不返回计划、价格、研究跟踪入口或推送许可。`investmentEligible` 仅表示冻结时点的严格资格，不是当前买入授权。

逻辑目录可跨独立研究批次累计，不再受总共8主题/10行业限制。**每批资源仍有界**：最多64项发现、8个正式方向、10个审核范围及对应50条五类风险查询计划、24条来源、一次模型调用。发现和兼容正式方向按 key 合并后，一份目录最多登记72项；分页支持12/20/30项，不启动模型。输入最多4 MiB，原输出最多2 MiB，模型执行沿用配置且不超过1200秒；这些限制不是精确金额或实际搜索次数承诺。

服务器在输入中冻结 `researchDiscovery.auditManifest`：范围、90日证据窗口、版本、任务及预算。Prompt、验收和恢复使用同一份清单，不在恢复时重新分配审核名额。预算不足保留 `PLANNED_DEFERRED` 等待办和覆盖缺口，下一次**独立获授权的研究**可轮换选择积压范围；不会自动循环调用模型，也不增加本批搜索/来源预算。新时间补证属于新批次，不反写旧证据时钟。

五类反方核查不删除、不改写。`UNVERIFIED` 不算完成，也不改成 `NOT_FOUND`；`FOUND` 的近期性、引文、原文核验及行业主体要求仍保留。结构化 `NOT_FOUND` 不等于有独立搜索执行回执，`searchExecutionVerified=false` 会如实显示。

## 正式、部分观察与历史兼容

V2逐项验收、确定性行业关联、依赖闭包后，用原始输入、来源核验结果和同一证据时钟完整调用严格 `validate_report()`，执行历史行业风险合并、价格/净值保护和评分。只有安全门及严格复验都通过的正式投影才进入首次 `READY`；页面显示部分覆盖和隔离说明。无法匹配的观察内容独立保留，旧 `READY` 消费者不读取目录。

高重要性依赖、系统性负面信号、无法证明归属的负面证据及可能影响保留方向的风险缺口会阻止自动发布。格式不合格的主题也不能使其原始系统性风险信号消失。系统/数据库异常仍抛出，不通过吞异常获得成功。没有安全正式结果时，维持 `FAILED` 与可用部分成果。

V1冻结资料继续使用V1修复契约；V2未来研究与离线恢复共用确定性核心。原 `FAILED`、`INITIAL`、冻结原文、Token计量、调度名额及pipeline终态均不更新。历史衍生版仍使用101迁移的不可变记录、管理员生成、另一管理员审核、显式历史只读发布，不进入旧 `READY` 的交易、跟踪、行业风险继承、机会提醒或自动通知。

只读文件预览、权限、配额、生成/审核/发布步骤见[历史恢复操作说明](research-repair-operations.md)。V2恢复同样不抓取新资料、不调用AI，也不能通过客户端提交替换原文或新证据。

## 迁移与运维检查

未来部署应先备份并依次应用099–102迁移、执行权限 readback，再更新匹配API、Worker和前端。本次未执行生产操作。102新增不可变主题快照/条目及窄权限写函数，启用并强制RLS；API只读，手动批次按源租户隔离，自动公共批次只共享安全投影。运行时没有任意删除权限。

目录随原归档待办持久化，由补偿事务写入。归档失败不撤销已经严格提交的正式报告。每目录正文最多1 MiB、每项16 KiB，并按数据库实际JSONB大小检查；资源超限保留有限遗漏凭证，明确显示目录不可恢复及原材料入口，不把零条目录假装成完整覆盖。数据库或程序错误不按“资源超限”吞掉。

灰度前应在隔离测试库确认迁移、RLS、只读API、分页及归档补偿；检查普通用户没有交易入口，管理员能追到原INITIAL与冻结材料。容量需持续监控：每批有界不代表长期总量有界；本轮没有赋予Worker清理历史的权限，也没有实施自动保留期删除。
