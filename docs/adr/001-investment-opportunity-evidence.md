# ADR-001：可追溯数据与独立证据，Alpha-V2采用双轨机会发现

- 状态：2026-10-17由Alpha-V2部分替代；来源、精度、权限和事实边界继续有效。
- 初始日期：2026-10-13。
- 范围：数据采集、历史、证据与机会发现。
- 现行规格：[设计28](../28.WealthSail宏观经济研究模块设计.md)；架构：[设计24](../24.支持基金筛选的方案.md)；实施：[计划38](../../ai-review/38.WealthSail-AlphaV2清理与双轨买卖区间实施计划.md)；[历史归档](../../.archive/alpha-v1/README.md)。

## 背景与保留决策

继续扩展现有React/FastAPI/PostgreSQL与Worker，不另建账户、权限、事实存储或账本。Worker采集、API读取已落库事实；来源、修订、算法与日期可追溯。观察月份不冒充发布时间，累计净值不冒充总回报，指数点位与复权/NAV研究坐标不冒充ETF实时可挂单价。

宏观、指数价值、基金收益风险、成本/跟踪质量、技术趋势、组合适配和真实PIT分别输出状态。真实日历、身份和来源核验仍约束所依赖的输入；坏值、冲突、过期或未知不提升信任。默认五年采集/36个月宏观窗口是目标，实际样本独立声明。供应商可用性、数据覆盖、代码正确性与策略有效性分别验收。

## Alpha-V2替代的决策

旧“完整价值/产品/盈利/PIT全部通过才允许发现任何候选”的合并闸门退出现行机会发现。PB、完整长期估值、产品评分和505期REAL_PIT不足是独立警告，不阻断满足其他真实条件的LEFT_VALUE/RIGHT_TREND。两轨的准确阈值、状态、公式和PARTIAL定义只维护于设计28，不在ADR复制一套。

MA200需要真实200期且仅作可选观察；缺MA200不借MA60。缺OHLC不伪造ATR，有均线/布林的有效参考区间可部分展示。旧统计方法历史不足仍保持原状态，不靠下调样本门槛宣称回测/价值已验证；候选不代表收益保证或个人风险放行。

私有study沿用actor/tenant权限、追加版本和真实成交约束；本轮只在现有版本JSON冻结计划，不新增迁移或公共经验库。私人复盘不进入公共模型，用户意向不自动形成成交。

## 后果

资料缺口可以定位到具体证据或价格字段，机会发现不再因无关缺口全局WAIT。保留真实来源、金融精度和账户权限；本轮范围、验证结果和未做扩展见计划38，旧评审仅作为历史证据。
