# ADR-001：投资机会采用可追溯数据与分层证据筛选

- 状态：已接受（用户2026-10-13授权整理设计与TDD实施）
- 日期：2026-10-13
- 范围：数据采集、历史、评价与筛选
- 关联：[设计](../24.支持基金筛选的方案.md)、[计划](../../ai-review/18.WealthSail-基金筛选页面功能扩展实施计划.md)

## 背景

已有页面和技术分析骨架，但自动数据、来源配置与价值证据仍有断点。旧计划的重复阶段混淆页面验收与真实投资研究能力。

## 选项

1. 宏观/技术/价值混为总分：快，但掩盖口径差异与缺失证据。
2. 外建量化系统：隔离明确，但重复权限、账户、任务和事实存储。
3. 扩展现有模块，独立事实和评价、明确资格闸门：需要来源治理，能复用架构。

## 决策

采用3。Worker自动采集已核验研究池，API只读落库。观察月份不冒充发布时间，累计净值不冒充总回报，指数价格不冒充基金收益；输入、修订和算法可追溯。

宏观、指数价值、基金收益风险、成本/跟踪质量、技术趋势、组合适配分别输出。透明版本化条件决定研究资格；缺失/过期/未知给出原因，技术分数和净值低位不决定长期价值。

默认采集5年、宏观观察36个月，实际覆盖独立声明。A股研究明确复用SSE真实日历，跨境独立。逐项TDD并提交；供应商与策略有效性分别验收。

2026-10-14实现补充：日历须逐日完整覆盖已公布窗口；日历尾部缺失或旧快照晚于修订后交易日均撤销资格。保留合法非交易日NAV披露与最新净值展示，收益风险按已核验交易日采样。当前真实PE/PB源仅61期，保持历史不足，后续接入长历史源须核验口径，不能下调样本门槛填满候选。

## 后果

同口径基金可比较，缺口可解释。来源登记后自动更新，未经核验不能提升信任。暂不生成个人化交易/收益预测。只维护一份实施清单，旧记录保留Git。
