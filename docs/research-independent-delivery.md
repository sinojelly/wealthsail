# 每日研究的独立交付合同

本轮以 `ef47f9fd-88a3-424a-8584-a562843805cc` 的本地冻结材料做回归，目标是未来稳定交付。未恢复、发布或改写该历史FAILED记录，未调用真实AI、连接NAS或生产数据库。

## 原失败路径与新的边界

| 原失败路径 | 现在的处理 | 投资边界 |
| --- | --- | --- |
| 新闻的临时概念被当成不存在的正式方向，整份报告拒绝 | 独立验收新闻来源、时钟和分析结构；保留未解析引用 | 未解析概念不成为基金行业或正式方向 |
| 没有可投资方向，动态主题和新闻失去关联身份 | 允许零正式方向，主题和新闻独立进入只读视图 | 不制造基金计划，不以数量补足资格 |
| 一条不同ID未知Web动作使整条流PARTIAL，全部任务证明丢失 | v2逐动作证明；未知动作只隔离自身，可信完成搜索仍精确匹配 | 同ID冲突撤销该ID；无法归属的损坏仍全局保守阻断 |
| 一个基金方向失败连带独立新闻失效 | 收集式验收与主题目录分别保留安全成果 | 被移除方向及重大负面依赖保留于附件，不能靠隔离降低投资保护 |
| 删除方向使原歧义标识变成唯一，错误重挂到另一正式方向 | 使用原始完整正式命名空间计算可能依赖，再做风险闭包 | 歧义只扩大保守阻断，不能产生关联或资格 |

## 三类独立身份

- 经济新闻：`events` / `upcoming`，有来源、时间、重要性、传导渠道、条件情景、反方和观察点。引文核对与经济推理分开，`factVerification=UNVERIFIED` 不被改成事实已证实。
- 动态研究洞察：`topicCatalog`，允许新主题、跨范围、暂无基金或反方审核的观察。目录保存逻辑、未知项、后续观察和待补任务，按稳定key登记、分页和跨批留存；同key冲突不选择性拼接事实。
- 正式投资方向：`valueDirections` / 具体基金计划，继续核对服务器产品身份、规范行业、五类反方审核、引文和事件时点、历史负面保护、双轨价格及入场条件。

事件关联使用有界 `relatedTopicKeys`、`relatedFormalDirectionKeys`、`relatedMacroConcepts`、`candidateConceptLabels`。服务器 `referenceResolution.version=research-event-links-v1` 保留每个解析方式和未解析原因。只做精确或ASCII大小写、下划线/连字符的唯一规范化，不按标题相似度匹配，不映射成基金行业。宏观概念和候选标签始终是声明，不能冒充已登记身份。

V2旧 `affectedDirectionIds` 中真实正式依赖仍受闭包保护；合法主题可成为只读关联，未知概念保留为未解析候选。V1旧严格引用语义保持兼容。新schema要求模型输出独立字段，Python默认值支持旧冻结材料；原材料不变，新离线结果使用新的校验指纹。

目录新增引文核对覆盖分数：已核对来源引用数/所有来源引用数×100，零引用为0。它不评价机会回报、主题正确性或推理质量，不赋投资资格。行业、跨范围或动态分类也不构成审核授权。

## 交付状态与投资资格

附加 `researchDeliveryStatus` 与 `investmentQualificationStatus` 保存于现有主题目录覆盖，不新增数据库正式终态。每日接口另返回版本化 `economicResearch`，只读取本日当前可见run的INITIAL验收和主题覆盖，不借用上一份READY作为今日研究，不读取冻结私密原文。旧客户端可忽略该附加字段，原正式状态、选报及下游消费者不变。

| 状态 | 含义 |
| --- | --- |
| `VALIDATED_READ_ONLY` | 独立内容验收通过，存在已核对引文支持的新闻或主题；经济传导仍是条件推演 |
| `OBSERVATION_READ_ONLY` | 观察资料可保留，证据或组件仍待核实，不能宣称研究全面完成 |
| `UNAVAILABLE` | 没有可安全交付的独立内容或输入不安全 |
| `QUALIFIED_CANDIDATES` | 存在严格通过且安全发布允许的有基金计划方向，仍受实时入场保护 |
| `NO_QUALIFIED_OPPORTUNITIES` | 没有合格正式基金计划，不表示经济研究失败 |
| `BLOCKED` | 已提出基金计划但资格未通过，不能被只读交付状态放行 |

首页主状态由独立经济交付决定：`AVAILABLE`为已有可阅读成果，`PARTIAL`为已有观察资料但核验仍不完整，`PENDING`为待归档，`UNAVAILABLE`为暂无可阅读成果，`UNKNOWN`保留旧数据的不确定性。正式投资状态单列；正式FAILED不再把当日可读成果染成首屏失败。证据、隔离项或正文节选未完整时不宣称全面完成；旧报告仍保留作投资日报回退。

经济完整度采用版本化 `economicIssueCount`，与原 `issueCount` 分开。只有服务器明确判定的纯基金身份/价格计划错误，以及依赖精确指向这些计划的方向包装错误才不计入经济问题；来源、行业、事实、风险依赖、未知错误及清单/正文不全仍保守处理。已核实的负面新闻本身不代表研究不完整。旧摘要缺乏依赖证明时不猜测豁免，原验收和正式终态不变。

“今日信息总览”在上一份正式报告之前展示本日验收新闻、日历、宏观摘要及来源状态，复用只读安全投影。只读观察不存在计划价格和交易入口。归档未完成不展示待办正文；两个既有上下文GET在当前run待归档时前5分钟每15秒、随后每60秒刷新，归档完成、不可恢复、身份不匹配或错误恢复预算耗尽即停止。保留原请求有界重试，不触发模型或重新研究。

归档GET的最终错误现在允许同一run额外最多3次延迟恢复（15/30/60秒）和1次联网恢复检查；成功收到PENDING不重置该预算。原请求重试配置保留，耗尽后停止错误轮询，可通过用户刷新重新检查。无当前归档等待时保留普通上下文的原联网行为；不触发POST或AI。

## 自动研究23小时冷却

任何模式（手动、自动、旧DEBUG）只要已写入不可变的AI派发意图，随后23小时禁止自动派发新AI，不区分READY/FAILED/UNCERTAIN或尚无终态，也不依赖可能漏写的Token遥测。起点为最近 `dispatched_at`，不是验收或归档结束时间；恰23小时解除。派发记录已提交后崩溃，无法证明是否产生AI消费时也保守保护。采集、质量、预算或CLI预检阶段明确未派发AI的失败不产生记录，不续期冷却。

调度入口在采集前检查，真正模型派发在原全局事务锁内、创建run/guard前再次检查，防止自动采集期间插入手动研究。冷却返回安全的 `COOLDOWN/ResearchCooldownActive`，不写虚构FAILED或消费自动名额；已领取的预模型pipeline在派发复查遇冷却时以MISSED结束并标明原因，不越权改写其他owner的pipeline。该次自动调度跳过，后续仍按原日历和启动窗口，不因冷却扩展窗口或重新使用旧批次。

每日接口 `automaticResearchCooldown` 仅公开是否生效、23小时、最近派发与自动准入时刻，首页明确提示只限制自动研究，下一计划避开冷却。管理员手动入口保留原权限、幂等、消费提醒和全局互斥；冷却到期也不能释放尚未确认退出的模型guard。本轮不增加数据库权限、终态或迁移，不改历史记录。

覆盖区分别记录发现数、具有已核对来源的主题数、待核实主题数、来源支持比例、服务器可评估基金方向数、严格合格基金方向数、有效新闻/日历数和未解析引用数。来源支持比例仅以实际登记的发现主题为分母，正式方向补项不抬高覆盖；零发现时比例未知。真实案例显示64个发现、2个具备已核对来源支持、62个待核实、3.1%，不再说全部经济研究已完成。主题有已核对来源也不代表其推理已证实。未获资格的固定原因按类别展示，非排他计数不能相加当总数。来源逐项展示 `SOURCE_CHECKED` / `UNVERIFIED` / `UNAVAILABLE`，保留HIGH、负面情景和未知项。

只读新闻、主题和候选标签没有交易、跟踪或推送入口。既有独立纯量化扫描入口仍按原基金身份、量化、价格及实时保护执行，不应将其解释为主题或行业审核已经完成；本轮未把主题接入该入口。

## 逐动作执行证明

`research-execution-v2` 保存有界 `actionProofs`、固定状态与 `proofBarrier`。仅受信CLI stdout观察器产生证明，完整 `item.completed` 搜索精确匹配查询哈希，再绑定研究ID、冻结manifest、输入时点和原校验时钟。

`UNKNOWN_ACTION`、`INCOMPLETE`、`CONFLICT` 等不授权自身。不同ID的未知动作可以与有效完成搜索共存；同ID不同完成或Web/非Web冲突会撤销该ID。坏JSON、重复JSON键、无法归属的截断、缺少turn完成、条目溢出等触发全局barrier。2 MiB响应超限摘要仍清除全部证明并明确原因，保留原研究正文。

旧v1 COMPLETE沿原规则读取，旧v1 PARTIAL不能凭哈希交集升级。本次真实导出没有原始CLI JSONL：能确认15次Web调用、52个查询哈希中50个匹配预设任务，但无法证明完整动作协议、顺序和未知动作类型，因此原有效执行证明维持0。未推测增加动作白名单；目前仍仅识别 `search`、`openPage`、`findInPage`。真实NAS v2兼容性仍需原始事件样本的离线核验，本轮协议形状测试不替代该验证。

匹配进度独立分为全部计划匹配、部分计划匹配、存在未归属计划的额外查询、未观测和未核验。48/50且无额外查询显示 `EXECUTION_PARTIALLY_MATCHED` 和48/50；额外查询保留单独提示。只修正诊断，不修改逐任务精确匹配、证据归属、来源核验或风险解除权限。

## 新闻身份与风险保留

V2新闻以完全一致的规范空白标题、事实摘要和阶段生成确定性身份，不以共享URL当作同一新闻；日历另包含日期/时刻与观察点。相同事实的多个来源可合并，最高重要性、全部来源、负面情景及未知项均保留；任一合并超过原字段上限则保留独立观察，不截断风险。相同事实跨日身份稳定，摘要有新事实则为独立更新；没有引入模糊或语义相似度合并。V1旧身份规则保持不变。身份变化只影响新验收结果，不更新历史报告。
