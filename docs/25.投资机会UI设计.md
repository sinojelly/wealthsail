## 研究路径和布局

路由/fund-screener、导航“投资机会”。直接搜索和市场→方向→指数→基金均可使用。基金选中保持父指数，面包屑完整。全局搜索跨市场定位，按instrumentId/市场区分；未知关系显示“未确认关联指数”。

顶部搜索、默认折叠宏观观察、市场/方向导航。左指数与基金表，右对象诊断；“综合判断/技术趋势/产品质量”页签，手机单列。各评价层分开显示，只按真实已落库事实绘图。

## 宏观历史

默认36个月，可切换12/36/60个月。显示单位、观察期、来源、质量、历史折线及实际样本数。最近变化只比较连续月份，缺期不比较。公布未知写“公布时间未核实”；不推导无模型的经济周期或方向推荐。加载、读取失败、未采集明确区分。

## 筛选和诊断

默认全部候选/名称排序；服务端分页、空值排后，条件与排序写URL。主数据覆盖和研究覆盖分别描述，不称全市场价值榜。“净值区间位置”不得改称估值分位。价值研究筛选依赖后端证据资格，不由前端价格低位或技术高分判断。

列表最新值注明单位净值、累计净值或后复权价格；经核验收益指数不能冒充净值。非交易日合法净值披露仍可作为最新净值，其披露日期与收益风险的交易日截止分别显示。

综合判断显示指数估值、基金收益风险、产品成本、技术趋势、组合适配各自状态、日期、方法与缺口。证据不足不生成总分或买卖建议。

技术趋势区分单位/累计净值、复权ETF价格、供应商收益指数、指数价格。历史窗口可以选择；收益风险展示63/252日收益、区间最大回撤、20日波动及实际区间。缺失为—，过期保留历史事实但撤销资格。

产品质量显示已采集管理/托管/销售服务费及来源日期，跟踪误差、流动性、折溢价未评价明确标示，不伪造完整质量排名。

## 操作和验收

加入自选基金复用真实接口；指数关注未支持时禁用。更新研究数据入后台队列并轮询，完成刷新、失败保留旧历史；过滤和分页不触发采集。

桌面/手机验证全局定位、父子关系、URL刷新、宏观窗口、历史/风险口径、资格缺口、空状态、重复更新、自选和权限。测试数据与真实供应商验收分开记录。
