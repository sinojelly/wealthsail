## 最新版 UI 评价

figma\v3.3 这版可以作为 WealthSail「投资机会中心」的正式 UI 基线，不建议再大改布局。

相较前几版，它已经解决了最明显的拥挤问题：宏观信息默认折叠、市场与方向筛选压缩成导航、左侧统一选择指数和基金、右侧只展示当前研究对象的诊断。

从截图来看，页面的视觉层级、留白和操作路线都已经比较清楚。用户可以先确定研究方向，再挑选指数和基金，不必反复上下滚动。

正式实施前，我只建议优先修正四点：

1. 保留指数与基金的父子选中关系。 例如选中 `510330` 时，左侧「沪深300」仍保持选中，顶部显示完整路径 `A股 / 宽基 / 沪深300 / 510330`。
2. 明确全局搜索的跳转行为。 搜索任意指数或基金后，应自动定位其市场、方向及关联指数，而不是仅筛选当前列表。
3. 区分“关注指数”和“加入自选基金”。 现有 WealthSail 自选接口支持 ETF、基金等标的，但尚未按本次设计完整支持指数。指数研究模式不能直接假设复用相同接口。
4. 让右侧综合判断真正成为决策摘要。 当真实数据接入后，优先回答“为什么关注、风险是什么、什么条件变化值得重新评估”，而不是只显示指标或评分。

还有一个重要原则：宏观、指数趋势、基金质量、组合风险应当分别计算，再形成可解释的研究结论。 不能用一个综合分数掩盖不同层面的不确定性。

下面我会把这套页面整理成正式设计规范，同时明确哪些能力 WealthSail 已有、哪些需要开发，以及用户如何用最少步骤完成一次研究。

### 我特别强化了三个方面

第一，让用户用最少操作完成研究。 知道基金代码就直接搜索；不知道买什么就从宏观和投资方向进入；已有持仓则直接看风险变化。不强制所有用户走相同流程。

第二，让数据真正自动流动。 明确宏观经济、指数行情、ETF、场外净值、基金费用和持仓数据各自怎么采集、何时更新、怎样计算，以及怎样自动传递到最终诊断。

第三，让投资结论可靠、可解释。 任何评分都要能追溯来源和计算方法；数据不完整就保留空值，不生成虚假的买卖信号。长期价值、技术趋势、基金质量和个人组合风险分别评价。
