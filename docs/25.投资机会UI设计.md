## 页面结构

路由`/fund-screener`、导航“投资机会”。保留“今日重点 / 市场证据 / 我的跟踪与复盘”三个入口及下方唯一指数/基金工作台；顶部研究可展开/收起。删除已废弃重复研究板、雷达与诊断时，先核实活跃引用及仍承担的功能。

直接搜索和市场→方向→指数→基金均可使用，选择与筛选写URL、支持刷新恢复。按instrumentId/市场区分标的，选中基金保持真实父指数；未知关系显示“未确认关联指数”。服务端分页、空值排后与手机单列布局保留。

## 今日重点与双轨计划

分别显示LEFT_VALUE、RIGHT_TREND的候选/观察/资料不足状态、真实触发依据、输入日期和缺失项。PB、PIT或MA200不足是相应证据提示，不把已成立的另一分支或轨道重新锁为全局WAIT。候选不是收益保证、历史验证或个人风险放行。

有真实锚点时显示入场区间、止损和T1/T2；无真实ATR时可展示均线/布林参考区间，标明PARTIAL及“缺真实高低价/ATR”，止损和目标为空。不用占位0或猜测波幅填齐卡片，不合理价位只关闭受影响字段。明确单位、币种、价格口径、算法版本和观察日期：指数点位、复权价格、净值研究坐标不能写成ETF实时可挂单价。

事件展示事实、潜在影响、反方条件和来源，程序计算价格以同标的真实锚点为准；未来日程与已发生事实分开。保留旧READY报告原日期及实际执行状态，页面刷新时间不冒充研究完成时间。红色个人风险仍需原有完整已确认预算证据。

## 市场证据与基金工作台

宏观默认36个月，可选12/36/60个月，显示实际样本、单位、来源、观察期、连续月变化与真实曲线；缺期不连伪趋势，公布未知明确标注。数据尚未采集、加载失败与数值为零区分。选单项才挂载完整宽图，桌面图/解释并列、手机上下排列，来源和方法按需展开。

估值、基金收益风险、产品成本、技术趋势和组合适配各自显示状态、日期和限制。净值区间位置不改名估值分位，价格回撤不冒充含分红基金收益，未知产品费用或跟踪误差不包装成完整质量排名。旧质量深链和当前选择保留，主数据覆盖与实际研究覆盖分开描述。

## 我的跟踪与复盘

加入跟踪沿用现有就地确认/取消和观察期流程；确认后服务端冻结真实研究与actionablePlan到现有私有版本JSON，包含价位、口径、日期、轨道及缺失项。后续行情或策略更新不覆盖已保存版本；修订追加新版本。

主题、笔记、ACK、启停和真实成交关联均按原tenant/actor权限。意向不等于成交，只关联本人可见已确认fill，不自动入账/下单。保留DAY成交先后未知与缺收益事实UNKNOWN；私人复盘不进入公共模型或经验库。

## 操作与验收

自选基金使用真实接口；对象刷新入既有后台队列，完成刷新、失败保留旧历史。GET、搜索、分页、图表、窗口切换及保存跟踪不额外调用模型。

验证桌面/手机无溢出、双轨状态及PARTIAL语义、价格单位/空值、URL恢复、宽图详情、冻结跟踪和角色隔离，并回归导入、持仓、报告与现有操作。测试夹具和真实供应商/浏览器验收分别记录，实际结果见计划38。
