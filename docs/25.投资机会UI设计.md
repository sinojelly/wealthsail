## 页面结构

路由`/fund-screener`、导航“投资机会”。保留“今日重点 / 市场证据 / 我的跟踪与复盘”三个入口；当前自动发现及扫描跟踪流程以[设计28第26—34节](28.WealthSail宏观经济研究模块设计.md)为准。今日重点不要求任何下拉筛选，依次显示宏观总纲、系统综合价值方向及基金买卖计划、关键要闻与日程。五主题下拉和静态关联资产面板移除；下方唯一指数/基金工作台与搜索作为按需展开的手动工具，明确标的深链仍可直接研究。

直接搜索和市场→方向→指数→基金均可使用，选择与筛选写URL、支持刷新恢复。按instrumentId/市场区分标的，选中基金保持真实父指数；未知关系显示“未确认关联指数”。服务端分页、空值排后与手机单列布局保留。

## 今日重点与双轨计划

当前升级以设计28第35—40节为准：今日总纲超过280字符提供“展开今日总纲/收起今日总纲”，完整阅读不留不可点的省略号，短文无空开关，新报告复位；打印遵循当前状态。净值与单位同容器不换行，日期/轨道另行排版。

每日30核心加最多10热点，扫描实际N由当份报告决定。v2 entryReady表示技术成立且价格入区，右轨WATCH仅为“价格近均线·待趋势触发”，不得绿标或排在真正入区之前；旧v1以原state/区间推导同样语义。跟踪和14:30提醒同步采用，止损/T1优先级保留。

跨日按基金代码及同市场/口径/单位/轨道匹配，方向key变化不重置；买区两沿都同向达到0.5%才调区间。新T1/T2至少1.5R/2.4R，中文参数放折叠技术依据。精选子新闻、研报/回购/业绩与真实ETF事实进入催化，ETF份额变化和二级主力流不冒充确定机构净申购。

分别显示LEFT_VALUE、RIGHT_TREND的候选/观察/资料不足状态、真实触发依据、输入日期和缺失项。PB、PIT或MA200不足是相应证据提示，不把已成立的另一分支或轨道重新锁为全局WAIT。候选不是收益保证、历史验证或个人风险放行。

有真实锚点时显示入场区间、止损和T1/T2。连续UNIT_NAV不少于20期且当前日期可核验时，可使用设计28的独立净值波动方法计算完整风险价，真实ATR保持原义。其他无OHLC序列可保留PARTIAL均线/布林区间；短历史、陈旧或不合理价位分别解释缺口，不用占位0或假历史填齐。净值显示四位、指数两位；指数点、复权价与净值不能写成基金实时挂单价。

动态方向卡片左侧为简短逻辑、信号、催化与有来源的关键风险，右侧逐基金/指数显示最新值、入场区、止损与T1/T2；正常连续UNIT_NAV可使用独立净值波动方法计算风险价，不能称为真实ATR。参考6—8项方向但不凑数，五个旧主题只是种子。每标的一套价格表，下方唯一默认折叠的技术依据不重复价格；综合依据只保留相关新闻、观察点及紧凑宏观引用。新闻默认显示标题、简短事实及影响方向，传导、情景、未知与原文放折叠详情；新闻不再提供创建跟踪按钮。未来日程与已发生事实分开。旧READY保留原日期，页面刷新时间不冒充研究完成时间。红色个人风险仍需原有完整已确认预算证据。完整规格见设计28第26—29节。

## 市场证据与基金工作台

方向卡下方提供默认收起的“全市场N只核心赛道基金量化扫描总表”，N取本份日报的真实扫描数量。表格完整展示基金名称/代码、最新披露净值及日期、RSI14、入区/距离与技术条件、买入区间、止损、T1/T2；已入买区优先，其余按距离排序。基金名称只移除重复的前缀代码，代码徽章保留。手机表格在本地容器横向滚动，不撑宽页面。

调价状态依次为首次建立、维持、上调、下修关注区间及止盈提醒。只有跨日可比计划才作价格调整判断，同价维持；新闻延续不充当同日价格基线。原因不在数字中间截断，新提示仅写一句原因；旧长篇/重复价格说明收进“查看完整调整原因”，打开后保留全文。另一轨以完整的入场、止损、目标及距买区说明单独展示。

宏观默认36个月，可选12/36/60个月，显示实际样本、单位、来源、观察期、连续月变化与真实曲线；缺期不连伪趋势，公布未知明确标注。数据尚未采集、加载失败与数值为零区分。选单项才挂载完整宽图，桌面图/解释并列、手机上下排列，来源和方法按需展开。

“其余证据”各分组和“待补充证据”独立展开/收起，可同时展开。开关其他分组保留当前已打开的证据详情；收起详情所属分组时清除该详情，重新展开后由用户按需查看。

估值、基金收益风险、产品成本、技术趋势和组合适配各自显示状态、日期和限制。净值区间位置不改名估值分位，价格回撤不冒充含分红基金收益，未知产品费用或跟踪误差不包装成完整质量排名。旧质量深链和当前选择保留，主数据覆盖与实际研究覆盖分开描述。

## 我的跟踪与复盘

方向卡片逐标的一键加入跟踪，服务端从可见READY日报读取并冻结方向逻辑、多新闻证据及所选原始价格，不接受客户端价格。相同方向/标的/轨道幂等，不因日报更新重复创建；后续行情或新计划不覆盖原版本。手动工作台保留原有就地确认/取消和观察期流程；修改假设仍追加版本，旧新闻跟踪记录保持可读。

扫描总表“+ 跟踪”也只提交报告/标的/轨道身份，服务器从原报告冻结价格。同报告同基金同轨道的方向和总表入口复用已有跟踪；不会把不同独立方向强行合并。保存失败允许重试，保存中防重复点击。

列表与详情均显示原冻结买区、止损、T1/T2、最新确认净值及时间、已有14:30估算净值及时间。触及止损、止盈、入区、实际持仓观察、普通区间观察和行情待更新分别显示；仅点击跟踪不算已持仓。过期或缺来源估值保留历史显示但不触发当前状态，确认净值与估值不混用，不移动原冻结价位。

主题、笔记、ACK、启停和真实成交关联均按原tenant/actor权限。意向不等于成交，只关联本人可见已确认fill，不自动入账/下单。保留DAY先后未知与缺收益事实UNKNOWN；原始私人复盘不进入公共模型，已授权的固定模板与聚合规则沿用设计28的隐私和统计边界。

## 操作与验收

开发调试且有权限时，在投资机会页提供“重新采集并分析”，明确说明会重新抓新闻并运行一次模型。点击后显示排队/运行/失败/完成，活动任务不能重复点击，刷新页面能恢复本人任务；成功自动重新读取最新报告。普通GET不派发模型，旧失败报告不覆盖上一份READY，调试版与正式版可区分。具体约束统一见设计28第19—22节。

新建研究先显示当前方向、具体标的名称/代码和可用价格轨道预览，再保存服务器认证快照。核心宏观同码选一个主展示，替代来源保留在明细；单位与算法术语统一中文。无真实校准规则时不显示模型的空规则调试文字。完整日报、来源、日程和算法详情默认折叠。

完整日报、官方发布、扫描总表与卡片综合依据均默认收起，切换报告复位。打印遵循当前折叠状态，不因打印展开来源全文/30行总表；默认打印保留主要方向、基金价格与风险，隐藏导航和操作控件。计划44使用旧03:12重放及真实07:29新报告均验收默认A4为4页；任意纸张、字体和未来内容数量仍以实际打印预览为准。

自选基金使用真实接口；对象刷新入既有后台队列，完成刷新、失败保留旧历史。GET、搜索、分页、图表、窗口切换及保存跟踪不额外调用模型。

验证桌面/手机无溢出、双轨状态及PARTIAL语义、价格单位/空值、URL恢复、宽图详情、冻结跟踪和角色隔离，并回归导入、持仓、报告与现有操作。测试夹具和真实供应商/浏览器验收分别记录，当前结果见计划44；2026-10-19真实v7新报告生成8方向/15只完整价位基金、30项全量扫描，跨日基线为10月18日。全部15项为首次建立区间，不能把首次状态称为已实测发生维持/上调/下修；这些分支另由回归和真实SQL验证。计划43保留此前v6的8方向/14只基金及来源验收，不把隔离重放当作新模型结果。
