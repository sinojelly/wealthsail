# 投资机会页面与数据交互契约

> 2026-11-07修订：依据[四入口设计评审79](../ai-review/79.投资机会子页面增加经济事件和我的基金.md)与[经济事件叙事评审78](../ai-review/78.支持经济事件故事叙事.md)，本文件定义当前页面信息架构；覆盖此前三入口及“今日重点全量展示跟踪”的约定。评审79引用“76.支持经济事件故事叙事”属于旧编号，本轮实际使用78。双轨状态、价格公式、公共输入与跟踪规则仍以[Alpha-V2设计28](28.WealthSail宏观经济研究模块设计.md)为准。需求及验收见[PRD](01.WealthSail投研平台需求文档.md)、[验收规范](04.WealthSail-MVP功能验收与自动化测试规范.md)、[追溯矩阵](08.WealthSail需求设计测试追溯矩阵.md)。本页是设计契约，实施状态以任务清单和测试证据为准，不代表NAS已部署。

## 页面结构

路由`/fund-screener`、导航“投资机会”。四个主入口依次为“今日重点 / 经济事件 / 我的基金 / 市场证据”，默认今日重点。今日重点负责发现机会，经济事件解释事实与条件传导，我的基金管理私人持仓和跟踪，市场证据核查数据。研究与复盘迁入我的基金二级详情，保留完整能力。不得让同一全量跟踪表、完整主题目录或完整日报在多个主入口重复铺开。

| 入口 | URL值 | 默认内容与次级内容 |
| --- | --- | --- |
| 今日重点 | `researchTab=events` | 市场判断、行动提醒、最多3个精选机会、最多3条事件摘要；完整机会按需展开 |
| 经济事件 | `researchTab=stories` | 事件阅读与分类、条件传导、来源、观察点；完整情景和证据按需展开 |
| 我的基金 | `researchTab=tracking` | 持仓/跟踪按基金聚合、真实净值图、独立冻结计划；研究复盘二级查看 |
| 市场证据 | `researchTab=macro` | 核心指标与曲线；完整宏观总纲、其余证据、专业研究及历史报告默认折叠 |

保留旧URL语义：`events`始终为今日重点，不因新增经济事件而改义；`tracking`保留原研究复盘深链，`studyTrack`存在时能打开对应研究；`macro`不变，`quality`与`researchData=1`继续兼容到市场证据。`researchOpen=0/1`、标的/方向/指数选择和无关查询参数继续恢复；新增导航不清空私人研究身份。切换支持前进/后退、刷新、左右箭头和Home/End键，窄屏导航不撑宽页面。

显式有效`researchTab`优先（含旧别名兼容）；只有`studyTrack`且没有可识别的tab时才默认我的基金。用户携带旧`studyTrack`切回今日重点或经济事件，不得被自动拽回复盘。进入我的基金后保留该研究选择。

五主题下拉和静态关联资产面板保持移除；下方唯一指数/基金工作台与搜索作为按需展开的手动工具，明确标的深链仍可直接研究。当前自动发现及扫描跟踪流程以[设计28第26—34节](28.WealthSail宏观经济研究模块设计.md)为准。

直接搜索和市场→方向→指数→基金均可使用，选择与筛选写URL、支持刷新恢复。按instrumentId/市场区分标的，选中基金保持真实父指数；未知关系显示“未确认关联指数”。服务端分页、空值排后与手机单列布局保留。

## 今日重点：先摘要，再查看详情

市场判断不超过三句话，由已保存的宏观总纲/摘要作确定性阅读投影，显示研究日期、当前或历史状态和“查看分析依据”入口；没有可读报告时明确说明资料不足，不由前端生成新判断。完整宏观总纲和指标移到市场证据，不能把独立更新行情当成旧判断被重新确认。

“我的行动提醒”只展示当前本人有效的买区、止损、止盈、风险异常及待核实事项，不重复所有持仓。优先复用`priceWatch`和`sellRiskAlerts`的服务端状态；持仓但没有冻结计划时不推算买卖条件。行情不合格或个人读取失败应显示状态；只有成功读取且没有有效触发时才显示“暂无新触发”。卖出/风险提醒优先级仍以原合同为准，不能被折叠、分数或入区颜色遮盖；阅读刷新不新增消息投递。

精选机会最多3个，不凑数，沿用同一研究已有排序，显示方向、简短核心逻辑、重点基金/当前价格状态、主要风险和证据状态。完整基金、图表、主题匹配和买卖计划按需打开，保持桌面信息在左、走势图在右，手机上下排列。直接候选、风险关联、间接观察与名称候选分开标注，不能用“高价值”标题将观察基金升级成可买入建议。没有直接候选时仍解释真实观察资料和缺口，不静默隐藏。完整代表池、主题目录、量化总表、历史报告与来源默认折叠。

重点事件最多3条，只显示标题、简短影响、来源/时间与当前或历史状态，跳转经济事件的对应事项。事件少于3条不补造；今日研究未成功时，历史事件保留原日期，不叫“今日最新”。

## 经济事件：事实、条件推演与学习

优先复用已保存的`events`、`sources`、`channels`、`scenarios`、`watchFor`、`unknowns`、`upcoming`以及独立安全经济研究交付；不新增模型调用、Prompt字段或Schema字段，不重复行业负面核查。默认可读列表最多8条，有更多时按需查看；分类至少包括全部、国际局势、国内经济、金融市场、产业与就业、科技。分类是阅读分流，不认证行业范围或真实性，没有确切分类时保留其他事项。

每条按“发生了什么 → 为什么值得关注 → 经济可能如何传导 → 可能影响哪些资产 → 后续观察什么”组织。标题、摘要保持源文含义，不把个别企业裁员写成整个行业倒闭潮。事实阶段分别标媒体报道、机构观点、计划中、已宣布、已实施；这些标签不是整件事已核验的证明。未核实事实保留待核实。来源`SOURCE_CHECKED`只说明引用与原文匹配，不升级为因果或全部事件事实已证实。

事件来源发布时间、研究时间、事件实际发生时间分别处理。现有事件未提供独立发生时间时显示“事件发生时间未单独提供”，不能把研究时间或来源发布时间冒充事件时间。历史READY、本次失败的安全经济观察及独立官方事实必须标清来源/日期，不互相借ID，不把上一份日报伪装成今天新闻。

当前`marketReaction`为`UNVERIFIED`，没有可靠价格证据就显示“尚无可靠市场反应数据”，不声称某资产已经涨跌或由事件导致。已有能源观察可以独立展示真实观察期、变化与单位；股票/汇率等未接入证据不补行情。经济传导、受益/受损、情景及反方条件统一作为条件推演，事件阅读不产生交易、跟踪、推送或基金投资资格。

经济知识说明仅复用本事件已有机制，并注明“通用机制”或“本事件的条件推演”；没有可解释机制时显示缺口，不强制生成每日知识点。原文、完整机制、情景、未知和来源证据按需展开，安全外链保留。

**跨日边界（用户已选择方案1）**：每份报告的事件完全独立，即使事件ID相同也不跨报告归并或称为同一故事的已核实新进展。只在同份研究内，依据明确的事件ID、来源和证据关系去重；不得用标题、关键词或语义跨日合并，也不能仅凭来源相同覆盖不同事实。保留每份原事件、来源、`runId`、实际发生时间（若提供）、来源发布时间及原核验状态；未知发生时间不借用报告或发布时间。

可按接口实际提供的可用归档日期浏览，并保留明确的历史报告链接；当前接口只提供当前安全成果与保留的有效报告，应标明可阅读范围，缺少某日材料时明确不可用，不包装成全历史档案或已核实故事进展。跨日期选择、历史研究、本次部分失败、错误关联和资料缺失分别验收。稳定故事ID、可审计且可撤销的关联留作独立阶段，本轮不改数据库、模型、Prompt或研究验收核心规则。

## 我的基金：一只基金一份汇总，多个计划独立

私人持仓与跟踪使用现有`getStudyTracks()`独立读取，不依赖公共报告成功、报告ID或当前研究状态。初始公共加载、超时、本次失败、历史报告仍可查看私人模块。加载、读取失败、真实为空和仅行情缺失分别显示，账号/租户切换不得保留上一用户的缓存或选择。

按已确认的市场和基金代码/标的身份归组，同一基金同时持仓和跟踪只出现一份汇总，保留不同身份与来源。仅点击跟踪不算已买入，未知代码/指数关系不猜。活动基金不超过4只时默认宽卡，信息在左、真实单位净值图在右；超过4只提供名称/代码搜索和紧凑列表，选择一只查看完整详情，避免同时挂载大量曲线。手机信息和图表上下排列。

展示最新确认净值、可用估值及各自日期/来源、持仓/跟踪状态与当前判断。真实成本、份额、盈亏只在可靠私人数据实际存在时显示，不把计划预计收益当成真实收益。同基金不同研究日期、方向和轨道的冻结计划分别可选，保留原价位、来源和版本，不合并区间、不被新报告覆盖；图中叠加线来自当前选择的冻结计划。没有计划时保留真实净值图且解释没有冻结买卖点。

现有`getStudyTracks()`列表不含真实成本/份额，当前汇总不展示这些数值。“下一观察条件”只在用户选择一份研究详情后调用`getStudyDetail()`读取实际条件，不为列表所有记录批量取详情；失败显示缺口，不借用另一研究的条件。

确认净值截止日、研究时状态、当前`priceWatch`时点与曲线截止日分别标注。曲线末端落后于确认净值时明确提示日期差异，不追加合成点，也不把研究时入区标签当成当前仍入区。净值图沿用近半年/1年/2年/成立以来、真实来源与缺数状态。

“研究与复盘”保留冻结快照、条件核验、版本、修订、笔记、ACK、人工决策、MFE/MAE、真实成交关联及历史研究。非基金研究、已结束/停用研究也保留可访问入口，不因个人卡片只展示活动基金而失去历史功能。旧`studyTrack`可直接打开；未选记录可新建研究，不能删除原闭环。

## 数据刷新、失败与默认折叠

公共展示以单一`opportunity-context`决策，首次来源未确定时显示稳定loading/skeleton，不先展示会被替换的fallback。刷新时保留上一份有效内容并明确更新中/更新失败；当前执行ID与展示报告ID分开，历史主题/基金匹配始终从展示报告自身读取。本次只读研究观察单独标注，404/未归档/资料不足/明确零匹配分别说明。已结束但跨日显示为STALE的当前研究按有效结束时间读取只读归档，运行中的研究不得误读终态归档。

首屏保留简短执行状态、展示来源与真实风险，技术错误代码、失败阶段、执行ID和冷却详情进入默认折叠诊断。状态文案与主内容来源分离。次级区独立可收展；异步刷新同一来源保留用户收展与选择，替换报告时说明来源更新并重置仅属于旧报告的展开项。打印尊重实际收展状态。

## 基金机会详情与双轨计划

详细计划和完整宏观阅读沿用设计28第35—40节：市场证据中的完整总纲超过280字符提供明确展开/收起，短文无空开关，新报告复位；今日重点仍遵守三句摘要上限。打印遵循当前状态。净值与单位同容器不换行，日期/轨道另行排版。

每日40核心加最多6热点，扫描实际N由当份报告决定。entryReady表示技术成立、价格入区且无阻止入场的风险；右轨WATCH仅为“价格近均线·待趋势触发”，不得绿标或排在真正入区之前。旧数据按原状态与区间降级读取。跟踪和14:30提醒同步采用，止损/T1优先级保留。

跨日按基金代码及同市场/口径/单位/轨道匹配，方向key变化不重置；买区两沿都同向达到0.5%才调区间。新T1/T2至少1.5R/2.4R，中文参数放折叠技术依据。精选子新闻、研报/回购/业绩与真实ETF事实进入催化，ETF份额变化和二级主力流不冒充确定机构净申购。

分别显示LEFT_VALUE、RIGHT_TREND的候选/观察/资料不足状态、真实触发依据、输入日期和缺失项。PB、PIT或MA200不足是相应证据提示，不把已成立的另一分支或轨道重新锁为全局WAIT。候选不是收益保证、历史验证或个人风险放行。

有真实锚点时显示入场区间、止损和T1/T2。连续UNIT_NAV不少于20期且当前日期可核验时，可使用设计28的独立净值波动方法计算完整风险价，真实ATR保持原义。其他无OHLC序列可保留PARTIAL均线/布林区间；短历史、陈旧或不合理价位分别解释缺口，不用占位0或假历史填齐。净值显示四位、指数两位；指数点、复权价与净值不能写成基金实时挂单价。

动态方向卡片左侧为简短逻辑、信号、催化与有来源的关键风险，右侧逐基金/指数显示最新值、入场区、止损与T1/T2；正常连续UNIT_NAV可使用独立净值波动方法计算风险价，不能称为真实ATR。参考6—8项方向但不凑数，五个旧主题只是种子。每标的一套价格表，下方唯一默认折叠的技术依据不重复价格；综合依据只保留相关新闻、观察点及紧凑宏观引用。新闻默认显示标题、简短事实及影响方向，传导、情景、未知与原文放折叠详情；新闻不再提供创建跟踪按钮。未来日程与已发生事实分开。旧READY保留原日期，页面刷新时间不冒充研究完成时间。红色个人风险仍需原有完整已确认预算证据。完整规格见设计28第26—29节。

“我的基金”持续展示当前用户活动的基金跟踪及其价格状态，不依赖该基金再次被新日报选中；今日重点仅引用有效提醒。跟踪区使用本人已有研究记录与priceWatch，显示冻结买区、止损、T1/T2、最新确认净值、可用14:30估值及日期，并可进入该基金的研究与复盘。停止或观察期到期的跟踪退出活动区，历史仍可在我的基金中查看；无可用当前行情时保留原计划并显示待更新。新日报继续独立发现公共机会，不读取私人跟踪来强制生成推荐。

公共方向和扫描表在同一基金计划中列出入场与退出参考线；个人命中的卖出/风控提醒在页面顶部单列。持续跟踪区同时表达入区、止盈、止损与观察状态，便于比较原计划和当前行情。持续展示不表示每天重新建议买入，也不因页面刷新或日报更新重复发送通知。

## 市场证据与基金工作台

方向卡下方提供默认收起的“全市场N只核心赛道基金量化扫描总表”，N取本份日报的真实扫描数量。表格完整展示基金名称/代码、最新披露净值及日期、RSI14、入区/距离与技术条件、买入区间、止损、T1/T2；成立且入区、非高位的基金优先，再按程序机会分/盈亏比排序。无评分旧包按原技术/距离降级。基金名称只移除重复的前缀代码，代码徽章保留。手机表格在本地容器横向滚动，不撑宽页面。

调价状态依次为首次建立、维持、上调、下修关注区间及止盈提醒。只有跨日可比计划才作价格调整判断，同价维持；新闻延续不充当同日价格基线。原因不在数字中间截断，新提示仅写一句原因；旧长篇/重复价格说明收进“查看完整调整原因”，打开后保留全文。另一轨以完整的入场、止损、目标及距买区说明单独展示。

宏观默认36个月，可选12/36/60个月，核心卡优先显示最新数值、变化趋势、经济含义和数据截止日，再按经济类别查看其他指标。经济含义采用指标本身可解释定义，例如PMI与50分界，不能借单项观测推出投资方向已成立。保留实际样本、单位、来源、观察期、连续月变化与真实曲线；缺期不连伪趋势，公布未知明确标注。数据尚未采集、加载失败与数值为零区分。选单项才在同位置挂载完整宽图，桌面图/解释并列、手机上下排列，来源和方法按需展开；没有序列不画假图，图表必须有加载、错误重试和数据缺失状态。

“其余证据”各分组和“待补充证据”独立展开/收起，可同时展开。开关其他分组保留当前已打开的证据详情；收起详情所属分组时清除该详情，重新展开后由用户按需查看。
