## 1. 全栈测试战略与质量评估体系 (Full-Stack Quality Metrics)

WealthSail 全量系统定位于**工业级量化投研与大类资产配置中台**。系统测试必须兼顾“金融量化的绝对严谨性”、“大模型认知的自进化有效性”以及“多端分布式高并发的实时性与安全性”。

```
                              / \
                             /   \       【L4: 端到端全景业务与用户旅程验收 (E2E Acceptance)】
                            / E2E \      全天候配置、多Agent辩论、NL2Strategy、自进化复盘、Web看板
                           /-------\
                          / Perf &  \    【L3: 性能、安全与高可用专项测试 (NFR / Security)】
                         /  Secur    \   Go高并发协程、RLS跨租户渗透、7x24h NAS容器自愈、压测
                        /-------------\
                       /  Integration  \ 【L2: 跨服务与跨语言集成测试 (Cross-Service IT)】
                      /   (Go/Py/Node)  \ Backtrader量化解释、pgvector相似度RAG、Supabase Realtime
                     /-------------------\
                    /     Unit Tests      \ 【L1: 模块级单元测试 (Unit Tests)】
                   /   (Go / Py / TSX)     \ 数据清洗、回测算法、指标计算、UI组件无状态渲染
                  /-------------------------\
```

### 1.1 核心质量衡量指标与合格阈值
| 质量考核维度 | 指标定义与验收阈值 | 验证与度量手段 |
| :--- | :--- | :--- |
| **1. 量化回测严谨性 (Quant Rigor)** | • 回测指标（年化 CAGR、最大回撤 MaxDD、夏普比率 Sharpe、卡玛比率 Calmar）与专业机构级量化软件误差 $<0.01\%$。<br>• 严禁前瞻性偏差（Lookahead Bias）与幸存者偏差。 | 将同一策略与数据输入 Python Backtrader 与标准对标基准核验输出。 |
| **2. 宏观与周期时效性 (Data Freshness)** | • 原油、铜博士大宗期货与现货金价盘中更新延迟 $<3$ 秒。<br>• 隔夜美股/中概/A50 盘前数据在 `08:00` 准时完成清洗归档。<br>• 全球突发地缘黑天鹅要闻捕获至触发风险排查延迟 $<15$ 分钟。 | 模拟 WebSocket/高频轮询推送时延打点监控。 |
| **3. 多租户数据隔离安全 (Security & RLS)** | • 任意租户绝对无法通过 Web API、GraphQL 或 SQL 越权访问其他用户的持仓、交易记录与向量反思记忆。<br>• 模拟渗透测试与 SQL 注入拦截率 $100\%$。 | 编写自动化安全测试套件模拟多 Token 越权探测 (403 Forbidden)。 |
| **4. 高并发与触点告警性能 (Performance)** | • Go 数据同步引擎单实例常驻内存 $<100\text{MB}$，支持同时监控 $5000+$ 只标的实时行情。<br>• 盘中点位触达预警从判定到推送到微信/飞书/TG 延迟 $\le 5$ 秒。<br>• Next.js Web 首屏加载时间 (FCP) $<1.5$ 秒，TradingView 图表 $60\text{ FPS}$ 流畅渲染。 | 自动化压测工具 (Locust / k6 / Lighthouse) 自动化评分。 |
| **5. 认知闭环自进化有效性 (Evolution Efficiency)** | • T+N 自动归因准确率 $\ge 95\%$（准确区分 `AI_ERROR` 与 `USER_ERROR`）。<br>• 反面模式 `[Anti-Pattern]` 在相似历史形态再次出现时的 RAG 召回率 $\ge 90\%$。 | 构建历史误判基准测试集 (Golden Evaluation Dataset) 跑批比对。 |

## 4. 全量上线验收签署与交付标准 (Release Criteria)

全量系统正式发布交付前，必须满足以下**硬性上线准入条件**：
1. **自动化测试通过率**：全栈自动化测试用例（UT + IT + ST + NFR）**通过率必须达到 100%**，无任何 P0/P1 级别失败用例。
2. **代码测试覆盖率**：核心金融计算、分红折算与 RLS 安全模块代码行覆盖率（Line Coverage）$\ge 90\%$。
3. **数据一致性校验**：多品类持仓（股票/基金/黄金）、可用现金、分红流水与大盘净值走势严格借贷平稳、逻辑自洽。
4. **无人值守稳定性**：在本地 NAS / VPS 环境下 Docker-compose 持续压测运行 72 小时无内存泄漏、无死锁、无异常重启。
