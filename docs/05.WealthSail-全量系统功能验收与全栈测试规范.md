## 1. L2–L4 开发准入条件 (Entry Criteria)

任何 L2–L4 需求开发与合并前，必须满足以下前置 Gate：
1. **L0/L1 回归通过**：不可变双式记账、PostgreSQL RLS 行级隔离与四时段核心闭环无任何 P0/P1 阻塞缺陷；
2. **稳定标识保持不变**：`tenant_id`、`account_id`、`instrument_id`、`ledger_event_id`、`source_id`、`report_id` 保持稳定全局唯一；
3. **兼容性保障**：采用 `expand–migrate–contract` 模式，未知可选字段容忍，未知 major 显式拒绝，绝不破坏旧客户端 contract tests；
4. **数据许可与安全审查**：涉及外部多媒体、自选研报与新市场数据源时，必须有明确的数据版权与 API 许可台账。
