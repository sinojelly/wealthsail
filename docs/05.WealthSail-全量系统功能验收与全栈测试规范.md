## 1. 通用准入与退出规则

每个增量阶段开始前必须满足：前序 Must 回归通过；稳定 ID 和事件兼容性不破坏；数据/媒体/券商许可明确；威胁模型、成本预算、迁移/回滚和删除方案获评审。新增能力使用 feature flag，影子运行与双读验证后才逐租户开放。

每个用例必须保留 commit、环境、Migration checksum、fixture/历史数据版本、Provider/模型/Skill 版本和原始报告。回测和 Agent 质量结论必须预先冻结评估集与阈值，禁止看完结果再改成功标准。
