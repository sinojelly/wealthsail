# 天天基金本地持仓与交易采集工具

这个工具在用户电脑上打开一个独立、可见的浏览器。用户自行扫码登录天天基金后，工具自动采集当前基金持仓和普通基金成功交易，按年度拆分交易日期、获取全部分页、去重并生成 WealthSail 可导入的单个 ZIP。

它不自动下单，不修改天天基金账户，不保存用户名或密码，也不会把 Cookie、访问令牌或浏览器资料提交到 WealthSail 服务端。

## 1. 当前采集范围

工具首先从天天基金主持仓接口提取基金代码、名称、市值、持仓收益和最近净值，再自动逐只打开“持仓明细”，汇总同一基金在多张银行卡下的可用份额、持仓份额和市值。成本使用同一时点的“持仓市值－持仓收益”精确推导，不用四位小数净值反推份额。分卡市值四舍五入产生的 0.01 元差额使用主持仓汇总值；更大差额、条数不平或市值汇总不平时，工具停止形成完整基线，不会把页面加载失败误判为“空持仓”。

工具自动查询天天基金交易页第一行的普通基金业务：

- 买入；
- 卖出；
- 转换；
- 超级转换；
- 定投；
- 组合调仓；
- 分红；
- 其他。

查询状态固定为“成功”。充值、自动充值、普通取现、快速取现、活期宝转出、互转、结转收益、预约取现、信用卡还款和每日收益等活期宝业务不会作为基金交易导入。

即使天天基金返回了混入的活期宝记录，工具仍会在本地二次分类，放入 `excluded-cash-management.csv`，不会进入 `fund-transactions.csv`。

`活期宝转入`和`卖出回活期宝`是普通基金以活期宝作为付款或回款渠道的真实买卖，工具会保留；`活期宝充值`、`活期宝快速取现`和`活期宝普通取现`属于现金管理，即使页面返回了底层货币基金代码也会排除。`强行调增`、`活动发放`以及没有基金代码的组合调仓等特殊记录进入 `review-required.csv`，不会伪装为标准成交。

## 2. 首次安装

要求 Node.js 22 或更高版本。进入工具目录安装依赖：

```powershell
cd D:\develop\gitee\WealthSail\tools\tiantian-fund-importer
pnpm install
```

工具默认使用系统安装的 Microsoft Edge，不需要另行下载自动化浏览器。

## 3. 推荐运行命令

当前参考资料中最早可见交易在 2020 年，因此第一次建议从 2020-01-01 开始：

```powershell
pnpm capture -- --from 2020-01-01
```

如果实际开户更早，把日期提前。例如：

```powershell
pnpm capture -- --from 2015-01-01
```

运行后只需协助完成以下步骤：

1. 工具打开一个独立的 Edge 窗口；
2. 在该窗口中登录天天基金，推荐使用天天基金 App 扫码登录；
3. 确认浏览器已经显示“交易查询”页面；
4. 回到 PowerShell，按一次 `Enter`；
5. 工具随后会访问“持仓明细”。如果天天基金要求持仓子系统单独登录，按终端提示在同一浏览器中再扫码一次，看到基金持仓列表后再按 `Enter`；
6. 不要关闭自动打开的浏览器，等待终端显示“采集完成”。

以后再次运行会复用本机独立浏览器资料，通常不必重复登录；天天基金要求重新验证时，再扫码确认即可。

## 4. 浏览器启动失败

如果电脑没有 Edge，可改用 Chrome：

```powershell
pnpm capture -- --from 2020-01-01 --browser chrome
```

如果 Edge 和 Chrome 都不可用，可以安装 Playwright Chromium：

```powershell
pnpm exec playwright install chromium
pnpm capture -- --from 2020-01-01 --browser chromium
```

## 5. 输出内容

结果默认写入：

```text
tools/tiantian-fund-importer/private-data/exports/run-时间戳/
├── manifest.json
├── current-positions.json
├── all-transactions.json
├── fund-transactions.csv
├── excluded-cash-management.csv
├── review-required.csv
├── non-posting.csv
└── wealthsail-tiantian-YYYYMMDD.zip
```

- `manifest.json`：本地诊断输出的时间范围、分类数量、去重数量、文件 SHA-256 和安全声明；
- `current-positions.json`：脱敏后的当前持仓快照；
- `all-transactions.json`：标准化后的完整结果，银行卡只保留尾号；
- `fund-transactions.csv`：供本地核对的普通基金成功交易；
- `excluded-cash-management.csv`：被排除的活期宝记录；
- `review-required.csv`：无法安全判断的“其他”产品或特殊交易，必须人工确认；
- `non-posting.csv`：不应改变持仓的状态记录。当前默认只查询成功状态，通常为空。
- `wealthsail-tiantian-YYYYMMDD.zip`：Web 中实际选择的 v2 导入包，包含持仓、基金交易、待复核记录、活期宝排除摘要和文件哈希。

登录 WealthSail 后进入“导入 / 更新持仓”，选择最后这个 ZIP。不要手工解压后逐个选择文件。

活期宝详细流水只保存在本地核对 CSV 中，不进入上传 ZIP。

CSV 会阻断以 `= + - @` 开头的单元格，避免使用 Excel 打开第三方数据时执行公式。

## 6. 在 WealthSail 中预览并确认

1. 使用 `OWNER`、`ADMIN` 或 `EDITOR` 登录，进入“持仓”页面，点击“导入 / 更新持仓”；
2. 选择 `wealthsail-tiantian-YYYYMMDD.zip`。浏览器只读取文件用于上传，不会把本地目录路径保存到服务器；
3. 首次导入可创建一个“天天基金”专用投资账户，后续导入必须选择该来源已经绑定的同一账户；
4. 等待预览完成，核对新增、变更、不变、关闭和冲突五类基金，以及交易覆盖日期、待复核记录和活期宝排除摘要；
5. 对证据不足的持有起始日填写人工确认日期。即使没有待复核项，也必须勾选“已核对全部预览”；目标账户为空时还需额外确认用当前快照建立完整基线；
6. 点击确认后，持仓账本先完成更新，官方净值和持有区间指标由 Worker 异步回填。页面显示 `PENDING` 不代表导入失败；稍后会变为 `READY`、`PARTIAL` 或 `CONFLICT`；
7. 网络中断或关闭页面后，重新进入导入页可以从服务端批次历史恢复 DRAFT 或查看已确认结果，不需要重新上传同一个包。

当前快照是导入时点的权威外部账户基线：上次存在、本次不再持有的基金会在预览中显示“关闭”，确认后份额归零；只替换该天天基金来源管理的基金，不会清空其他手工账户或其他来源。历史交易只用于核对来源和推断持有起始日，不会伪造成 WealthSail 的申购、赎回或现金流水。

`VIEWER` 可以查看已有持仓、区间指标和导入历史，但不能上传、确认、取消或重试。若管理员尚未打开服务器功能开关，页面会说明功能暂不可写；不要通过重复刷新绕过。

### 常见导入错误

| 提示 | 含义与处理 |
|---|---|
| 文件不是 ZIP、Schema/哈希不匹配 | 不要自行改压缩包内容；重新运行采集器生成完整 v2 ZIP |
| 文件过大、解压比例或记录数超限 | 缩短历史日期后重采，或由管理员评估资源后调整限制；不要拆开逐文件上传 |
| 包已导入/草稿已存在 | 从批次历史继续原 DRAFT 或查看已确认结果，避免重复建立基线 |
| 目标账户已变化（409） | 预览后账户又被更新；刷新并重新生成差异，不能强行覆盖 |
| 存在冲突/待复核项 | 根据页面说明核对基金代码、份额和持有日期；未完成复核时不能确认 |
| 账本成功、指标失败 | 持仓已经导入，不要再次确认；点击“重试指标”，只重跑官方净值和区间计算 |

## 7. 常用选项

```text
--from YYYY-MM-DD      最早交易日期，默认 2010-01-01
--to YYYY-MM-DD        截止日期，默认今天
--browser NAME         msedge、chrome 或 chromium
--delay-ms NUMBER      请求间隔，默认 800 毫秒，允许 300~10000
--output-dir PATH      自定义导出目录
--profile-dir PATH     自定义独立浏览器资料目录
--help                 显示命令帮助
```

天天基金历史查询每次最多支持约一年，工具会自动拆分为不重叠区间，并把最近一年与历史交易分别查询。每个业务类型、每个日期区间都从第一页开始，根据官方返回的总记录数继续获取后续页面。

## 8. 隐私与安全

- `private-data/` 和 `reference/天天基金/` 已在仓库根 `.gitignore` 中忽略；
- 不要把 `browser-profile/`、完整交易文件、原始截图或 Cookie 发到群聊、工单或 Git；
- 如需协助排查，优先提供 `manifest.json` 和已人工检查过的 `review-required.csv`；
- 临时访问令牌只存在于采集进程内存中，结束后随进程释放；
- 工具使用天天基金交易查询页面当前调用的结构化查询接口。网站升级后如果字段或接口发生变化，工具会停止并报错，不会把失败响应当成空交易继续导出。

`current-positions.json` 和交易 CSV 虽然不含登录密码、Cookie 和完整银行卡号，但仍包含真实的个人持仓、成本和交易时间，属于敏感金融数据。“脱敏”只指去掉直接登录凭据和不必要身份字段，不等于可以公开分享。上传前应确认 WealthSail 部署和目标租户可信。
