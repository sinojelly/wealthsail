这次的问题确实比较明显。界面虽然换成了四个分类，但仍然没有形成清晰的投资研究工作流，反而把原来藏在弹窗里的复杂内容直接铺到了页面上。

从截图看，我认为问题不仅是 UI 粗糙，而是三个层面同时出了问题：

1. 视觉层： 顶部摘要文字溢出、展开状态不清楚、宏观图表没有利用好空间，卡片和大面积空白并存。
2. 信息层： 同一个沪深300趋势判断在顶部、重要变化、投资方向中反复出现；用户看到很多字，却很难提取不同的信息。
3. 价值层： 页面把“已经采集了什么”“还有什么没验证”放得太突出，反而缺少用户真正关心的“发生了什么、意味着什么、哪些资产值得关注、下一步看什么”。

我的判断是：现在应该停止继续添加卡片、标签和按钮，先把首页收敛成一条明确的主线。

> 重要变化 → 对市场和基金的影响 → 值得观察的机会或风险 → 触发条件 → 后续验证与复盘

宏观数据、新闻来源、研究缺口都是这条主线的证据，而不应该和投资结论抢占首页的位置。

我会结合当前 WealthSail 实际前端实现，找出哪些是布局 bug，哪些是信息组织本身出了问题。

### 1. 最严重的逻辑问题：“研究机会”并不代表机会

截图里显示：

- 沪深300尚未满足 MA200 与63期正动量条件。
- 63期动量约为 -11.18%。
- 相对 MA200 约为 -10.87%。
- PE 历史分位约为 60.11%。

这些数据如果准确，只能支持当前趋势偏弱、估值并未显示明显的历史低分位优势，而不是告诉用户沪深300存在值得买入的机会。

因此，不能因为系统找到两条有数值的“研究项”，就把它们放进“研究机会”。

正确的表达应该是：

沪深300 · 当前研究状态

趋势条件未通过

63期动量

# -11.18%

相对 MA200

# -10.87%

当前研究解释

趋势证据暂不支持预设的趋势型建仓条件。PE分位约60%，也不能独立证明估值便宜。继续观察趋势改善及盈利、估值证据。

示例数值来自截图，并非实时行情

状态：继续观察

当然，不同投资策略可以有不同逻辑。趋势策略不满足，并不自动否定长期定投或价值型策略；但每种策略都应分别展示自己的条件和验证依据。

### 2. “重要风险”为空，但实际存在值得提示的市场风险观察

你现在的“重要风险”显示：

“当前没有可展示事项，不代表已完成该类判断。”

这句话很谨慎，却对用户没有帮助。

系统既然已经知道沪深300处于预设趋势条件以下，就可以将其显示为市场趋势风险观察，而不是把“重要风险”留白。

不过必须区分三个层次：

- 已证实风险： 例如用户真实持仓风险预算超限。
- 风险信号： 例如指数明显低于 MA200、动量为负、波动快速上升。
- 潜在事件风险： 例如能源供应中断可能影响通胀，但后续影响尚未证实。

使用不同的颜色和状态，不能一律红色，更不能把“弱势技术指标”写成“未来一定下跌”。

### 3. 宏观详情图不是数据不足，而是布局没有设计好

这张截图很典型：展开 PMI 后，图表还是一个窄小的固定尺寸图，周围却有大片空白。

建议采用以下规则：

- 桌面端图表至少占详情区域的 60%，高度大约 260—320px；
- 右侧集中展示“当前值、参考线、环比变化、近3个月变化、历史分位及投资含义”；
- 数据来源、采样方法和修订记录放到二级折叠区；
- 手机端改成图表在上、说明在下；
- 图表的 SVG 或容器必须按父容器宽度伸缩，不能沿用缩略图尺寸。

特别是 `制造业 PMI 50.1`，最醒目的应该是：

50.1，略高于50荣枯参考线0.1点；但需要连续月份与订单等指标确认扩张是否稳固。

而不是先列十几行发布日期和历史样本数。

### 4. 每日研究状态仍然没有真正解决

截图顶部的“最近有效研究：未确认”，以及正文里的“今日尚未研究”，属于两个不同的问题。

“最近有效研究”应当只从真正成功保存的研究结果中选取。如果没有成功报告，应明确显示“暂无有效日报”，而不是“未确认”。

另外，截图的下次计划是 10月18日08:30。如果这张图是10月17日08:30之后拍的，就应检查当天的任务：没有成功报告，究竟是没有执行、执行失败、超时、校验失败，还是前端没有读到？

不能单凭已经显示了明天的计划时间，就认定今天已经完成任务。

需要检查数据库中的每日执行记录、终态、错误类以及最近一次有效报告；不要为了让 UI 显示“完成”而制造一份空日报。

### 5. 未来事件不能代替重大新闻

目前“未来事件”显示的是 PMI 和 PPI 发布计划。

这是有价值的经济日历，但不是完整的重大事件情报。

用户想要的是全球市场中能够改变投资假设的事件，例如地缘局势、制裁、能源运输、贸易政策、美联储变化，以及它们对不同资产的潜在影响。

应该把“重要事件”与“未来日历”分开。未来日历放在一个简短的区域中，不能挤掉真正的重要新闻。

## 二、建议直接采用的最终页面结构

我建议不要再维持现在的四个大标签加四列摘要的结构。它与下方已有的“指数和基金筛选”功能重复，导致页面越做越长。

可以收敛成以下布局：

今日投资观察

日报状态 · 数据截至时间

市场判断：当前研究方向趋势偏弱，暂未形成已验证买入机会

主要关注：趋势能否改善、全球重要事件是否改变风险条件

风险与逆风

沪深300趋势条件未通过

有观察依据；非未来涨跌预测

机会与候选

尚无符合完整条件的基金候选

继续观察估值与趋势改善

事件与下一步

等待重要经济事件更新

关注预期差与市场反应

结构示意，非实时研究报告。用户持仓未知时单独显示提示，不占一整张空白大卡片。

今日重点

市场证据

我的跟踪与复盘

当前值得继续验证的研究

沪深300：趋势条件未通过；关注 MA200、63期动量及估值是否发生有意义的变化。

全球事件：每日研究成功后按重要性呈现，尚无有效报告时显示历史版本与数据状态。

真正收起时，应只留下标题、研究状态和一到两行摘要。上面展开的内容才在用户点击后出现。

### 为什么只保留三个详细分类？

| 分类      | 具体内容                      | 是否默认展示 |
| ------- | ------------------------- | ------ |
| 今日重点    | 全球重大事件、风险、机会线索、受影响资产、验证条件 | 展开后默认  |
| 市场证据    | 增长、通胀、流动性、利率、油价、估值与市场趋势   | 按需查看   |
| 我的跟踪与复盘 | 已关注的研究假设、条件变化、历史判断和结果     | 按需查看   |

“投资方向与基金”不用在这里再做一套长页面。它本来就是下方指数与基金工作台的主功能。在今日重点中点击相关指数，直接跳到对应指数研究，而不是再嵌套一份简化版。

数据质量同样不需要占主要标签。显示在指标旁的状态标识和专门的诊断页面即可。

## 三、详细分类怎么展示，才能真正有投资价值？

### 1. 今日重点：用事件和投资假设作为基本单位

不要再按新闻文章或宏观数字生成长卡片。

一条重要事项只展示：

| 字段    | 示例             |
| ----- | -------------- |
| 事项    | 沪深300趋势条件仍偏弱   |
| 类型    | 市场风险观察         |
| 事实依据  | 相对MA200和63期动量  |
| 投资影响  | 趋势型策略的预设条件尚不满足 |
| 受影响方向 | A股宽基           |
| 下一步验证 | 趋势修复、盈利和估值条件   |
| 证据时间  | 2026-10-16     |
| 操作    | 查看详情 / 加入跟踪    |

如果是国际新闻，则需要用“事实 → 经济传导 → 潜在受益/承压资产 → 反方情景 → 验证指标”的结构，而不是只显示新闻摘要。

每天可以有十几条候选新闻，但首页只选真正重要的几条。相同事件合并，不重复打印全文。

### 2. 市场证据：指标按经济问题组织，不按数据接口组织

建议划分为四组：

| 组别      | 核心数据                    | 最需要解释的事情           |
| ------- | ----------------------- | ------------------ |
| 经济增长    | PMI、订单、生产、社零、工业增加值、企业盈利 | 经济正在改善还是走弱？        |
| 通胀与成本   | CPI、PPI、油价、运输成本         | 通胀或利润压力是否变化？       |
| 利率与信用   | M1、M2、社融、国债利率、融资利率      | 流动性是否真正传递到实体和资产价格？ |
| 全球风险与市场 | 美债实际利率、美元、原油、指数趋势、波动    | 外部因素会怎样影响研究资产？     |

首页只显示每组的关键结论和最重要变化。进入详情后，再看曲线、参考线、历史分位和来源。

例如 PMI 卡片里真正重要的是“50.1、较上期+0.3、距离50线+0.1、近3个月变化、是否持续”。发布日期、统计样本、来源哈希等信息可以继续保留，但应该放在次级证据区。

### 3. 我的跟踪与复盘：先做成轻量研究清单

这里不需要每天调用模型。

用户点击“加入跟踪”时，冻结当时的研究假设、证据日期、相关指数和触发条件。

后续程序只需要检查预定义指标有没有满足、违反或失效，并记录变化。

例如：

| 研究主题      | 当前状态 | 下一次核查           |
| --------- | ---- | --------------- |
| 沪深300趋势修复 | 观察中  | 收盘价与MA200、63期动量 |
| A股盈利改善    | 证据不足 | 企业盈利与订单         |
| 某项全球能源事件  | 等待验证 | 实际供应、油价、航运成本    |

最终用户应该能对着一条研究记录回答：当初为什么关注？什么条件会让我改变看法？后来事实如何？我是否按原计划执行？

## 四、如何解决目前“全是已采集事实，没有有用信息”的根因？

这个问题不能只靠 CSS 修复。

从截图看，目前页面已经有 PMI、CPI、M2、沪深300趋势和 PE，但每日全球研究仍未提供有效报告。于是页面只能把已有数据拼接成所谓的“投资重点”。

这相当于把有数据误认为有投资机会。

建议修改后端返回前端的研究对象，明确区分四种结果：

| 结果状态    | 含义               | 首页怎样显示       |
| ------- | ---------------- | ------------ |
| 已确认风险   | 有明确风险规则及有效证据     | 风险提醒         |
| 有限研究线索  | 发现值得研究的条件，但资格未完成 | 候选观察         |
| 已满足策略条件 | 预设条件通过，且有足够适用证据  | 策略候选，并保留风险检查 |
| 无可靠结论   | 当前证据不足或条件不满足     | 清楚说明，绝不凑机会   |

同时要求每条摘要包含 `类型、关联资产、重要性、事实来源、证据时间、支持条件、反方条件、下一步验证、失效条件`。

不要再让前端根据有几个指标，就自动把它们填到“研究机会”中。

另外，目前事件和宏观信息之间的关系也应单独建立。例如，某项全球能源政策变化可能同时影响油价、通胀预期、国债利率、能源基金和消费基金；系统应共享同一事件 ID，在不同投资方向展示其关联影响，而不是分别复制几篇文字。

## 五、我建议 Codex 下一轮只完成这三项任务

为了避免你再经历一轮“加了很多功能，但页面更乱”，应该控制开发范围。

P0

先修布局、样式和交互

统一标题、正文、卡片间距和边界；修复顶部溢出、展开状态、宏观图表宽度、空白布局、过多重复按钮。不要增加新页面、新弹窗。

P1

再修投资信息组织

精简成三个详细分类；把趋势不达标从“投资机会”中移走；按事件与研究假设去重；使用具体风险、机会状态和验证条件，而不是普通指标堆砌。

P2

最后补齐每日研究与复盘链路

查明 08:30 任务状态，确保有效日报正常展示；将事件、假设、指标、基金与历史研究记录串起来，支持用户持续跟踪和事后复盘。

### 必须设定明确的 UI 验收标准

建议至少检查 1440px 桌面与 390px 手机布局，并验证：

- 顶部摘要不会超出容器，也不会贴边。
- 收起和展开状态一眼可见，展开后不会出现空白大区域。
- PMI 详情图能真正占满分配给图表的空间。
- 首页不存在同一事实的多次长篇重复。
- 没有真实机会时，绝不把趋势不满足包装成机会。
- 点击某项研究后，能够直接查看其证据与下一步条件，不需要连续打开多个弹窗。
- 用户刷新、展开和切换标签都不调用大模型。
- 每日研究失败时明确显示状态，能够读取上一次有效报告，而不是只出现“今日尚未研究”。

我最建议你现在做的决定是：不要继续往这块区域加内容。先把它减到真正有价值的信息，再让数据和分析逐步填进去。

目前已有的宏观采集、指数趋势、估值证据和 Codex 每日研究机制都可以保留。问题不在于技术工作完全没有价值，而在于系统还没有把这些东西转化成用户能迅速理解和持续验证的投资判断。

下一轮能否成功，验收重点不应该是“又增加了多少指标和按钮”，而应该是：

一个用户打开页面30秒内，能否知道当前最重要的风险、最值得研究的方向，以及为什么需要继续观察或改变原有判断。
