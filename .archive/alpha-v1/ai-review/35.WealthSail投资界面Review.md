## 这次比上一版好了，但还没达到可交付的 UI 水平

我对这版的评价是：整体方向正确，信息架构有进步，但交互细节和视觉层次还需要一次集中整改。

好的变化有三点：日报终于完成并能展示全球事件；顶部真正做到了收起简洁、展开详细；“今日重点、市场证据、我的跟踪与复盘”这三个一级分类也可以保留。

但从截图看，最明显的问题是：看起来已经有分析能力了，界面却还没有把分析结果组织成一个顺畅、直观的投资研究体验。

### 一、PPI 点击后不出图，是优先级最高的 Bug

这一点我同意你的判断，应该直接恢复以前那种能够看到趋势图的体验。

从前几版截图可以看到，PPI 曾经有历史曲线；现在 PPI 仍能显示同比 5%，但点击“完整证据”后不能正常呈现图表。因此，首先应该排查数据是否传入展开组件、图表容器尺寸和条件渲染逻辑，不能简单解释为“PPI没有数据”。

目前还无法仅凭截图确认具体代码原因，但以下几种情况特别值得检查：

| 可能的问题              | 排查方式                           |
| ------------------ | ------------------------------ |
| PPI 卡片只有最新值，没传历史序列 | 检查展开前后接口数据、序列长度和指标ID映射         |
| 图表所在容器没有有效高度       | 检查图表父容器实际宽高，尤其是 `height: 100%` |
| 点击后卡片跨列，组件被重新挂载    | 检查 React `key`、展开状态和条件渲染       |
| 只有核心指标才渲染图表        | 检查“核心指标”和“其他证据”是否使用了不同组件       |
| 历史序列格式或值为空         | 检查日期、数值、排序和可绘制样本数              |

期望交互不是“点一下，卡片变大”，而是“点一下，真正看到更大的图和解释”。

推荐改成：

PPI 同比

指标详情布局示意

# 5.0%

较上期 +1.2 个百分点

工业品出厂价格同比上升，应进一步区分上游涨价、下游成本和企业利润影响。

示意曲线，并非真实PPI数据；正式页面应使用已核验的历史序列。

观察月份

2026年9月

下一步研究

行业成本与利润

详细来源、计算方法和历史样本放在最下方，默认收起。

这应是所有宏观指标共用的详情组件，PMI、CPI、PPI、M2、国债收益率、油价都用同一套展示规则，不要每个指标临时拼一套 UI。

更重要的是：点击一个卡片时，不要改变整个三列布局。 可以在该行下面打开全宽的详情区域，或者进入统一的指标详情视图，让页面布局稳定。

如果无法绘图，明确显示“历史序列未就绪及具体原因”，而不是展开空白区域。

## 二、现在还有五个明显的界面问题

### 1. 宏观指标的分类和展开状态存在错位风险

有一张截图中，“全球风险与市场”区域下方出现了 CPI 同比大图。而 CPI 应属于“通胀与成本”，不应出现在全球风险组下。

再结合你反映的 PPI 点击后没有图，我怀疑不仅是 CSS，还可能存在展开状态与指标ID没有正确绑定的问题。

应该确保：

- 点击 PPI，只展开 PPI 的历史数据与解释。
- 点击 CPI，只展开 CPI。
- 切换指标分组时，不能继承其他指标的展开状态。
- 缺少历史数据的指标不能渲染一个空图。
- 图表必须紧邻被选择的指标，而不是跳到其他分类下。

实现时，建议按照稳定的 `indicatorId` 保存展开状态，不要用数组位置或列表序号代表当前展开的指标。

### 2. “市场证据”仍然显得像数据管理页面

现在核心指标有六个格子，其中三个显示正常，另三个都是 `—`。

这些空卡片占据了和有效数据一样大的空间，实际降低了信息密度。

建议改成两层：

| 区域     | 默认显示                           |
| ------ | ------------------------------ |
| 已有有效证据 | 有数值、有变化、有解释的指标卡和小趋势图           |
| 待补充证据  | 一行简短提示，例如“中国10年国债利率、M1、社融仍待核验” |

需要研究某个指标时再展开。

更合理的是根据当前研究主题动态选择核心指标。研究A股宽基时，除了PMI、信用等，还应优先展示指数估值和价格趋势；研究能源时，PPI、油价、炼油价差就应该更靠前，而不是固定放进“其他证据”。

### 3. “今日重点”仍然没有把真正重要的事情放在最前面

这次 Codex 日报内容其实比以前丰富很多。

例如截图中已经出现了中国技术出口政策、美国科技股回调、能源与制裁、美国利率等研究主题。

说明新闻研究能力开始产生有价值的材料了。现在的瓶颈更多在展示层。

但用户展开后，首先看到的是两个“当前资产观察”大卡片，下面是日历，再往后才看到真正的全球重要事件。

应该改成下面这个顺序：

### 今日重点 · 建议结构

1\. 今天最值得关注的事件

每条只显示：发生了什么、可能影响哪些资产、下一步验证什么。最多展示3条，按影响程度排序。

2\. 目前市场和基金有什么信号

关联沪深300、中证A500、中证500及具体ETF，分开展示趋势、估值、风险与机会资格。

3\. 接下来关注什么

未来重要事件、验证条件和用户已经跟踪的研究主题。

4\. 阅读完整日报

展开所有事件、引用、推理、反方条件和研究局限。默认收起。

这样用户不会被长篇日报打断，却能继续深入。

### 4. 新闻正文还是太像模型的原始输出

例如：

“最近24小时内 AP 报道……当前为报道线索，不能证明事件因果……历史质量冲突、PIT缺口……”

这种文字适合保存在研究依据中，但不适合直接作为普通用户的事件卡正文。

应该把它转换成更自然的四行：

事件： 美国科技股出现明显回调。

潜在影响： 关注高估值成长资产及相关科技基金的波动风险。

当前证据： 市场下跌已有报道，但原因尚不能单独归结为某项政策。

下一步： 核对指数价格、盈利预期、美债实际利率及科技企业资本开支。

其中，报道中提到的具体跌幅和解释仍要保留来源及核验状态。

`PIT`、`SOURCE_CHECKED`、`IMPLEMENTED`、`historyQuality=CONFLICT` 等技术字段，不应直接出现在主要投资阅读界面。可以转换成用户能理解的文案，例如“历史时点数据尚未验证”。

### 5. 研究跟踪区域已经有雏形，但交互还有点粗糙

现在“我的跟踪与复盘”只有：

“暂无研究主题 → 新建研究 → 观察天数30 → 冻结研究并跟踪”。

流程可以更自然。

应该让用户从某个具体事项进入：

看到事件或指数研究 → 点击「持续跟踪」→ 确认研究假设 → 保存。

随后才在“我的跟踪与复盘”显示状态和历史记录。

“30天”可以作为默认观察期，但最好由研究假设类型决定推荐期限。比如技术趋势可以观察数周，企业盈利研究可能需要跨季度，不能用同一个周期解释所有事件。

## 三、UI 应该有一套统一的视觉规则

现在有的卡片很宽、有的很窄，有的按钮占满整行，有的内容稀疏，有的内容是一长段文字。建议统一如下：

| 元素        | 推荐视觉规则                        |
| --------- | ----------------------------- |
| 顶部折叠栏     | 收起状态约 100—140px 高，显示核心观点与日报状态 |
| 一级标签      | 固定为「今日重点」「市场证据」「我的跟踪与复盘」      |
| 普通指标卡     | 相同尺寸，小趋势图可直接看到                |
| 指标展开详情    | 左侧大图、右侧解释、底部可折叠的数据依据          |
| 事件卡       | 标题、事实、影响、下一步；完整推理折叠           |
| 正常数据      | 中性色或青绿色辅助                     |
| 值得关注的风险   | 橙色突出                          |
| 明确风险超限    | 红色，仅用于已达到的风险阈值                |
| 研究机会      | 青绿色，但必须符合相应研究候选条件             |
| 尚未采集或不能判断 | 灰色，不应占据首页主要位置                 |

颜色要表达研究状态，不是直接表达预测涨跌。

例如 PMI 高于50可以用温和的积极提示；但不能因为 PMI 50.1 就把整个A股方向标绿。

## 四、给 Codex 的下一轮修改要求

我建议你这次只让它做界面质量修复与信息呈现优化，不要顺便添加新宏观指标、新闻源或分析算法。否则很容易又改乱。

下面这段可以直接交给项目 Codex 执行：

# WealthSail 投资机会中心 UI 精修任务

## 本轮目标

保持现有“今日投资观察”顶部折叠栏，以及“今日重点 / 市场证据 / 我的跟踪与复盘”三个一级分类。

本轮只修复 UI、交互与信息呈现，不增加新页面、弹窗或大模型调用。

## P0：修复指标详情与图表

1. 排查 PPI 点击“完整证据”后图表不显示、布局却变化的问题。
2. 核查展开指标与实际展示内容的绑定关系，确保每个指标使用稳定 indicatorId。
3. 核对 PPI 历史序列是否真实存在。若存在则正确渲染；若不存在，明确展示原因，不允许空白详情。
4. 统一 PMI、CPI、PPI、M2、国债利率及油价的图表详情组件。
5. 图表必须响应式，占据有效可用宽度。默认卡片可以包含小趋势图，展开后呈现大图。
6. 不允许点击单张卡片导致其他卡片错位、跨组展示或高度异常。
7. 修复分组展开状态串扰，例如“全球风险与市场”显示其他分组指标的问题。

## P1：简化市场证据

1. 有效数据卡优先展示数值、边际变化、参考线和简短解释。
2. 缺失指标合并进“待补充证据”，不再生成大量空白卡片。
3. 根据研究方向动态安排核心指标。
4. 图表可直接观察趋势，不必先阅读长篇来源说明。
5. 完整数据来源、样本数量、计算口径和核验日志统一放在折叠详情的底部。

## P1：改善今日重点

1. 优先呈现真正重要的全球事件及市场风险。
2. 将事件内容标准化为：事实、投资影响、受影响资产、下一步验证。
3. 当日全球重大事件与当前研究方向的内容分开排序，再合理融合。
4. 不得把“趋势不符合条件”包装为买入机会。
5. 日历和完整日报属于次级内容，默认收起。
6. 不显示大模型原始技术枚举和开发诊断术语。

## P2：优化研究跟踪

1. 允许从事件、指数或基金研究直接“加入跟踪”。
2. 保存原始研究假设、来源、观察时间、验证条件和失效条件。
3. 研究跟踪页重点显示当前状态、条件变化与后续复盘，不堆叠表单。

## UI 验收标准

- PPI有可用历史数据时能够正常显示趋势图。
- 点击任意指标，不得出现错位、空白详情或其他指标的图表。
- 收起与展开操作清晰、稳定。
- 页面在1440px、1024px及390px宽度下没有溢出和异常留白。
- 每个主要事件在30秒内能够读懂其事实、影响与下一步。
- 首页不重复出现同一段长篇研究解释。
- 刷新、切换标签、展开图表不会额外调用Codex CLI。
- 对缺失数据与未经验证结论继续保持严格限制，不使用虚构数据填补。

先定位和修复 PPI 图表故障，再进行信息层级和视觉精修，最后提供前后截图以及测试结果。

## 最终评价

我认为这一版已经不需要继续大改整体架构。

值得保留的部分是顶部折叠设计、每日 Codex 研究、三个一级分类、事件证据追溯，以及逐步形成的研究跟踪机制。

现在应该集中处理三个问题：

第一，把 PPI 等图表交互修好，恢复直观的可视化。

第二，把长篇 AI 分析转换成清晰的事件、影响、条件与对应资产，真正做到让用户先看到价值。

第三，整理空白、卡片尺寸、按钮层级、颜色和重复内容，让整个页面形成统一的视觉语言。

这一步做好以后，才适合继续优化指数和基金之间的投资决策联动。当前最不应该发生的是：后台已经有数据、有研究，而前端点开以后却没有图，或者用大段文字掩盖了真正的重要信息。
